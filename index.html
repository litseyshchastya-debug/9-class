Креативне програмування в Processing — курс для 9 класу

Україномовний курс програмування мовою Processing у середовищі Processing (PDE) для учнів 9 класу, які вже знають основи програмування (змінні, розгалуження, цикли — наприклад, у Python чи Scratch).

Курс побудовано на основі двох класичних англомовних посібників:

Посібник Автори Що взято з посібника
Processing: A Programming Handbook for Visual Designers and Artists (MIT Press, 2-ге вид., 2014) Кейсі Різ (Casey Reas), Бен Фрай (Ben Fry) — творці Processing погляд на код як на художній інструмент: розділи Draw, Color, Repeat, Random, Transform, Typography, Image, Motion; генеративне мистецтво; синтез-проєкти
Learning Processing: A Beginner's Guide to Programming Images, Animation, and Interaction (Morgan Kaufmann, 2-ге вид., 2015) Деніел Шиффман (Daniel Shiffman) покрокова методика: Pixels → Interaction → Variables → Conditionals → Loops → Functions → Objects → Arrays → Algorithms → Debugging; наскрізний персонаж, гра «Ловець»

Пояснення, приклади й завдання адаптовано для 9 класу та української школи. Це не переклад книжок. Коментарі в коді — українською мовою.

Мета курсу

  • навчитися створювати зображення, анімацію та інтерактивні програми кодом;
  • перенести знання основ програмування на мову з явною типізацією (Java-синтаксис);
  • опанувати функції, об'єктно-орієнтоване програмування та масиви на наочних прикладах;
  • розвинути алгоритмічне та творче мислення, створити власний завершений проєкт.

Структура репозиторію

Кожен скетч лежить в окремій папці з тією самою назвою, як вимагає Processing: skechi/L07_Vidskok/L07_Vidskok.pde. Щоб запустити, відкрийте .pde-файл у Processing і натисніть ▶ Run.

Вебверсія

Відкрийте index.html у браузері: звідти є посилання на окрему сторінку кожного уроку (storinky/urok-01.html … urok-16.html). Сторінки однаково зручні на комп'ютері й на телефоні і працюють без інтернету. Після змін в uroky/ чи skechi/ оновіть їх командою python3 tools/zibraty_sait.py (потрібен пакет markdown: pip install markdown).

Структура кожного уроку

  1. Джерела: розділи обох посібників для поглибленого читання (для вчителя та зацікавлених учнів).
  2. Мета й ключові поняття (з англійськими відповідниками, бо документація Processing — англійською).
  3. Теорія з прикладами коду. Новий синтаксис порівнюється з Python, який учні вже знають.
  4. Практика на трьох рівнях: - Рівень 1: відтворення та невелика зміна прикладу (середній рівень навчальних досягнень); - Рівень 2: самостійне застосування (достатній рівень); - Рівень 3 (творчий): власний задум (високий рівень).
  5. Перевір себе: питання для рефлексії та усного опитування.

Наскрізні ідеї курсу

  • Власний персонаж. На уроці 2 учень малює персонажа (як Зуг у Шиффмана). На наступних уроках персонаж отримує змінні, рух, реакцію на мишу, функції, а потім стає класом і «натовпом» у масиві. Так видно, як кожна нова тема покращує ту саму програму.
  • Код як художній інструмент (Різ і Фрай): у кожному модулі є творче завдання з генеративного мистецтва, типографіки чи анімації.
  • Маленькі кроки (Шиффман): написали кілька рядків — запустили — перевірили.
