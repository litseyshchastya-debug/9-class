# Урок 2. Геометричні фігури та атрибути малювання

> **Джерела:** Shiffman, *Learning Processing* — розд. 1 «Pixels» (Simple Shapes); Reas & Fry — розд. 3 «Draw», 15 «Vertices».

## Мета уроку
- опанувати базові функції малювання фігур;
- навчитися керувати контуром і заливкою;
- зрозуміти **порядок малювання** (шари).

## Базові фігури (2D primitives)
| Функція | Що малює | Аргументи |
|---|---|---|
| `point(x, y)` | точку | координати |
| `line(x1, y1, x2, y2)` | відрізок | початок і кінець |
| `rect(x, y, w, h)` | прямокутник | лівий верхній кут, ширина, висота |
| `ellipse(x, y, w, h)` | еліпс / коло | **центр**, ширина, висота |
| `triangle(x1,y1, x2,y2, x3,y3)` | трикутник | три вершини |
| `quad(x1,y1, … x4,y4)` | чотирикутник | чотири вершини |
| `arc(x, y, w, h, start, stop)` | дугу / сектор | як еліпс + кути в радіанах |

### Режими прямокутника й еліпса
```java
rectMode(CORNER);   // (за замовчуванням) x,y — лівий верхній кут
rectMode(CENTER);   // x,y — центр прямокутника
ellipseMode(CENTER);  // (за замовчуванням) x,y — центр
ellipseMode(CORNER);  // x,y — лівий верхній кут описаного прямокутника
```
💡 Режим `CENTER` дуже зручний, коли фігури мають бути вирівняні по одній осі.

### Дуги
Кути задають у **радіанах**. Processing має готові константи: `PI` (180°), `HALF_PI` (90°), `QUARTER_PI` (45°), `TWO_PI` (360°). Можна перетворювати градуси: `radians(45)`.
```java
arc(100, 100, 80, 80, 0, PI);          // нижня половина кола
arc(200, 100, 80, 80, QUARTER_PI, TWO_PI - QUARTER_PI, PIE);  // «Пакмен»
```

## Атрибути малювання
| Функція | Призначення |
|---|---|
| `stroke(c)` / `noStroke()` | колір контуру / без контуру |
| `fill(c)` / `noFill()` | колір заливки / без заливки |
| `strokeWeight(n)` | товщина лінії в пікселях |
| `strokeCap(ROUND / SQUARE / PROJECT)` | форма кінців ліній |
| `smooth()` / `noSmooth()` | згладжування країв |

**Важливо:** атрибути діють **на всі фігури після них**, доки їх не змінять. Це як узяти пензель певного кольору: ним малюємо, поки не візьмемо інший.

## Порядок малювання
Processing малює фігури **у порядку рядків коду**. Кожна наступна фігура лягає **поверх** попередньої — як аркуші паперу на столі.

```java
size(300, 200);
background(220);
fill(255);  rect(50, 50, 120, 80);    // білий прямокутник — знизу
fill(100);  ellipse(150, 100, 100, 100);  // сіре коло — зверху
```

## Довільні фігури: beginShape()
```java
beginShape();
vertex(100, 20);
vertex(130, 90);
vertex(70, 90);
endShape(CLOSE);   // CLOSE замикає контур
```
За допомогою `vertex()` можна малювати зірки, стрілки, будь-які багатокутники.

## Приклад: робот Зуг
Шиффман у книзі будує персонажа **Зуга** (Zoog) і розвиває його впродовж усього курсу. Ми зробимо так само зі своїм персонажем.
```java
size(200, 200);
background(255);
rectMode(CENTER);
ellipseMode(CENTER);
// тіло
stroke(0);
fill(150);
rect(100, 100, 20, 100);
// голова
fill(255);
ellipse(100, 70, 60, 60);
// очі
fill(0);
ellipse(81, 70, 16, 32);
ellipse(119, 70, 16, 32);
// ноги
line(90, 150, 80, 160);
line(110, 150, 120, 160);
```

## Практика: компетентнісне завдання

**Ситуація.** До Тижня безпеки дорожнього руху початкова школа замовила цифровий плакат. На ньому мають бути світлофор, робот-помічник «Пішохідик» і нагорода-зірка для найуважніших пішоходів.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| ілюстратор цифрового плаката | плакат 500×400 зі світлофором, роботом і нагородами | учні 1–4 класів |

**Розвиваємо компетентності:** інформаційно-цифрова, громадянська (безпека на дорозі), культурна.

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: ви побачите сірий корпус світлофора.
2. Під коментарем «додайте червоне, жовте та зелене світло» напишіть `fill(255, 0, 0);` і `ellipse(80, 100, 70, 70);`.
3. Додайте ще два кола інших кольорів (жовте й зелене). Координати оберіть самі.

**Кінцевий результат.** На плакаті сірий корпус і три кольорові кола-сигнали.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Перевірте, що всі три кола мають **однаковий** x (стоять одне під одним) і різні y.
2. Розподіліть сигнали рівномірно по висоті корпусу: верхній, середній, нижній.

**Кінцевий результат.** Охайний світлофор: червоне, жовте й зелене світло вирівняні по вертикалі в межах корпусу.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Праворуч від світлофора намалюйте робота «Пішохідика» щонайменше з 6 фігур.
2. Для частин робота використайте `rectMode(CENTER)`: так зручно вирівнювати тіло й голову по одній осі.
3. Зробіть контур товщим: `strokeWeight(3)`.

**Кінцевий результат.** На плакаті поруч зі світлофором стоїть симетричний робот із виразним контуром.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Створіть нагороду-зірку: `beginShape()`, 10 вершин `vertex()` і `endShape(CLOSE)`.
2. Додайте ігрового персонажа «Пакмена» — `arc(..., PIE)` з «ротом» від `QUARTER_PI` до `TWO_PI - QUARTER_PI`.
3. Розташуйте всі елементи так, щоб плакат читався з першого погляду.

**Кінцевий результат.** Завершений плакат: світлофор, робот, п'ятикутна зірка й «Пакмен», жоден елемент не перекриває інші.
