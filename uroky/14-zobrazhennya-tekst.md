# Урок 14. Зображення, пікселі та текст

> **Джерела:** Shiffman, *Learning Processing* — розд. 15 «Images», 17 «Text»; Reas & Fry — розд. 11 «Text», 12 «Typography», 13 «Image», 34 «Image Processing».

## Мета уроку
- завантажувати та відображати зображення;
- застосовувати фільтри й обробляти зображення попіксельно;
- виводити текст і працювати зі шрифтами.

## 1. Завантаження зображення
1. Перетягніть файл (`.jpg`, `.png`, `.gif`) у вікно PDE — Processing скопіює його в папку **data** скетчу.
2. Код:
```java
PImage img;

void setup() {
  size(600, 400);
  img = loadImage("cat.jpg");     // завантажуємо ОДИН раз у setup()
}

void draw() {
  image(img, 0, 0);                    // x, y
  image(img, 300, 0, 150, 100);        // з іншим розміром
}
```
⚠️ Не викликайте `loadImage()` у `draw()` — файл завантажуватиметься 60 разів за секунду!

## 2. Тонування й фільтри
```java
tint(255, 0, 0);        // червоний відтінок
tint(255, 128);         // напівпрозорість
noTint();
filter(GRAY);           // відтінки сірого
filter(INVERT);         // негатив
filter(THRESHOLD, 0.5); // чорно-біле
filter(BLUR, 3);        // розмиття
filter(POSTERIZE, 4);   // постеризація
```

## 3. Пікселі: зображення = масив чисел
Будь-яке зображення — це **одновимірний масив** кольорів `pixels[]`. Піксель у точці (x, y) має індекс:
```java
int index = x + y * img.width;
```
Попіксельна обробка:
```java
img.loadPixels();
for (int y = 0; y < img.height; y++) {
  for (int x = 0; x < img.width; x++) {
    int i = x + y * img.width;
    float r = red(img.pixels[i]);
    float g = green(img.pixels[i]);
    float b = blue(img.pixels[i]);
    img.pixels[i] = color(255 - r, 255 - g, 255 - b);   // власний негатив
  }
}
img.updatePixels();
```
Так працюють фільтри у Photoshop чи Instagram — тепер ви можете написати власний!

### Пуантилізм
Малюємо зображення **колами** кольорів, узятих з випадкових пікселів (`img.get(x, y)`) — прийом у стилі Жоржа Сера. Див. скетч `L14_Puantylizm` (працює і без файлу: зображення генерується програмно).

## 4. Текст
```java
PFont font;

void setup() {
  size(400, 200);
  font = createFont("Arial", 32);   // шрифт системи
  textFont(font);
}

void draw() {
  background(255);
  fill(0);
  textAlign(CENTER, CENTER);
  textSize(32);
  text("Привіт, світ!", width/2, height/2);
  text("Кадр: " + frameCount, width/2, height/2 + 40);
}
```
- `textAlign(LEFT | CENTER | RIGHT)` — вирівнювання;
- `textWidth("слово")` — ширина тексту в пікселях;
- *Tools → Create Font* — створити файл шрифту `.vlw` для папки data;
- для кирилиці обирайте шрифт, який містить українські літери (Arial, DejaVu Sans, Roboto).

### Кінетична типографіка
Текст теж можна анімувати: кожну літеру рядка малюємо окремо з `charAt(i)` і зсуваємо через `sin()` — «хвиля з літер». Див. скетч `L14_Tekst`.

## Практика: компетентнісне завдання

**Ситуація.** Шкільна газета запускає онлайн-версію. Потрібні банер з іменем автора, простий фоторедактор з фільтрами для фото з подій і ефект «ліхтарика» для квесту «Темна кімната».

| Ваша роль | Продукт | Для кого |
|---|---|---|
| розробник медіаінструментів | банер, фоторедактор і ефект «ліхтарик» | редакція шкільної газети |

**Розвиваємо компетентності:** інформаційно-цифрова, медіаграмотність, культурна (типографіка).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: напис «Моє ім'я» в лівому верхньому куті.
2. Замініть текст своїм ім'ям.
3. Перед `text()` допишіть `textAlign(CENTER, CENTER);` і змініть координати на `width/2, height/2`.

**Кінцевий результат.** Ваше ім'я розташоване точно по центру банера.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Задайте розмір і шрифт: `textSize(48);` або `textFont(createFont("Arial", 48));` (у `setup()`).
2. Зробіть колір напису залежним від миші: `fill(mouseX * 255 / width, 150, 255);`.

**Кінцевий результат.** Великий банер з іменем, який переливається кольорами, коли рухається миша.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Додайте своє фото: «Скетч → Додати файл», потім `PImage img = loadImage("назва.jpg");` у `setup()`.
2. Покажіть фото `image()` і застосуйте фільтри `filter()` за клавішами 1–4 (наприклад, GRAY, INVERT, THRESHOLD, BLUR).

**Кінцевий результат.** Простий фоторедактор: фото змінюється за натисканням клавіш 1–4.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Створіть ефект «ліхтарика»: `loadPixels()`, змінюйте `pixels[]` і завершіть `updatePixels()`.
2. Яскравість кожного пікселя залежить від `dist()` до курсора: біля миші світло, далі — темрява.
3. Використайте `brightness()` або `red()`/`green()`/`blue()`.

**Кінцевий результат.** Інтерактивний ефект: курсор «освітлює» ділянку зображення, решта залишається в темряві.
