# Урок 14. Зображення, пікселі та текст

> **Джерела:** Shiffman, *Learning Processing* — розд. 15 «Images», 17 «Text»; Reas & Fry — розд. 11 «Text», 12 «Typography», 13 «Image», 34 «Image Processing».

## Мета уроку
- завантажувати та відображати зображення;
- застосовувати фільтри й обробляти зображення попіксельно;
- виводити текст і працювати зі шрифтами.

## 1. Завантаження зображення
1. Перетягніть файл (`.jpg`, `.png`, `.gif`) у вікно PDE — Processing скопіює його в папку **data** скетчу.
2. Код:
```java
PImage img;

void setup() {
  size(600, 400);
  img = loadImage("cat.jpg");     // завантажуємо ОДИН раз у setup()
}

void draw() {
  image(img, 0, 0);                    // x, y
  image(img, 300, 0, 150, 100);        // з іншим розміром
}
```
⚠️ Не викликайте `loadImage()` у `draw()` — файл завантажуватиметься 60 разів за секунду!

## 2. Тонування й фільтри
```java
tint(255, 0, 0);        // червоний відтінок
tint(255, 128);         // напівпрозорість
noTint();
filter(GRAY);           // відтінки сірого
filter(INVERT);         // негатив
filter(THRESHOLD, 0.5); // чорно-біле
filter(BLUR, 3);        // розмиття
filter(POSTERIZE, 4);   // постеризація
```

## 3. Пікселі: зображення = масив чисел
Будь-яке зображення — це **одновимірний масив** кольорів `pixels[]`. Піксель у точці (x, y) має індекс:
```java
int index = x + y * img.width;
```
Попіксельна обробка:
```java
img.loadPixels();
for (int y = 0; y < img.height; y++) {
  for (int x = 0; x < img.width; x++) {
    int i = x + y * img.width;
    float r = red(img.pixels[i]);
    float g = green(img.pixels[i]);
    float b = blue(img.pixels[i]);
    img.pixels[i] = color(255 - r, 255 - g, 255 - b);   // власний негатив
  }
}
img.updatePixels();
```
Так працюють фільтри у Photoshop чи Instagram — тепер ви можете написати власний!

### Пуантилізм
Малюємо зображення **колами** кольорів, узятих з випадкових пікселів (`img.get(x, y)`) — прийом у стилі Жоржа Сера. Див. скетч `L14_Puantylizm` (працює і без файлу: зображення генерується програмно).

## 4. Текст
```java
PFont font;

void setup() {
  size(400, 200);
  font = createFont("Arial", 32);   // шрифт системи
  textFont(font);
}

void draw() {
  background(255);
  fill(0);
  textAlign(CENTER, CENTER);
  textSize(32);
  text("Привіт, світ!", width/2, height/2);
  text("Кадр: " + frameCount, width/2, height/2 + 40);
}
```
- `textAlign(LEFT | CENTER | RIGHT)` — вирівнювання;
- `textWidth("слово")` — ширина тексту в пікселях;
- *Tools → Create Font* — створити файл шрифту `.vlw` для папки data;
- для кирилиці обирайте шрифт, який містить українські літери (Arial, DejaVu Sans, Roboto).

### Кінетична типографіка
Текст теж можна анімувати: кожну літеру рядка малюємо окремо з `charAt(i)` і зсуваємо через `sin()` — «хвиля з літер». Див. скетч `L14_Tekst`.

## Практика
**Рівень 1.** Виведіть своє ім'я по центру екрана; колір тексту змінюється залежно від положення миші.

**Рівень 2.** Завантажте власне фото; залежно від клавіш `1–4` застосовуйте різні фільтри.

**Рівень 3 (творчий).** «Ліхтарик»: зображення темне, а навколо курсора — яскраве (яскравість пікселя залежить від `dist()` до миші).
