## 2. Зіткнення двох кіл
Кола перетинаються, якщо відстань між центрами менша за суму радіусів:
```java
boolean intersect(Catcher c, Drop d) {
  return dist(c.x, c.y, d.x, d.y) < c.r + d.r;
}
```

## 3. Час: millis()
`millis()` — кількість мілісекунд від запуску програми. Таймер:
```java
int savedTime;
int interval = 1000;    // 1 секунда

void setup() {
  savedTime = millis();
}

void draw() {
  if (millis() - savedTime > interval) {
    // минула секунда — додаємо нову краплю
    savedTime = millis();
  }
}
```
Також доступні `second()`, `minute()`, `hour()`, `day()`, `month()`, `year()` — системний годинник.

## 4. Стани програми (екрани гри)
Більшість ігор мають екрани: заставка → гра → кінець. Зберігаємо стан у змінній:
```java
int state = 0;   // 0 — меню, 1 — гра, 2 — кінець

void draw() {
  if (state == 0) drawMenu();
  else if (state == 1) playGame();
  else if (state == 2) drawGameOver();
}

void mousePressed() {
  if (state == 0) state = 1;
  else if (state == 2) restart();
}
```

## 5. Налагодження (debugging)
Поради з розділу «Debugging» Шиффмана:
1. **Зроби перерву.** Свіжий погляд знаходить помилку швидше.
2. **Залучи друга** — поясни код уголос (метод «гумової качечки»).
3. **Спрости.** Закоментуйте частини коду, поки помилка не зникне, — так знайдете, де вона.
4. **println() — твій друг.** Виводьте значення змінних, щоб побачити, що «думає» програма.
5. **Режим налагодження** PDE: кнопка *Debug* (метелик), точки зупинки (breakpoints) — клацання на номері рядка, покрокове виконання.

| Тип помилки | Приклад | Як знайти |
|---|---|---|
| синтаксична | пропущена `;` | підкреслення в редакторі, консоль |
| помилка виконання | `NullPointerException`, вихід за межі масиву | повідомлення в консолі + номер рядка |
| логічна | м'яч «застрягає» у стіні | `println()`, debugger, спрощення |

## Практика: компетентнісне завдання

**Ситуація.** На шкільному ярмарку ваш клас запускає гру «Ловець крапель». Тестування показало, що молодшим дітям вона заскладна, а старшим — занудна. Потрібно налаштувати баланс, додати рівні та перешкоди.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| геймдизайнер і тестувальник | збалансована гра з рівнями | відвідувачі ярмарку різного віку |

**Розвиваємо компетентності:** інформаційно-цифрова, підприємливість (продукт для покупця), спілкування (зворотний зв'язок від гравців).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть гру й зіграйте раз: що здається заскладним?
2. У головній вкладці знайдіть `timer = new Timer(1000);` і змініть інтервал появи крапель (наприклад, на 1500 для повільнішої гри).
3. Знайдіть `lives = 3;` і змініть кількість життів.

**Кінцевий результат.** Гра запускається з іншим темпом появи крапель і іншою кількістю життів.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. У вкладці `Drop` знайдіть рядок, що задає швидкість: `speed = baseSpeed + random(1, 3);`, і змініть діапазон.
2. Зіграйте кілька разів і доберіть значення, за яких гра цікава, але не надто складна. Запишіть висновки в коментар.

**Кінцевий результат.** Збалансована гра: змінено інтервал, кількість життів і швидкість крапель.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Додайте змінну `int level`, яка зростає кожні 10 спійманих крапель.
2. Виводьте на екран напис «Рівень N».
3. Зробіть швидкість крапель залежною від рівня (передавайте `level` у `new Drop(...)`).

**Кінцевий результат.** Гра поступово ускладнюється, і гравець бачить свій рівень.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Створіть новий клас перешкоди (наприклад, `Stone`) і окремий `ArrayList` для перешкод.
2. Камінець, якого торкнувся ловець, віднімає життя (`lives--`).
3. Зробіть камінці помітно іншими за кольором чи формою.

**Кінцевий результат.** Гра з рівнями й перешкодами, яку цікаво проходити і молодшим, і старшим.
