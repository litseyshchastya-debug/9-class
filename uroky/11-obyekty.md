# Урок 11. Об'єкти та класи

> **Джерела:** Shiffman, *Learning Processing* — розд. 8 «Objects» (I'm down with OOP, Using an object: the details, Writing the cookie cutter, Constructor arguments); Reas & Fry — розд. 25 «Objects».

## Мета уроку
- зрозуміти ідею об'єктно-орієнтованого програмування (ООП);
- описати **клас** з полями, конструктором і методами;
- створити кілька **об'єктів** одного класу.

## 1. Клас і об'єкт: формочка для печива
Шиффман пояснює так: **клас** — це формочка для печива, а **об'єкти** — печиво, вирізане нею. Одна формочка — скільки завгодно печива, і кожне можна по-різному прикрасити.

| Поняття | English | Приклад |
|---|---|---|
| клас | class | `Car` — креслення машини |
| об'єкт / екземпляр | object / instance | `myCar`, `yourCar` |
| поле | field | колір, координати, швидкість — **дані** |
| метод | method | `move()`, `display()` — **поведінка** |
| конструктор | constructor | спосіб «зібрати» новий об'єкт |

## 2. Від змінних до класу
До ООП машина — це «розкидані» змінні та функції:
```java
color c;  float x, y, speed;
void move() { ... }   void display() { ... }
```
ООП збирає їх в **одне ціле**:
```java
class Car {
  // 1. Поля (дані)
  color c;
  float x, y;
  float speed;

  // 2. Конструктор — назва збігається з назвою класу, без типу
  Car(color tempC, float tempX, float tempY, float tempSpeed) {
    c = tempC;
    x = tempX;
    y = tempY;
    speed = tempSpeed;
  }

  // 3. Методи (поведінка)
  void move() {
    x += speed;
    if (x > width) x = 0;
  }

  void display() {
    rectMode(CENTER);
    fill(c);
    rect(x, y, 40, 20);
  }
}
```

## 3. Використання об'єктів
```java
Car redCar;    // 1. оголосити
Car blueCar;

void setup() {
  size(400, 200);
  redCar  = new Car(color(255, 0, 0), 0, 60, 2);     // 2. створити (new)
  blueCar = new Car(color(0, 0, 255), 0, 140, 1);
}

void draw() {
  background(255);
  redCar.move();      // 3. викликати методи через крапку
  redCar.display();
  blueCar.move();
  blueCar.display();
}
```
⚠️ Якщо забути `new`, отримаєте помилку `NullPointerException` — змінна є, а об'єкта ще немає.

## 4. Вкладки (tabs)
Класи зручно зберігати в окремих вкладках PDE: стрілка ▼ біля назви вкладки → *New Tab* → назва `Car`. Processing об'єднає всі вкладки в одну програму.

## 5. Чому ООП — це зручно?
- код ближчий до реального світу: «м'яч», «гравець», «ворог»;
- кожен об'єкт **сам знає**, як рухатися й малюватися;
- легко створити 2, 10 чи 1000 об'єктів (урок 12 — масиви об'єктів).

## Практика: компетентнісне завдання

**Ситуація.** Міська рада проводить конкурс ідей безпечного перехрестя біля школи. Ваша команда робить комп'ютерну модель: машини, м'ячі на ігровому майданчику і пішохід, якого можна «спіймати» мишею.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| розробник симуляції | модель перехрестя з машинами, м'ячами й пішоходом | журі конкурсу міської ради |

**Розвиваємо компетентності:** інформаційно-цифрова, громадянська (безпека громади), математична (моделювання).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: дві машини класу `Car` (див. вкладку `Car`).
2. У `setup()` створіть третю машину: оголосіть `Car greenCar;` і напишіть `greenCar = new Car(color(0, 200, 0), 0, 100, 3);`.

**Кінцевий результат.** У програмі є три об'єкти класу `Car`, хоч третя ще не їде.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. У `draw()` викличте для третьої машини `greenCar.move();` і `greenCar.display();`.
2. Розведіть машини по різних смугах (різні y) і зробіть різну швидкість.

**Кінцевий результат.** Три машини різних кольорів їдуть своїми смугами з різною швидкістю.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Додайте вкладку `Ball` і створіть клас з конструктором і методами `move()`, `bounce()`, `display()`.
2. Створіть щонайменше 3 м'ячі на ігровому майданчику.

**Кінцевий результат.** Біля перехрестя відскакують три м'ячі, кожен — окремий об'єкт.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Створіть клас пішохода з методами `display()`, `move()` і `jiggle()` (легке тремтіння).
2. Додайте метод `boolean isUnderMouse()`, який повертає `true`, коли курсор над пішоходом.
3. Використайте його: пішохід змінює колір, коли на нього наведено мишу.

**Кінцевий результат.** Модель з трьома класами об'єктів, де користувач може взаємодіяти з пішоходом.
