# Урок 3. Колір: відтінки сірого, RGB, прозорість, HSB

> **Джерела:** Shiffman, *Learning Processing* — розд. 1 (Grayscale Color, RGB Color, Color Transparency, Custom Color Ranges); Reas & Fry — розд. 4 «Color».

## Мета уроку
- зрозуміти, як комп'ютер кодує колір;
- використовувати моделі **RGB** та **HSB** і прозорість (альфа-канал);
- користуватися інструментом *Tools → Color Selector*.

## 1. Відтінки сірого
Одне число від **0** (чорний) до **255** (білий):
```java
background(0);     // чорний
fill(127);         // середньо-сірий
stroke(255);       // білий
```
❓ Чому саме 255? Бо на один канал кольору відводиться **1 байт = 8 біт**, а 2⁸ = 256 значень (0…255). Це ви вже знаєте з теми «Кодування даних».

## 2. Модель RGB
Екран змішує **світло** трьох кольорів: червоного (Red), зеленого (Green) і синього (Blue). Це **адитивне** змішування — зовсім не так, як фарби!
```java
fill(255, 0, 0);      // червоний
fill(0, 255, 0);      // зелений
fill(0, 0, 255);      // синій
fill(255, 255, 0);    // червоний + зелений = жовтий
fill(255, 255, 255);  // усі разом = білий
```
Кольори також можна записати шістнадцятковим кодом, як у веб-дизайні: `fill(#FF8800);`

| Колір | R | G | B |
|---|---|---|---|
| жовтий | 255 | 255 | 0 |
| бірюзовий | 0 | 255 | 255 |
| пурпуровий | 255 | 0 | 255 |
| помаранчевий | 255 | 136 | 0 |

## 3. Прозорість (альфа-канал)
Четвертий аргумент — **альфа**: 0 — повністю прозорий, 255 — непрозорий.
```java
background(255);
noStroke();
fill(255, 0, 0, 120);  ellipse(80, 100, 120, 120);
fill(0, 0, 255, 120);  ellipse(140, 100, 120, 120);
```
Там, де кола перетинаються, кольори змішуються.

## 4. Модель HSB
Іноді зручніше думати не «скільки червоного», а «**який відтінок, наскільки насичений, наскільки яскравий**»:
- **H**ue — відтінок (колір на колі кольорів);
- **S**aturation — насиченість (від сірого до чистого кольору);
- **B**rightness — яскравість (від чорного до повного світла).
```java
colorMode(HSB, 360, 100, 100);  // H: 0–360°, S і B: 0–100%
fill(0, 100, 100);    // червоний
fill(120, 100, 100);  // зелений
fill(210, 40, 100);   // блідо-блакитний
```
`colorMode(RGB, 1.0)` — дозволяє задавати RGB дробами від 0 до 1. Це те, що Шиффман називає *Custom Color Ranges*.

## 5. Тип даних color
Колір можна зберегти в змінній (детальніше про змінні — на наступному уроці):
```java
color sky = color(135, 206, 235);
background(sky);
```
Функції `red(c)`, `green(c)`, `blue(c)`, `hue(c)`, `brightness(c)` повертають складові кольору.

## Практика: компетентнісне завдання

**Ситуація.** На уроці фізики вивчають світло, а вчитель просить наочну ілюстрацію того, як змішуються кольори на екрані. Шкільний альманах також шукає обкладинку в стилі Піта Мондріана.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| інфографік і дизайнер обкладинки | ілюстрація змішування RGB і композиція-обкладинка | учні на уроці фізики, читачі альманаху |

**Розвиваємо компетентності:** інформаційно-цифрова, природничо-наукова (світло й колір), культурна (мистецтво абстракції).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: біле вікно 500×400.
2. Намалюйте три фігури (кола або прямокутники).
3. Перед першою фігурою напишіть `fill(255, 0, 0);` — колір RGB з трьох чисел.

**Кінцевий результат.** Три фігури, щонайменше одна з них червона.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Задайте кожній фігурі **свій** колір через `fill(r, g, b)`: щонайменше 3 різні кольори.
2. Скористайтеся меню «Інструменти → Вибір кольору», щоб підібрати числа.

**Кінцевий результат.** Три фігури трьох різних кольорів RGB.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Зробіть ілюстрацію для фізики: три кола (червоне, зелене, синє), які частково перекриваються.
2. Додайте прозорість — четверте число в `fill()`, наприклад `fill(255, 0, 0, 130)`.
3. Вимкніть контур: `noStroke()`.

**Кінцевий результат.** Діаграма з трьох прозорих кіл, де в перетинах видно нові кольори (жовтий, бірюзовий, пурпуровий, білуватий).

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Праворуч створіть обкладинку в стилі Мондріана: щонайменше 5 прямокутників із товстими чорними межами.
2. Використайте щонайменше 5 різних кольорів, зокрема записаних як `#RRGGBB` або через `colorMode(HSB, 360, 100, 100)`.
3. Поясніть у коментарі, чому обрали саме ці кольори.

**Кінцевий результат.** На полотні є наукова ілюстрація і художня композиція з 5+ кольорових площин.

## Перевір себе

Тест із 8 питань: оберіть одну правильну відповідь. Після перевірки ви побачите пояснення до кожного питання й оцінку за 12-бальною шкалою. Це **додаткова оцінка** до оцінки за практику: результат першої спроби додається до роботи, яку ви здаєте вчителю. Наступні спроби — тренувальні.

1. Який колір дасть `fill(255, 255, 255)`?
   - [ ] Чорний
   - [ ] Сірий
   - [ ] Жовтий
   - [x] Білий
   > Усі три «лампочки» світять на повну — виходить білий.

2. Який колір дасть `fill(255, 255, 0)`?
   - [ ] Білий
   - [ ] Зелений
   - [x] Жовтий
   - [ ] Помаранчевий
   > Червоне й зелене світло разом дають жовтий (адитивне змішування).

3. Чим змішування кольорів на екрані відрізняється від змішування фарб?
   - [ ] Нічим не відрізняється
   - [x] На екрані світло додається, і всі кольори разом дають білий
   - [ ] На екрані всі кольори разом дають чорний
   - [ ] На екрані неможливо змішати кольори
   > Фарби поглинають світло, а екран його випромінює — тому змішування адитивне.

4. Що означає четвертий аргумент у `fill(255, 0, 0, 50)`?
   - [x] Прозорість (альфа-канал)
   - [ ] Яскравість
   - [ ] Товщину контуру
   - [ ] Насиченість
   > Альфа: 0 — повністю прозоро, 255 — непрозоро.

5. Що означає `fill(255, 0)`?
   - [ ] Червоний колір
   - [ ] Білий непрозорий
   - [ ] Помилку
   - [x] Білий, повністю прозорий — фігури не видно
   > Два числа — це «сірий + альфа», а не червоний.

6. Чому значення кожної складової кольору лежать від 0 до 255?
   - [ ] Так вирішили творці Processing без причини
   - [ ] Монітор має лише 255 кольорів
   - [x] На складову відводиться 1 байт: 8 бітів дають 256 значень
   - [ ] Це межа людського зору
   > 2⁸ = 256 значень: від 0 до 255.

7. Коли зручно використовувати модель HSB?
   - [ ] Лише для чорно-білих зображень
   - [x] Коли треба змінити відтінок чи насиченість, не перераховуючи три числа RGB
   - [ ] Коли потрібна прозорість
   - [ ] HSB не можна використовувати в Processing
   > У HSB відтінок, насиченість і яскравість — окремі числа.

8. Який запис дасть той самий колір, що й `fill(255, 136, 0)`?
   - [x] `fill(#FF8800);`
   - [ ] `fill(#00FF88);`
   - [ ] `fill(#FF0088);`
   - [ ] `fill(#888800);`
   > FF = 255, 88 = 136, 00 = 0.
