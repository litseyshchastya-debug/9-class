## 1. Що таке Processing?
Processing — це мова програмування і середовище розробки, яке у 2001 році створили **Кейсі Різ** і **Бен Фрай** у Медіалабораторії MIT. Мета — навчити програмуванню художників і дизайнерів через **візуальний результат**: кожен рядок коду одразу видно на екрані.

Processing побудований на мові **Java**, тому все, що ви вивчите, знадобиться і в «дорослому» програмуванні (Java, C#, JavaScript/p5.js).

Ідея авторів: програмування — це новий вид *грамотності* (literacy). Як ми вчимося писати, щоб висловити думку, так ми вчимося кодувати, щоб створювати зображення, анімацію та інтерактив.

## 2. Середовище розробки (PDE)
1. Завантажте Processing із сайту **processing.org** (розділ *Download*), розпакуйте та запустіть.
2. Головне вікно містить:
   - ▶ **Run** — запуск скетчу (Ctrl+R);
   - ■ **Stop** — зупинка;
   - **текстовий редактор** — місце для коду;
   - **консоль** — сюди виводяться повідомлення `println()` і помилки.
3. Збереження: *File → Save*. Processing створює **папку** з тією ж назвою, що й файл `.pde`. Назва не може починатися з цифри та містити пробіли.
4. Довідка: виділіть назву функції → *Help → Find in Reference*.

## 3. Система координат
Шкільна система координат має початок у центрі, а вісь Y спрямована **вгору**. На екрані комп'ютера інакше:

```
(0,0) ──────────► X
  │
  │     • (40, 20)
  │
  ▼
  Y
```

- Початок координат **(0, 0)** — лівий **верхній** кут вікна.
- X збільшується **праворуч**, Y — **донизу**.
- Вікно `size(200, 100)` має координати X від 0 до 199 та Y від 0 до 99.

> 💡 Шиффман радить: перед кодом намалюйте задум на **папері в клітинку** — кожна клітинка = піксель. Це найкращий спосіб планувати координати.

## 4. Перший скетч
```java
// Мій перший скетч
size(400, 300);        // розмір вікна: ширина 400, висота 300
background(255);       // білий фон
line(0, 0, 400, 300);  // лінія з лівого верхнього в правий нижній кут
rect(150, 100, 100, 60);    // прямокутник: x, y, ширина, висота
ellipse(200, 130, 50, 50);  // коло: центр x, центр y, ширина, висота
println("Привіт, Processing!");  // повідомлення в консоль
```
📁 Скетч: `skechi/L01_PershyiSketch`

### Правила запису коду
- кожна інструкція закінчується **крапкою з комою** `;`
- Processing розрізняє великі й малі літери: `Size()` ≠ `size()`
- коментарі: `// один рядок` та `/* кілька рядків */`
- аргументи функції розділяються комами

### Типові помилки новачків
| Повідомлення | Причина |
|---|---|
| `Syntax error, maybe a missing semicolon?` | пропущено `;` |
| `The function "Rect(int,int,int,int)" does not exist` | неправильний регістр літер |
| `Missing right parenthesis ")"` | не закрита дужка |

## Практика: компетентнісне завдання

**Ситуація.** Шкільний сайт оновлюють, і команда дизайнерів просить вас намалювати кодом ескізи іконок. Код зручний тим, що іконку будь-якого розміру можна перемалювати, змінивши кілька чисел.

| Ваша роль | Продукт | Для кого |
|---|---|---|

**Розвиваємо компетентності:** інформаційно-цифрова, математична (система координат), культурна (графічний дизайн).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад ▶. Переконайтеся, що вікно має розмір 500×500 (`size(500, 500);`).
2. Знайдіть коментар «намалюйте першу діагональ» і під ним напишіть `line(0, 0, 500, 500);`.
3. Запустіть програму ще раз.

**Кінцевий результат.** Біле вікно 500×500, через яке проходить одна лінія з лівого верхнього кута в правий нижній.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Додайте другу лінію так, щоб вийшов хрест — іконка «Закрити».
2. Підказка: друга лінія з'єднує правий верхній кут (500, 0) з лівим нижнім (0, 500).

**Кінцевий результат.** У вікні великий хрест «✕»: дві діагоналі перетинаються в центрі (250, 250).

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Намалюйте іконку «На головну» — будиночок: стіна `rect()`, дах із двох `line()`, вікно — маленький квадрат.
2. Додайте сонце — `ellipse()`.
3. Сплануйте координати на папері в клітинку, щоб будиночок не перекривав центр хреста.

**Кінцевий результат.** На аркуші, крім хреста, є будиночок зі стіною, дахом і вікном та сонце — щонайменше 8 фігур.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Створіть монограму — першу літеру свого імені лише з `line()` і `rect()` (разом із попередніми фігурами — щонайменше 12 ліній і прямокутників).
2. Розподіліть іконки так, щоб фігури були в усіх чотирьох чвертях вікна і аркуш виглядав завершеним.
3. Додайте коментарі: яка частина коду малює яку іконку.

**Кінцевий результат.** Збалансований аркуш з трьома іконками (хрест, будиночок із сонцем, монограма), де використано щонайменше 3 різні види фігур.

## Перевір себе

Тест із 8 питань: оберіть одну правильну відповідь. Після перевірки ви побачите пояснення до кожного питання й оцінку за 12-бальною шкалою. Це **додаткова оцінка** до оцінки за практику: результат першої спроби додається до роботи, яку ви здаєте вчителю. Наступні спроби — тренувальні.

1. Де розташована точка (0, 0) у вікні Processing?
   - [ ] У центрі вікна
   - [x] У лівому верхньому куті
   - [ ] У лівому нижньому куті
   - [ ] У правому нижньому куті
   > Початок координат — лівий верхній кут; x зростає праворуч, y — донизу.

2. Які координати має правий нижній піксель вікна `size(300, 200)`?
   - [x] (299, 199)
   - [ ] (300, 200)
   - [ ] (200, 300)
   - [ ] (0, 200)
   > Лічба пікселів починається з нуля, тому останній має координати (ширина − 1, висота − 1).

3. Чому скетч треба зберігати в папці з такою самою назвою, як файл `.pde`?
   - [ ] Щоб скетч займав менше місця
   - [ ] Щоб код виконувався швидше
   - [ ] Це вимога лише для macOS
   - [x] Так Processing знаходить скетч і його файли
   > Processing вважає скетчем саме папку: у ній головний файл, вкладки й папка data.

4. Що робить функція `println("Привіт")`?
   - [ ] Малює текст у вікні програми
   - [ ] Друкує текст на принтері
   - [x] Виводить текст у консоль і переходить на новий рядок
   - [ ] Зберігає текст у файл
   > Консоль бачить програміст; текст у вікні виводить функція text().

5. Що означають аргументи у виклику `rect(50, 40, 120, 60);`?
   - [ ] x і y центру, ширина, висота
   - [x] x і y лівого верхнього кута, ширина, висота
   - [ ] Координати двох протилежних кутів
   - [ ] Ширина, висота, x і y
   > За замовчуванням (rectMode(CORNER)) перші два числа — кут, наступні — розміри.

6. Що буде, якщо написати `Line(0, 0, 100, 100);`?
   - [x] Помилка: функції Line не існує, бо регістр літер має значення
   - [ ] Буде намальовано лінію
   - [ ] Буде намальовано товсту лінію
   - [ ] Processing сам виправить на line
   > Processing розрізняє великі й малі літери: правильно line().

7. Яка команда намалює коло з центром (100, 100) і радіусом 30?
   - [ ] `ellipse(100, 100, 30, 30);`
   - [ ] `ellipse(70, 70, 60, 60);`

   - [x] `ellipse(100, 100, 60, 60);`

8. Як записати коментар в один рядок?
   - [ ] `# текст коментаря`
   - [ ] `<!-- текст -->`
   - [x] `// текст коментаря`
   - [ ] `-- текст коментаря`
