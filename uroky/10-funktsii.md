# Урок 10. Власні функції: параметри та повернення значень

> **Джерела:** Shiffman, *Learning Processing* — розд. 7 «Functions» (Break it down, Modularity, Reusability, Arguments, Return type, Zoog reorganization); Reas & Fry — розд. 24 «Functions».

## Мета уроку
- створювати власні функції;
- передавати у функцію **аргументи** та повертати значення через `return`;
- реорганізувати великий скетч на модулі.

## 1. Навіщо функції?
Шиффман називає дві головні причини:
- **модульність** — велику програму розбиваємо на зрозумілі частини (`drawBody()`, `move()`, `checkEdges()`);
- **повторне використання** — написали один раз, викликаємо скільки завгодно.

## 2. Оголошення функції
```java
тип_результату назва(параметри) {
  // тіло функції
}
```
```java
void drawCar(float x, float y, color c) {
  rectMode(CENTER);
  fill(c);
  rect(x, y, 80, 30);          // кузов
  fill(0);
  ellipse(x - 25, y + 15, 20, 20);   // колеса
  ellipse(x + 25, y + 15, 20, 20);
}

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  drawCar(100, 100, color(255, 0, 0));
  drawCar(250, 200, color(0, 0, 255));
  drawCar(mouseX, mouseY, color(0, 200, 0));
}
```
- `void` — функція нічого не повертає, вона лише **виконує дію**;
- `float x, float y, color c` — **параметри**: у Java для кожного вказують тип;
- значення під час виклику — **аргументи**: їхня кількість і типи мають збігатися.

Порівняння з Python: `def draw_car(x, y, c):` ↔ `void drawCar(float x, float y, color c) {`

## 3. Функції, що повертають значення
```java
float area(float r) {
  return PI * r * r;      // тип результату — float
}

boolean isInside(float px, float py, float cx, float cy, float r) {
  return dist(px, py, cx, cy) < r;
}
```
Виклик: `float s = area(10);` або `if (isInside(mouseX, mouseY, 200, 200, 50)) { ... }`

Вбудовані функції, якими ви вже користувалися, побудовані так само: `random()` повертає `float`, `dist()` — `float`, `ellipse()` — `void`.

## 4. Реорганізація скетчу
Великий `draw()` перетворюється на «зміст книжки»:
```java
void draw() {
  background(255);
  move();
  bounce();
  display();
}
```
Кожна функція — окремий «розділ». Код читається як текст українською: «рухайся, відскакуй, покажися».

## 5. Локальні змінні та параметри
Параметри та змінні, оголошені всередині функції, — **локальні**: вони існують лише під час її виконання. Функція отримує **копію** значення аргументу (для простих типів).
