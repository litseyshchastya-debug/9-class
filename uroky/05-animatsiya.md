# Урок 5. Потік програми: setup() і draw(). Анімація

> **Джерела:** Shiffman, *Learning Processing* — розд. 3 «Interaction» (Go with the flow, Our good friends setup() and draw()), розд. 4 (Variables and motion); Reas & Fry — розд. 6 «Flow», 22 «Motion».

## Мета уроку
- зрозуміти різницю між **статичним** і **динамічним** скетчем;
- опанувати структуру `setup()` / `draw()`;
- створити першу анімацію за допомогою змінних;
- розуміти **область видимості** змінних (глобальні й локальні).

## 1. Як «оживає» картинка
Мультфільм — це послідовність кадрів, що швидко змінюються. Processing робить так само:
```java
void setup() {
  // виконується ОДИН раз на початку
  size(400, 400);
}

void draw() {
  // виконується ЗНОВУ І ЗНОВУ (≈60 разів на секунду)
  background(255);
  ellipse(200, 200, 50, 50);
}
```
- `setup()` — підготовка: розмір вікна, початкові значення;
- `draw()` — **нескінченний цикл**: кожен виклик малює один кадр;
- слово `void` означає, що функція нічого не повертає (докладніше — урок 10).

`frameRate(30);` — змінює кількість кадрів за секунду. `frameCount` — номер поточного кадру.

## 2. Рух = змінна, що змінюється
```java
float x = 0;     // ГЛОБАЛЬНА змінна — оголошена поза функціями

void setup() {
  size(400, 200);
}

void draw() {
  background(255);
  ellipse(x, height/2, 40, 40);
  x = x + 2;     // кожен кадр зміщуємося на 2 пікселі
}
```
### Алгоритм будь-якої анімації (за Шиффманом)
1. **Оголосити** змінну вгорі скетчу.
2. **Ініціалізувати** її в `setup()` або при оголошенні.
3. **Використати** її в `draw()` для малювання.
4. **Змінити** її значення в `draw()`.

## 3. Що буде без background()?
Якщо прибрати `background()` з `draw()`, попередні кадри не стираються — і фігура лишає **слід**. Це не помилка, а художній прийом! Спробуйте напівпрозорий фон:
```java
fill(255, 20);
rect(0, 0, width, height);   // «туманне» стирання — плавний шлейф
```

## 4. Область видимості змінних
```java
int a = 5;          // глобальна: видно всюди

void draw() {
  int b = 10;       // локальна: існує лише всередині draw()
  // b створюється заново в кожному кадрі!
}
```
⚠️ Типова помилка: оголосити `float x = 0;` **всередині** `draw()` — тоді x щокадру знову стає нулем і нічого не рухається.

## 5. Інші види руху
```java
x += 2;                       // рівномірний рух
diameter += 0.5;              // зростання
angle += 0.05;                // обертання (урок 13)
c = (c + 1) % 256;            // зміна кольору по колу
```

## Практика: компетентнісне завдання

**Ситуація.** Шкільний телеканал готує вечірній випуск новин і замовив анімовану заставку на кілька секунд. У ній має бути рухомий об'єкт, а наприкінці — захід сонця.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| аніматор | анімована заставка | глядачі шкільного телеканалу |

**Розвиваємо компетентності:** інформаційно-цифрова, математична (зміна величин у часі), культурна (мультиплікація).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: коло рухається праворуч, бо `x` щокадру збільшується на 2.
2. Угорі скетчу оголосіть ще одну змінну: `float y = 0;`.
3. Замініть `ellipse(x, 50, 40, 40)` на `ellipse(200, y, 40, 40)`, а `x = x + 2;` — на `y = y + 2;`.

**Кінцевий результат.** Коло падає вертикально вниз посередині вікна, як крапля.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Поверніть у `ellipse()` змінну `x` замість 200 і змінюйте щокадру **обидві** змінні: `x += 2; y += 2;`.
2. Поекспериментуйте з кроками: однакові кроки — рух під кутом 45°, `y += 1` — пологіше.

**Кінцевий результат.** Коло плавно летить з лівого верхнього кута до правого нижнього, як метеор у заставці.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Додайте змінну діаметра: коло поступово збільшується, ніби наближається.
2. Додайте змінну кольору: `fill(c)`, де `c` щокадру зростає від 0 (чорний) до 255 (білий).

**Кінцевий результат.** Коло летить по діагоналі, збільшується і світлішає від чорного до білого.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Додайте захід сонця: жовте сонце повільно опускається (його `y` зростає).
2. Небо поступово темнішає: числа в `background(r, g, b)` щокадру зменшуються.
3. Додайте землю чи будинки, щоб у кадрі було щонайменше 3 фігури.

**Кінцевий результат.** Завершена заставка: метеор летить, сонце сідає, небо темнішає.
