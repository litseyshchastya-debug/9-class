## 1. Функція random()
```java
float r = random(10);        // дробове число від 0 до 10 (10 не включно)
float g = random(50, 100);   // від 50 до 100
int n = int(random(6)) + 1;  // ціле від 1 до 6 — кубик
```
⚠️ `random()` повертає `float`. Для цілого числа — перетворення `int()`.

### Випадкові кольорові кола
```java
void draw() {
  noStroke();
  fill(random(255), random(255), random(255), 100);
  float d = random(10, 60);
  ellipse(random(width), random(height), d, d);
}
```

### Повторюваний «випадок»
`randomSeed(42);` — щоразу та сама послідовність «випадкових» чисел. Корисно, коли знайшли вдалу композицію й хочете її відтворити.

### Ймовірність
```java
if (random(1) < 0.1) {   // подія з імовірністю 10%
  // ...
}
```

## 2. Випадкове блукання (random walk)
Точка щокадру робить крок у випадковому напрямку:
```java
x += random(-2, 2);
y += random(-2, 2);
point(x, y);
```

## 3. Шум Перліна — noise()
`random()` дає «стрибки», а природа змінюється **плавно**: хмари, гори, рух листя. Кен Перлін придумав функцію шуму для фільму «Трон» (1982) і отримав за це «Оскар».
```java
float t = 0;

void draw() {
  float x = noise(t) * width;   // noise повертає число від 0 до 1
  ellipse(x, height/2, 30, 30);
  t += 0.01;                    // маленький крок → плавніший рух
}
```
| random() | noise() |
|---|---|
| кожне значення незалежне | сусідні значення близькі |
| «шум телевізора» | «рельєф гір» |
| аргумент — межі | аргумент — «час» / координата |

### Гірський пейзаж
```java
for (int x = 0; x < width; x++) {
  float h = noise(x * 0.01) * height;
  line(x, height, x, height - h);
}
```

## 4. Генеративне мистецтво
Генеративне мистецтво — коли художник створює **правила**, а комп'ютер — твір. Кожен запуск дає новий унікальний результат. Відомі автори: Віра Мольнар, Георг Нес, сам Кейсі Різ (співавтор Processing).

Класичний приклад — «**10 PRINT**»: лабіринт із випадкових діагоналей.
```java
for (int y = 0; y < height; y += 20) {
  for (int x = 0; x < width; x += 20) {
    if (random(1) < 0.5) line(x, y, x + 20, y + 20);
    else                 line(x + 20, y, x, y + 20);
  }
}
```
