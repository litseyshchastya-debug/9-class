## Мета уроку

## 1. Координати миші
| Змінна | Значення |
|---|---|
| `mouseX`, `mouseY` | поточне положення курсора |
| `pmouseX`, `pmouseY` | положення курсора в **попередньому** кадрі |
| `mousePressed` | `true`, якщо кнопку затиснуто |
| `mouseButton` | `LEFT`, `RIGHT` або `CENTER` |

```java
void setup() {
  size(400, 400);
}
void draw() {
  background(255);
  ellipse(mouseX, mouseY, 40, 40);   // коло ходить за мишею
}
```

### Пензлик для малювання
```java
void setup() {
  size(600, 400);
  background(255);
  strokeWeight(4);
}
void draw() {
  // без background() — малюнок зберігається
  line(pmouseX, pmouseY, mouseX, mouseY);
}
```
💡 Лінія від попередньої точки до поточної дає **неперервний** слід навіть при швидкому русі миші.

### Миша як «регулятор»
Положення миші можна перетворити на будь-яку величину — колір, розмір, швидкість:
```java
background(mouseX * 255 / width);              // колір фону залежить від X
float d = map(mouseY, 0, height, 10, 200);     // діаметр від 10 до 200
```
`map(value, start1, stop1, start2, stop2)` — перераховує число з одного діапазону в інший. Одна з найкорисніших функцій Processing!

## 2. Події (events)
Функції подій викликаються **автоматично**, коли щось стається — один раз на подію:
```java
void mousePressed() {   // клацання мишею
  background(255);      // очистити полотно
}

void keyPressed() {     // натискання клавіші
  if (key == 's') {
    saveFrame("malyunok-####.png");   // зберегти малюнок у файл
  }
}
```
| Функція-подія | Коли викликається |
|---|---|
| `mousePressed()` | кнопку миші натиснуто |
| `mouseReleased()` | кнопку відпущено |
| `mouseDragged()` | рух із затиснутою кнопкою |
| `mouseMoved()` | рух без натискання |
| `mouseWheel(MouseEvent e)` | прокручування колеса |
| `keyPressed()` / `keyReleased()` | клавішу натиснуто / відпущено |

### Змінна vs подія
- `mousePressed` (змінна) — «кнопка **затиснута** зараз?» → перевіряється кожен кадр;
- `mousePressed()` (функція) — «щойно **відбулося** клацання» → спрацьовує один раз.

## 3. Клавіатура
- `key` — символ натиснутої клавіші (`'a'`, `'1'`, `' '`);
- `keyCode` — код спеціальних клавіш: `UP`, `DOWN`, `LEFT`, `RIGHT`, `SHIFT`… (тоді `key == CODED`).

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: персонаж стоїть у центрі.
2. У рядку з головою `ellipse(200, 180, 50, 50)` замініть 200 на `mouseX`, а 180 на `mouseY`.
3. Рухайте мишею над полотном.

**Кінцевий результат.** Голова персонажа ходить за курсором, а тіло поки стоїть на місці.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Перенесіть за мишею і тіло: у `rect(200, 220, 20, 60)` використайте `mouseX` і `mouseY + 40`.
2. Перевірте, що персонаж рухається в усі кути вікна.

**Кінцевий результат.** Увесь персонаж (голова і тіло разом) слідує за курсором, куди б ви його не повели.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Зробіть колір персонажа залежним від `mouseX`, наприклад `fill(mouseX * 255 / width, 100, 200)`.
2. Додайте функцію-подію `void mousePressed() { }`, яка змінює колір фону на випадковий. Збережіть колір у змінній `color bg`.

**Кінцевий результат.** Персонаж змінює колір, коли рухається вбік, а кожне клацання перефарбовує фон.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Додайте малювалку: поки кнопку затиснуто, малюйте `line(pmouseX, pmouseY, mouseX, mouseY)`.
2. Додайте дзеркальну лінію відносно вертикальної осі: `width - mouseX`.
3. Подумайте, як не стирати орнамент фоном (підказка: `background()` лише в `setup()` або за натисканням клавіші).

**Кінцевий результат.** Симетрична малювалка: кожен штрих дзеркально повторюється, і виходить орнамент.

   - [ ] Положення останнього клацання

   - [x] Положення курсора в попередньому кадрі
   - [ ] Центр вікна
   > p — previous (попередній).

2. Чим змінна `mousePressed` відрізняється від функції `mousePressed()`?
   - [ ] Нічим
   - [x] Змінна правдива, поки кнопку затиснуто; функція спрацьовує один раз на натискання
   - [ ] Функція спрацьовує щокадру, змінна — один раз

3. Що поверне `map(50, 0, 100, 0, 255)`?
   - [x] 127.5
   - [ ] 50.0
   - [ ] 255.0
   - [ ] 100.0

4. Як зберегти малюнок у файл із номером кадру?

   - [x] `saveFrame("pic-####.png");`

5. Як перевірити, що натиснуто стрілку вгору?

6. Як правильно записати символ у перевірці клавіші?
   - [ ] `key == "s"` (подвійні лапки)

7. Навіщо малювати `line(pmouseX, pmouseY, mouseX, mouseY)` замість `point(mouseX, mouseY)`?
   - [x] Щоб лінія була неперервною навіть при швидкому русі миші

   - [ ] point() не працює з мишею

8. Чому програма не реагує на клавіатуру, хоча `keyPressed()` написано правильно?
