# Урок 7. Умови: if / else, логічні оператори. Відскок м'яча

> **Джерела:** Shiffman, *Learning Processing* — розд. 5 «Conditionals» (Boolean expressions, Logical operators, Bouncing ball, Rollovers, Physics 101); Reas & Fry — розд. 6 «Flow».

## Мета уроку
- записувати умови в синтаксисі Java;
- комбінувати умови логічними операторами;
- створити м'яч, що відбивається від стінок, та «кнопку», що реагує на мишу.

## 1. Синтаксис умови
```java
if (умова) {
  // якщо true
} else if (інша умова) {
  // якщо перша false, а друга true
} else {
  // в усіх інших випадках
}
```
Порівняння з Python:
| Python | Processing (Java) |
|---|---|
| `if x > 5:` | `if (x > 5) {` |
| `elif` | `else if` |
| `and`, `or`, `not` | `&&`, `\|\|`, `!` |
| відступи | фігурні дужки `{ }` |

Оператори порівняння: `>  <  >=  <=  ==  !=`.
⚠️ `=` — присвоєння, `==` — порівняння!

## 2. Приклад: фон залежно від положення миші
```java
void draw() {
  if (mouseX < width/3) {
    background(255, 0, 0);
  } else if (mouseX < 2*width/3) {
    background(0, 255, 0);
  } else {
    background(0, 0, 255);
  }
}
```

## 3. Логічні оператори та «наведення» (rollover)
Чи знаходиться миша всередині прямокутника?
```java
if (mouseX > x && mouseX < x + w && mouseY > y && mouseY < y + h) {
  fill(255, 200, 0);   // підсвічування
} else {
  fill(200);
}
rect(x, y, w, h);
```
Чи знаходиться миша всередині **кола**? — відстань до центру менша за радіус:
```java
if (dist(mouseX, mouseY, cx, cy) < r) { ... }
```

## 4. Змінна-перемикач (boolean)
```java
boolean isOn = false;

void mousePressed() {
  isOn = !isOn;     // перемикаємо: true ↔ false
}
void draw() {
  if (isOn) background(255);
  else      background(0);
}
```

## 5. М'яч, що відскакує
Ключова ідея — **швидкість** як окрема змінна, яка може змінювати знак:
```java
float x = 100, y = 100;
float xSpeed = 3, ySpeed = 2;

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  x += xSpeed;
  y += ySpeed;
  if (x > width || x < 0)  xSpeed *= -1;   // відскок від бічних стінок
  if (y > height || y < 0) ySpeed *= -1;   // відскок від верху та низу
  ellipse(x, y, 30, 30);
}
```

### Трохи фізики (Physics 101)
Гравітація — це прискорення, яке щокадру збільшує швидкість:
```java
ySpeed += gravity;        // gravity = 0.2
y += ySpeed;
if (y > height) {
  ySpeed *= -0.9;         // відскок із втратою енергії
  y = height;
}
```

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: один квадрат у лівому верхньому куті.
2. За зразком додайте ще три квадрати: праворуч угорі, ліворуч унизу, праворуч унизу (усі `width/2` × `height/2`).
3. Перед квадратами додайте першу умову: `if (mousePressed) { fill(200); } else { fill(255); }`.

**Кінцевий результат.** Вікно поділено на 4 зони, які сіріють, поки натиснуто кнопку миші.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Замініть умову: кожна зона має свою перевірку положення миші. Для лівої верхньої: `if (mouseX < width/2 && mouseY < height/2) { fill(0); } else { fill(255); }`.
2. Напишіть такі самі умови для решти трьох зон.
3. Перевірте: чорною має бути **лише** та зона, над якою зараз курсор.

**Кінцевий результат.** Меню з чотирьох зон: підсвічується тільки та, над якою миша.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Додайте м'яч: змінні `x`, `y`, `xSpeed`, `ySpeed`.
2. Коли м'яч торкається стінки, змініть знак швидкості: `xSpeed *= -1`.
3. Під час кожного відскоку змінюйте колір м'яча.

**Кінцевий результат.** М'яч літає над меню, відскакує від усіх стінок і щоразу змінює колір.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Додайте ракетку внизу, яка рухається за `mouseX`.
2. Якщо м'яч торкнувся ракетки (умова з `&&`), він відскакує вгору.
3. Якщо м'яч упав нижче вікна — виведіть `text("Гру закінчено", ...)`.

**Кінцевий результат.** Гра, у яку можна грати: ракетка відбиває м'яч, а промах завершує гру написом.
