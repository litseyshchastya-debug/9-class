# Урок 7. Умови: if / else, логічні оператори. Відскок м'яча

> **Джерела:** Shiffman, *Learning Processing* — розд. 5 «Conditionals» (Boolean expressions, Logical operators, Bouncing ball, Rollovers, Physics 101); Reas & Fry — розд. 6 «Flow».

## Мета уроку
- записувати умови в синтаксисі Java;
- комбінувати умови логічними операторами;
- створити м'яч, що відбивається від стінок, та «кнопку», що реагує на мишу.

## 1. Синтаксис умови
```java
if (умова) {
  // якщо true
} else if (інша умова) {
  // якщо перша false, а друга true
} else {
  // в усіх інших випадках
}
```
Порівняння з Python:
| Python | Processing (Java) |
|---|---|
| `if x > 5:` | `if (x > 5) {` |
| `elif` | `else if` |
| `and`, `or`, `not` | `&&`, `\|\|`, `!` |
| відступи | фігурні дужки `{ }` |

Оператори порівняння: `>  <  >=  <=  ==  !=`.
⚠️ `=` — присвоєння, `==` — порівняння!

## 2. Приклад: фон залежно від положення миші
```java
void draw() {
  if (mouseX < width/3) {
    background(255, 0, 0);
  } else if (mouseX < 2*width/3) {
    background(0, 255, 0);
  } else {
    background(0, 0, 255);
  }
}
```

## 3. Логічні оператори та «наведення» (rollover)
Чи знаходиться миша всередині прямокутника?
```java
if (mouseX > x && mouseX < x + w && mouseY > y && mouseY < y + h) {
  fill(255, 200, 0);   // підсвічування
} else {
  fill(200);
}
rect(x, y, w, h);
```
Чи знаходиться миша всередині **кола**? — відстань до центру менша за радіус:
```java
if (dist(mouseX, mouseY, cx, cy) < r) { ... }
```

## 4. Змінна-перемикач (boolean)
```java
boolean isOn = false;

void mousePressed() {
  isOn = !isOn;     // перемикаємо: true ↔ false
}
void draw() {
  if (isOn) background(255);
  else      background(0);
}
```

## 5. М'яч, що відскакує
Ключова ідея — **швидкість** як окрема змінна, яка може змінювати знак:
```java
float x = 100, y = 100;
float xSpeed = 3, ySpeed = 2;

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  x += xSpeed;
  y += ySpeed;
  if (x > width || x < 0)  xSpeed *= -1;   // відскок від бічних стінок
  if (y > height || y < 0) ySpeed *= -1;   // відскок від верху та низу
  ellipse(x, y, 30, 30);
}
```

### Трохи фізики (Physics 101)
Гравітація — це прискорення, яке щокадру збільшує швидкість:
```java
ySpeed += gravity;        // gravity = 0.2
y += ySpeed;
if (y > height) {
  ySpeed *= -0.9;         // відскок із втратою енергії
  y = height;
}
```

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

3. Перевірте: чорною має бути **лише** та зона, над якою зараз курсор.

**Кінцевий результат.** Меню з чотирьох зон: підсвічується тільки та, над якою миша.

**Кінцевий результат.** М'яч літає над меню, відскакує від усіх стінок і щоразу змінює колір.

3. Якщо м'яч упав нижче вікна — виведіть `text("Гру закінчено", ...)`.

**Кінцевий результат.** Гра, у яку можна грати: ракетка відбиває м'яч, а промах завершує гру написом.

## Перевір себе

Тест із 8 питань: оберіть одну правильну відповідь. Після перевірки ви побачите пояснення до кожного питання й оцінку за 12-бальною шкалою. Це **додаткова оцінка** до оцінки за практику: результат першої спроби додається до роботи, яку ви здаєте вчителю. Наступні спроби — тренувальні.

1. Чим відрізняються `=` і `==`?
   - [ ] Нічим
   - [ ] = порівнює, == присвоює
   - [ ] == — це помилка
   - [x] = присвоює значення, == порівнює
   > if (x = 5) у Processing — помилка, треба if (x == 5).

2. Як записати умову «x від 10 до 50 включно»?
   - [ ] `10 <= x <= 50`
   - [ ] `x >= 10 || x <= 50`
   - [x] `x >= 10 && x <= 50`
   - [ ] `x > 10 && x < 50`
   > Подвійне порівняння розбивають на дві умови з &&; «включно» — це >= і <=.

3. Навіщо в м'ячі, що відскакує, множити швидкість на −1?
   - [ ] Щоб зупинити м'яч
   - [x] Щоб змінити напрямок руху на протилежний
   - [ ] Щоб пришвидшити м'яч
   - [ ] Щоб змінити колір
   > Зміна знака швидкості — це відскок.

4. Як перевірити, що курсор усередині кола з центром (cx, cy) і радіусом r?
   - [x] `dist(mouseX, mouseY, cx, cy) < r`
   - [ ] `mouseX == cx && mouseY == cy`
   - [ ] `mouseX < r`
   - [ ] `dist(mouseX, mouseY, cx, cy) > r`
   > Точка всередині, якщо відстань до центру менша за радіус.

5. Чому дорівнює `(5 > 3) && (2 > 4)`?
   - [ ] true
   - [ ] 5
   - [ ] Помилка
   - [x] false
   > && правдиве, лише коли правдиві обидві частини.

6. Що виведе програма при `t = 25`: `if (t > 30) println("спека"); else if (t > 20) println("тепло"); else println("прохолодно");`?
   - [ ] спека
   - [ ] прохолодно
   - [x] тепло
   - [ ] тепло і прохолодно
   > Виконується гілка першої правдивої умови.

7. Що робить рядок `isOn = !isOn;`?
   - [ ] Завжди робить isOn = false
   - [x] Перемикає логічну змінну на протилежне значення
   - [ ] Порівнює isOn із собою
   - [ ] Видаляє змінну
   > ! — заперечення: true стає false, і навпаки.

8. Чому м'яч «наполовину заходить» у стінку, якщо перевіряти `x > width`?
   - [x] x — це центр м'яча, тому треба враховувати радіус: x > width - r
   - [ ] Через помилку Processing
   - [ ] Через замалу швидкість
   - [ ] Треба перевіряти y, а не x
   > Відскок має відбуватися, коли стінки торкається край, а не центр.

## Домашнє завдання

**Намалюйте кодом «Кімната з вимикачем».** Кімната: стіни, вікно з місяцем, стіл і лампа. На стіні — вимикач-прямокутник: при наведенні він підсвічується, а клацання вмикає й вимикає світло в кімнаті. Під стелею літає муха, що відскакує від стін.

**Обов'язково використайте:**

- змінна `boolean` для стану світла
- умови `if`/`else` з `&&` для наведення на вимикач
- `mousePressed()` для перемикання
- відскок мухи зміною знака швидкості

**Що має вийти:** при вимкненому світлі кімната темна, при ввімкненому — світла й тепла. Муха не вилітає за стіни.

**Для охочих:** при вимкненому світлі навколо курсора видно «промінь ліхтарика» — коло, всередині якого кімната світліша.
