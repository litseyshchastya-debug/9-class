# Урок 8. Цикли while і for. Вкладені цикли та візерунки

> **Джерела:** Shiffman, *Learning Processing* — розд. 6 «Loops»; Reas & Fry — розд. 8 «Repeat».

## Мета уроку
- використовувати цикли `while` і `for` для повторення малювання;
- будувати сітки за допомогою **вкладених** циклів;
- розуміти, чому `draw()` сам по собі вже цикл.

## 1. Навіщо цикли?
Без циклу 10 ніг для персонажа — це 10 рядків коду. З циклом — 3 рядки, і кількість ніг змінюється одним числом.

## 2. Цикл while
```java
int x = 50;
while (x <= 350) {
  line(x, 100, x, 200);
  x += 20;
}
```
⚠️ **Нескінченний цикл:** якщо забути `x += 20`, програма «зависне» — `draw()` ніколи не завершить кадр.

## 3. Цикл for
Те саме компактніше:
```java
for (int x = 50; x <= 350; x += 20) {
  line(x, 100, x, 200);
}
```
| Частина | Значення |
|---|---|
| `int x = 50` | ініціалізація (виконується один раз) |
| `x <= 350` | умова продовження |
| `x += 20` | крок (після кожного повторення) |

Порівняння з Python: `for x in range(50, 351, 20):`

## 4. Цикл всередині draw()
`draw()` повторюється щокадру, а цикл `for` повністю виконується **за один кадр**. Тому:
- щоб намалювати 100 ліній **одночасно** — цикл `for`;
- щоб лінії з'являлися **по одній** — змінна, яка зростає в `draw()`.

Інтерактивний приклад — лінії, що підсвічуються біля курсора:
```java
for (int x = 0; x < width; x += 10) {
  float d = abs(mouseX - x);
  stroke(255 - d);
  line(x, 0, x, height);
}
```

## 5. Вкладені цикли = сітка
```java
for (int y = 0; y < height; y += 40) {
  for (int x = 0; x < width; x += 40) {
    fill(x * 255 / width, y * 255 / height, 150);
    rect(x, y, 40, 40);
  }
}
```
Зовнішній цикл перебирає **рядки**, внутрішній — **стовпці**. Так побудовано шахову дошку, таблицю, пікселі зображення (урок 14).

### Шахова дошка: остача від ділення
```java
if ((i + j) % 2 == 0) fill(255); else fill(0);
```

## 6. Генеративні візерунки
Цикли — основа **генеративного мистецтва** (Reas & Fry розділ «Repeat» показує роботи, де з простих повторень виникають складні структури).
```java
noFill();
for (int d = 400; d > 0; d -= 20) {
  ellipse(width/2, height/2, d, d);    // концентричні кола
}
```

## Практика: компетентнісне завдання

**Ситуація.** Школа проводить шаховий турнір і новорічний ярмарок. Потрібні гірлянда для афіші, цифрова шахівниця для табло та інтерактивна «стіна з вогників» для холу, яка реагує на людей поруч.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| дизайнер візерунків | гірлянда, шахівниця й інтерактивна стіна вогників | учасники турніру та ярмарку |

**Розвиваємо компетентності:** інформаційно-цифрова, математична (закономірності, остача від ділення), культурна.

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: одне коло.
2. Замініть рядок з колом на цикл: `for (int i = 0; i < 5; i++) { ellipse(25 + i * 50, 100 + i * 40, 40, 40); }`.
3. Запустіть програму.

**Кінцевий результат.** У вікні 5 кіл, які спускаються сходинкою, — цикл повторив команду 5 разів.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Змініть цикл так, щоб кіл було 10 і всі стояли **в один рядок** (однаковий y) рівномірно по ширині.
2. Поясніть у коментарі, як вираз `25 + i * 50` обчислює x кожного кола.

**Кінцевий результат.** Рівна гірлянда з 10 кіл через усю ширину вікна.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Нижче гірлянди намалюйте шахівницю 8×8 вкладеними циклами (рядки × стовпці).
2. Чергуйте кольори клітинок через остачу: `if ((i + j) % 2 == 0)`.

**Кінцевий результат.** Гірлянда і шахівниця з 64 правильно розфарбованих клітинок.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Додайте «стіну вогників»: сітку кіл, діаметр кожного залежить від відстані до курсора — `dist(mouseX, mouseY, x, y)`.
2. Продумайте, щоб вогники біля курсора були великими (або маленькими) і плавно змінювалися.

**Кінцевий результат.** Інтерактивна стіна: кола різного розміру, які змінюються, коли рухається миша.
