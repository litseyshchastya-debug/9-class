# Урок 4. Змінні та типи даних. Арифметика

> **Джерела:** Shiffman, *Learning Processing* — розд. 4 «Variables»; Reas & Fry — розд. 5 «Variables», 20 «Calculate».

## Мета уроку
- згадати, що таке змінна, і навчитися оголошувати змінні в Processing (Java);
- розрізняти типи `int`, `float`, `boolean`, `char`, `String`, `color`;
- використовувати системні змінні `width`, `height`;
- виконувати арифметичні обчислення та знати пастку цілочисельного ділення.

## 1. Змінна = «коробка з назвою»
Ви вже знаєте змінні з Python чи Scratch. Відмінність Java/Processing: **тип змінної треба вказати явно** під час оголошення.

```java
int x = 100;          // тип  назва = значення;
float speed = 2.5;
boolean isOn = true;
```

| Тип | Що зберігає | Приклад |
|---|---|---|
| `int` | ціле число | `int count = 10;` |
| `float` | дробове число | `float r = 3.14;` |
| `boolean` | `true` / `false` | `boolean ready = false;` |
| `char` | один символ | `char key1 = 'A';` |
| `String` | текст | `String name = "Оля";` |
| `color` | колір | `color c = color(255, 0, 0);` |

### Правила іменування
- починається з літери, без пробілів; латиницею;
- стиль **camelCase**: `ballSpeed`, `circleSize`;
- не можна використовувати зарезервовані слова (`int`, `for`, `if`…);
- назва має пояснювати зміст: `diameter`, а не `d1`.

## 2. Системні змінні
Processing сам створює та оновлює деякі змінні:
| Змінна | Значення |
|---|---|
| `width`, `height` | ширина та висота вікна |
| `mouseX`, `mouseY` | координати миші (урок 6) |
| `frameCount` | кількість кадрів від запуску (урок 5) |
| `key`, `keyCode` | остання натиснута клавіша (урок 6) |

Користуйтеся `width` і `height` замість «чарівних чисел» — тоді малюнок пристосується до будь-якого розміру вікна:
```java
size(400, 400);
ellipse(width/2, height/2, width/2, height/2);  // коло завжди по центру
```

## 3. Арифметика
`+  -  *  /  %` (остача від ділення).

⚠️ **Пастка цілочисельного ділення**:
```java
println(7 / 2);      // 3   — обидва числа цілі, дробова частина відкидається!
println(7.0 / 2);    // 3.5
println(7 % 2);      // 1   — остача
```

Скорочені записи:
```java
x = x + 1;   // те саме, що
x += 1;      // і те саме, що
x++;
```

Корисні математичні функції: `abs()`, `sqrt()`, `pow()`, `min()`, `max()`, `round()`, `constrain(v, min, max)`, `map(v, a1, b1, a2, b2)`, `dist(x1, y1, x2, y2)`.

## 4. Змінні роблять малюнок «керованим»
Ідея Шиффмана: спершу малюємо персонажа «жорсткими» числами, потім замінюємо числа на змінні — і **одним рядком** переміщуємо чи масштабуємо весь малюнок.
```java
int zoogX = 100;
int zoogY = 100;

size(200, 200);
background(255);
rectMode(CENTER);
fill(150);
rect(zoogX, zoogY, 20, 100);           // тіло
fill(255);
ellipse(zoogX, zoogY - 30, 60, 60);    // голова
fill(0);
ellipse(zoogX - 19, zoogY - 30, 16, 32);  // ліве око
ellipse(zoogX + 19, zoogY - 30, 16, 32);  // праве око
```
Змініть `zoogX = 50` — і весь персонаж переміститься!

## Практика: компетентнісне завдання

**Ситуація.** Шкільна команда розробляє гру, у якій кожен учень має аватар. Програміст має зробити аватар «налаштовуваним»: щоб його положення й розмір змінювалися одним числом, без переписування всього коду.

| Ваша роль | Продукт | Для кого |
|---|---|---|
| програміст ігрових персонажів | аватар, керований змінними | команда шкільної гри |

**Розвиваємо компетентності:** інформаційно-цифрова, математична (вирази зі змінними), уміння вчитися (узагальнення).

Працюйте в розділі **[«Практикум»](#praktykum)** нижче: там уже є приклад коду, який потрібно змінити. Усі рівні виконуються **в одному скетчі**, і кожен наступний рівень доповнює попередній. Оберіть рівень, з якого почнете: впевнено — одразу із середнього чи достатнього, а якщо тема нова — з початкового. Завершивши роботу, натисніть **[«Здати роботу»](#zdacha)**: програма перевірить результат автоматично.

### Початковий рівень (1–3 бали) — «Роблю за зразком»

**Вказівки.**

1. Запустіть приклад: коло в центрі й два рядки в консолі.
2. Над рядком `size(400, 400);` оголосіть змінні: `int x = 200;`, `int y = 200;`, `int d = 80;`.
3. Подивіться на консоль: чому `7 / 2` дає 3, а `7.0 / 2` — 3.5?

**Кінцевий результат.** Програма працює так само, але в ній уже є три змінні.

### Середній рівень (4–6 балів) — «Застосовую з підказкою»

**Вказівки.**

1. Замініть числа в `ellipse(200, 200, 80, 80)` на змінні: `ellipse(x, y, d, d);`.
2. Змініть лише значення змінних (наприклад, `x = 100`, `d = 150`) і запустіть знову.

**Кінцевий результат.** Коло переміщується й змінює розмір, коли змінюються лише значення змінних, а не виклик `ellipse()`.

### Достатній рівень (7–9 балів) — «Застосовую самостійно»

**Вказівки.**

1. Створіть змінні `charX` і `charY` — положення аватара.
2. Намалюйте аватар щонайменше з 3 фігур (тіло, голова, очі), усі координати яких записано через `charX`/`charY`, наприклад `charY - 60`.

**Кінцевий результат.** Зміна лише `charX` і `charY` переносить увесь аватар в інше місце вікна.

### Високий рівень (10–12 балів) — «Створюю власне рішення»

**Вказівки.**

1. Додайте змінну масштабу `float scale = 1.0;`.
2. Помножте на неї всі розміри й відступи частин аватара (`60 * scale`).
3. Перевірте значення 0.5 і 2.0 і виведіть їх у консоль через `println()`.

**Кінцевий результат.** Аватар щонайменше з 5 фігур, який можна перемістити й пропорційно збільшити чи зменшити, змінивши три змінні.
