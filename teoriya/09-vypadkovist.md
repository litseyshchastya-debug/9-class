# Детальна теорія до уроку 9. Випадкові числа і шум Перліна

> Тут пояснено, як комп'ютер отримує «випадкові» числа, що означають аргументи `random()`, `randomSeed()`, `noise()` і `noiseDetail()`, як моделювати ймовірність і чому шум Перліна виглядає «природно».

## 1. Навіщо випадковість

Без випадковості програма щоразу дає **однаковий** результат. Випадковість додає різноманітності: зорі розкидані по-різному, кольори щоразу інші, вороги в грі з'являються в неочікуваних місцях. У **генеративному мистецтві** художник придумує **правила**, а випадковість у межах цих правил створює щоразу новий твір.

## 2. Функція `random()`

| Виклик | Аргументи | Повертає |
|---|---|---|
| `random(верх)` | одне число | дробове число від **0** до верх (верх **не** включно) |
| `random(низ, верх)` | два числа | дробове число від низ до верх (верх не включно) |

```java
println(random(10));        // наприклад 7.3815
println(random(50, 100));   // наприклад 64.02
println(random(-1, 1));     // від −1 до 1, зручно для «тремтіння»
```

### Важливо: `random()` повертає `float`

Тому записати результат одразу в `int` не можна:

```java
int a = random(6);            // ПОМИЛКА: float не вміщується в int
int b = int(random(6));       // 0, 1, 2, 3, 4 або 5
int dice = int(random(6)) + 1;// 1…6 — гральний кубик
int c = int(random(1, 7));    // теж 1…6
```

`int()` **відкидає** дробову частину: `int(5.99)` = 5. Тому `int(random(6))` ніколи не дає 6: найбільше можливе значення 5.999…, а після відкидання — 5.

### Випадковий елемент списку

```java
String[] names = {"Оля", "Петро", "Ірина", "Максим"};
String who = names[int(random(names.length))];
```

*(Масиви — урок 12.)*

## 3. Ймовірність

`random(1)` повертає число від 0 до 1, і кожне значення однаково можливе. Тому:

| Умова | Ймовірність, що вона правдива |
|---|---|
| `random(1) < 0.5` | 50 % — «монетка» |
| `random(1) < 0.1` | 10 % |
| `random(1) < 0.01` | 1 % — рідкісна подія |
| `random(100) < 30` | 30 % |

```java
void setup() {
  size(400, 200);
  background(0);
}

void draw() {
  if (random(1) < 0.05) {               // 5 % кадрів: падаюча зірка
    stroke(255);
    float x = random(width);
    line(x, 0, x - 40, 60);
  }
  noStroke();
  fill(0, 30);
  rect(0, 0, width, height);
}
```

## 4. Псевдовипадковість і `randomSeed()`

Комп'ютер — точна машина: він **не вміє** робити справжню випадковість. `random()` обчислює числа за хитрою формулою, тому вони лише **схожі** на випадкові. Їх називають **псевдовипадковими**. Формула стартує з «насінини» (seed): за замовчуванням її беруть з поточного часу, тому щоразу виходить по-різному.

`randomSeed(число)` задає насінину вручну. З тією самою насіниною послідовність «випадкових» чисел **завжди однакова**.

| Функція | Аргумент | Навіщо |
|---|---|---|
| `randomSeed(n)` | будь-яке ціле число | повторити вдалу випадкову композицію; налагодити програму |

```java
size(300, 300);
background(255);
randomSeed(42);                // спробуйте 7, 2024, будь-яке інше
for (int i = 0; i < 40; i++) {
  fill(random(255), random(255), random(255), 150);
  ellipse(random(width), random(height), 30, 30);
}
```

Запустіть кілька разів: картинка та сама. Змініть 42 на інше число — інша, але теж стабільна.

## 5. Шум Перліна: `noise()`

### Чим `random()` не підходить для природи

Якщо щокадру брати `random(height)` для висоти точки, вона «стрибатиме» хаотично, як сніг на старому телевізорі. А гори, хвилі, хмари, політ метелика змінюються **плавно**: кожне наступне значення **близьке** до попереднього.

Кен Перлін придумав функцію плавного шуму для фільму «Трон» (1982) і в 1997 році отримав за неї технічну премію «Оскар».

### Як працює `noise()`

| Виклик | Аргументи | Повертає |
|---|---|---|
| `noise(x)` | одна координата | число від **0 до 1** |
| `noise(x, y)` | дві координати | двовимірний шум: текстури, хмари |
| `noise(x, y, z)` | три координати | третю часто використовують як «час» для анімації текстури |

Уявіть **нескінченну плавну гірську лінію**. `noise(x)` — це **висота** цієї лінії в точці x:
- **той самий** аргумент → **те саме** значення: `noise(5.3)` завжди однаковий під час одного запуску;
- **близькі** аргументи → **близькі** значення;
- **далекі** аргументи → незалежні значення.

### Крок — найважливіше налаштування

Що менший крок між аргументами, то плавніша зміна:

| Крок | Вигляд |
|---|---|
| 0.001 | майже пряма, дуже повільні зміни |
| 0.01 | плавні пагорби |
| 0.05 | гори |
| 0.5 і більше | майже як `random()`, хаотично |

```java
size(600, 300);
background(255);
for (int x = 0; x < width; x++) {
  float h1 = noise(x * 0.005) * height;   // крок 0.005 — плавно
  float h2 = noise(x * 0.05) * height;    // крок 0.05 — гостріше
  stroke(0, 120, 255);
  point(x, h1);
  stroke(255, 80, 0);
  point(x, h2);
}
```

Зверніть увагу: `noise()` повертає 0–1, тому результат **множать** на потрібний діапазон (тут на висоту вікна). Або використовують `map(noise(t), 0, 1, мін, макс)`.

### Анімація з `noise()`: змінна «часу»

```java
float t = 0;

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  float x = noise(t) * width;          // одна «гірська лінія» для x
  float y = noise(t + 100) * height;   // інша (зсув +100) — для y
  ellipse(x, y, 30, 30);
  t += 0.01;
}
```

Чому `t + 100`? Якби для x і y брати однаковий аргумент, вони були б однакові, і коло рухалось би лише по діагоналі. Зсув на 100 бере значення з **іншої ділянки** нескінченної лінії.

### Налаштування шуму

| Функція | Аргументи | Що робить |
|---|---|---|
| `noiseSeed(n)` | ціле число | як `randomSeed`, але для шуму |
| `noiseDetail(октави, спад)` | кількість «шарів» деталей (типово 4) і їхня сила 0–1 (типово 0.5) | більше октав і більший спад — більш «шорсткий», деталізований шум |

## 6. `random()` і `noise()` поруч

| | `random()` | `noise()` |
|---|---|---|
| Повертає | від низ до верх (як задано) | завжди 0…1 |
| Сусідні значення | ніяк не пов'язані | близькі |
| Той самий аргумент | щоразу інше число | те саме число |
| Аргумент означає | межі діапазону | **координату** або «час» |
| Застосування | кубики, розкидання, ймовірність | рельєф, хмари, природний рух |

## 7. Генеративне мистецтво: правила + випадковість

Класичний твір «10 PRINT» — це одне **правило**: у кожній клітинці сітки випадково провести діагональ «\» або «/». З цього виникає складний лабіринт. Інші приклади правил:
- «у кожній клітинці коло, розмір — `noise()` від координат»;
- «200 ліній, кожна починається там, де закінчилась попередня, напрямок випадковий» (random walk — випадкове блукання);
- «палітра з 4 кольорів, колір кожної фігури — випадковий з палітри».

## 8. Типові помилки

| Що сталося | Причина |
|---|---|
| `Type mismatch: float → int` | `int n = random(…)` без `int(...)` |
| кубик ніколи не показує 6 | `int(random(6))` дає 0…5; додайте `+ 1` |
| `noise()` завжди однаковий | аргумент не змінюється: забули `t += 0.01` |
| рух на `noise()` дуже «нервовий» | завеликий крок; зменште до 0.005–0.02 |
| об'єкт на `noise()` стоїть у верхньому лівому куті | забули помножити результат 0…1 на ширину чи висоту |
| `random()` у `draw()` дає миготіння | нове випадкове значення щокадру; якщо значення має бути стабільним, обчисліть його один раз у `setup()` і збережіть у змінній |

## 9. Шпаргалка

```java
random(10)               // 0 … 9.999
random(5, 10)            // 5 … 9.999
int(random(6)) + 1       // кубик 1…6
random(1) < 0.2          // подія з імовірністю 20 %
randomSeed(42)           // повторювана випадковість
noise(t) * width         // плавне значення 0 … width
t += 0.01                // крок «часу» для noise
```

## 10. Перевір себе

1. Які найменше і найбільше значення може повернути `int(random(3, 8))`?
2. Як отримати подію, що стається приблизно раз на 200 кадрів?
3. Чому `noise(0.5)` двічі поспіль поверне те саме число, а `random(1)` — ні?
4. Як за допомогою `map()` отримати з `noise(t)` значення від −50 до 50?
5. Навіщо в програмах генеративного мистецтва використовують `randomSeed()`?

<details>
<summary>Відповіді</summary>

1. Від 3 до 7: `random(3, 8)` дає 3…7.999, а `int()` відкидає дробову частину.
2. `if (random(1) < 1.0 / 200) { ... }` або `if (random(200) < 1)`.
3. `noise()` — це «висота» сталої плавної лінії в точці 0.5, тож однаковий аргумент дає однаковий результат. `random()` щоразу бере наступне число з послідовності.
4. `map(noise(t), 0, 1, -50, 50)`
5. Щоб відтворити вдалий результат: з тією самою насіниною програма намалює ту саму композицію, наприклад для друку постера.

</details>
