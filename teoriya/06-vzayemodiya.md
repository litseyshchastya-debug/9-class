# Детальна теорія до уроку 6. Миша, клавіатура і події

> Тут пояснено всі змінні та функції для взаємодії з людиною: координати миші, кнопки, клавіші, функції-події. Окремо розібрано функцію `map()` і збереження малюнка у файл.

## 1. Взаємодія = програма реагує на людину

Інтерактивна програма щокадру «дивиться», що робить користувач, і змінює малюнок. Інформацію про мишу й клавіатуру Processing кладе в **системні змінні**, які оновлюються перед кожним кадром. Крім того, він викликає особливі **функції-події**, коли щось стається.

Є два способи дізнатися про дії людини:

| Спосіб | Як працює | Аналогія |
|---|---|---|
| **змінні** (`mouseX`, `mousePressed`, `keyPressed`) | ви **самі** питаєте щокадру: «кнопка зараз затиснута?» | постійно дивитися у вікно, чи прийшов друг |
| **події** (`mousePressed()`, `keyPressed()`) | Processing **сам** викликає функцію, коли подія сталася | дверний дзвоник: дзвонить один раз, коли друг прийшов |

## 2. Змінні миші

| Змінна | Тип | Значення |
|---|---|---|
| `mouseX` | int | x курсора зараз |
| `mouseY` | int | y курсора зараз |
| `pmouseX` | int | x курсора в **попередньому** кадрі (p = previous) |
| `pmouseY` | int | y курсора в попередньому кадрі |
| `mousePressed` | boolean | `true`, поки кнопка **затиснута** |
| `mouseButton` | константа | яка кнопка: `LEFT`, `RIGHT` або `CENTER` |

Поки курсор не заходив у вікно, `mouseX` і `mouseY` дорівнюють 0.

### Миша як координата

```java
void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  line(mouseX, 0, mouseX, height);   // вертикальна лінія за мишею
  line(0, mouseY, width, mouseY);    // горизонтальна лінія за мишею
  fill(0);
  text(mouseX + ", " + mouseY, mouseX + 8, mouseY - 8);
}
```

### `pmouseX` і `pmouseY`: як малювати неперервну лінію

Миша рухається швидко, і між двома кадрами курсор може «перестрибнути» на 30 пікселів. Якщо в кожному кадрі малювати точку `point(mouseX, mouseY)`, вийде пунктир. Якщо малювати **відрізок від попереднього положення до поточного** `line(pmouseX, pmouseY, mouseX, mouseY)`, лінія буде суцільною.

Ще одне застосування — **швидкість миші**: `dist(pmouseX, pmouseY, mouseX, mouseY)` — на скільки пікселів курсор зрушив за кадр.

### Миша як «регулятор»

Координату миші можна перетворити на **будь-яку** величину: колір, розмір, швидкість, кут. Для цього потрібна функція `map()`.

## 3. Функція `map()` — ще раз, на прикладі миші

`map(значення, від1, до1, від2, до2)` перераховує число з одного діапазону в інший.

```java
void setup() {
  size(400, 300);
}

void draw() {
  float gray = map(mouseX, 0, width, 0, 255);    // ліворуч — чорний, праворуч — білий
  float d = map(mouseY, 0, height, 10, 200);     // вгорі — мале коло, внизу — велике
  background(gray);
  fill(255 - gray);
  ellipse(width/2, height/2, d, d);
}
```

| Аргумент | Для `gray` | Для `d` |
|---|---|---|
| значення | `mouseX` | `mouseY` |
| від1, до1 (звідки) | 0 … ширина вікна | 0 … висота вікна |
| від2, до2 (куди) | 0 … 255 (колір) | 10 … 200 (діаметр) |

Діапазон можна «перевернути»: `map(mouseX, 0, width, 255, 0)` дає білий ліворуч і чорний праворуч.

## 4. Функції-події миші

Ви пишете функцію з **точно такою назвою**, і Processing сам викликає її, коли трапляється подія. Між подіями `draw()` працює як завжди.

| Функція | Коли викликається |
|---|---|
| `void mousePressed() { }` | кнопку миші **натиснули** (один раз на натискання) |
| `void mouseReleased() { }` | кнопку **відпустили** |
| `void mouseClicked() { }` | натиснули й відпустили (клік) |
| `void mouseMoved() { }` | мишу рухають **без** натиснутої кнопки |
| `void mouseDragged() { }` | мишу рухають **з** натиснутою кнопкою (перетягування) |
| `void mouseWheel(MouseEvent event) { }` | крутять коліщатко; `event.getCount()` дає напрямок: −1 або 1 |

```java
color bg = color(255);

void setup() {
  size(400, 300);
}

void draw() {
  background(bg);
  fill(0);
  text("Клацніть, щоб змінити колір", 20, 30);
}

void mousePressed() {
  bg = color(random(255), random(255), random(255));
}
```

### Змінна `mousePressed` чи функція `mousePressed()`?

| | Змінна `mousePressed` | Функція `mousePressed()` |
|---|---|---|
| Як записується | без дужок, в умові: `if (mousePressed)` | окрема функція: `void mousePressed() { }` |
| Відповідає на питання | «кнопка **затиснута зараз**?» | «кнопку **щойно натиснули**» |
| Скільки разів спрацює за одне довге натискання | у **кожному** кадрі, поки тримаємо | **один** раз |
| Для чого | малювати, поки тримаємо; тягнути об'єкт | перемикач, постріл, «клацнути по кнопці» |

## 5. Клавіатура

| Змінна | Тип | Значення |
|---|---|---|
| `keyPressed` | boolean | `true`, поки будь-яку клавішу затиснуто |
| `key` | char | символ останньої натиснутої клавіші: `'a'`, `'7'`, `' '` (пробіл) |
| `keyCode` | int | код **спеціальної** клавіші |

### Звичайні й спеціальні клавіші

- **Звичайні** (літери, цифри, пробіл, Enter): перевіряють `key`: `if (key == 's')`. Символ береться в **одинарні** лапки.
- **Спеціальні** (стрілки, Shift, Ctrl, Alt): у них немає символу. Тоді `key` дорівнює `CODED`, а яку саме клавішу натиснуто, показує `keyCode`.

```java
float x = 200, y = 150;

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  ellipse(x, y, 40, 40);
}

void keyPressed() {
  if (key == CODED) {                // спеціальна клавіша
    if (keyCode == UP)    y -= 10;
    if (keyCode == DOWN)  y += 10;
    if (keyCode == LEFT)  x -= 10;
    if (keyCode == RIGHT) x += 10;
  } else if (key == ' ') {           // пробіл — у центр
    x = width/2;
    y = height/2;
  }
}
```

*(Клацніть на полотні, щоб воно отримало клавіатуру.)*

Константи `keyCode`: `UP`, `DOWN`, `LEFT`, `RIGHT`, `SHIFT`, `CONTROL`, `ALT`. Для Enter і Backspace перевіряють `key == ENTER` та `key == BACKSPACE`.

| Функція-подія | Коли |
|---|---|
| `void keyPressed() { }` | клавішу натиснули (при утриманні повторюється, як у текстовому редакторі) |
| `void keyReleased() { }` | клавішу відпустили |
| `void keyTyped() { }` | надруковано символ (не викликається для стрілок і Shift) |

⚠️ Великі й малі літери різні: `'s'` і `'S'` — різні символи. Якщо увімкнено Caps Lock, перевірка `key == 's'` не спрацює. Надійніше: `if (key == 's' || key == 'S')`.

## 6. Збереження малюнка

| Функція | Аргументи | Що робить |
|---|---|---|
| `save("назва.png")` | ім'я файлу | зберігає поточне вікно в папку скетчу |
| `saveFrame()` | — | зберігає з автоматичною назвою `screen-0001.tif` |
| `saveFrame("kadr-####.png")` | шаблон | `####` замінюється номером кадру: `kadr-0042.png` |

Формат визначається розширенням: `.png` (без втрат якості, найкраще для малюнків), `.jpg` (менший файл), `.tif`.

Типовий прийом — зберігати за натисканням клавіші:

```java
void keyPressed() {
  if (key == 's') saveFrame("malyunok-####.png");
}
```

В онлайн-середовищі кадр з'являється у вікні, звідки його можна завантажити.

## 7. Курсор

| Функція | Що робить |
|---|---|
| `noCursor()` | ховає стрілку миші (корисно в іграх) |
| `cursor()` | повертає стрілку |
| `cursor(HAND)` | інший вигляд: `ARROW`, `CROSS`, `HAND`, `MOVE`, `TEXT`, `WAIT` |

## 8. Типові помилки

| Що сталося | Причина |
|---|---|
| `mousePressed()` не спрацьовує | назву написано з помилкою (`mousepressed`, `MousePressed`) або функцію вкладено в `draw()` |
| клавіші не реагують | полотно не у фокусі: клацніть на ньому мишею |
| `if (key == "s")` — помилка | символ береться в **одинарні** лапки: `'s'` |
| стрілки не працюють через `key` | стрілки — спеціальні клавіші, їх перевіряють через `keyCode` |
| подія спрацьовує багато разів | ви перевіряєте змінну `mousePressed` у `draw()`, а треба функцію |

## 9. Шпаргалка

```java
mouseX, mouseY          // де курсор зараз
pmouseX, pmouseY        // де був кадр тому
mousePressed            // кнопку затиснуто? (змінна)
void mousePressed() {}  // кнопку щойно натиснули (подія)
key == 'a'              // звичайна клавіша
key == CODED && keyCode == UP   // спеціальна клавіша
map(v, 0, width, 0, 255)        // перерахувати діапазон
saveFrame("img-####.png")       // зберегти кадр
```
