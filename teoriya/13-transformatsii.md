# Детальна теорія до уроку 13. Кути, синус і косинус, трансформації

> Тут пояснено, як Processing працює з кутами, навіщо в графіці синус і косинус, як знайти точку на колі та кут до курсора і як працюють трансформації `translate()`, `rotate()`, `scale()`, `pushMatrix()` і `popMatrix()`. Наприкінці — рекурсія.

## 1. Кути: градуси й радіани

Ми звикли міряти кути в **градусах**: повне коло — 360°. Processing, як і більшість мов програмування, міряє кути в **радіанах**.

**Радіан** — це кут, при якому довжина дуги дорівнює радіусу кола. На повне коло припадає 2π ≈ 6,28 таких кутів.

| Градуси | Радіани | Константа Processing |
|---|---|---|
| 0° | 0 | — |
| 45° | π/4 ≈ 0,785 | `QUARTER_PI` |
| 90° | π/2 ≈ 1,571 | `HALF_PI` |
| 180° | π ≈ 3,142 | `PI` |
| 270° | 3π/2 ≈ 4,712 | `PI + HALF_PI` |
| 360° | 2π ≈ 6,283 | `TWO_PI` |

| Функція | Аргумент | Повертає | Приклад |
|---|---|---|---|
| `radians(градуси)` | кут у градусах | кут у радіанах | `radians(180)` → 3.14159 |
| `degrees(радіани)` | кут у радіанах | кут у градусах | `degrees(HALF_PI)` → 90.0 |

Нагадування: у Processing кут 0 спрямований **праворуч**, а кути зростають **за годинниковою стрілкою**, бо вісь y спрямована донизу.

## 2. Синус і косинус простими словами

Уявіть **точку на ободі колеса** радіусом 1, яке обертається навколо центру. Коли колесо повернулося на кут `a`:
- `cos(a)` — на скільки точка зміщена **по горизонталі** від центру (від −1 до 1);
- `sin(a)` — на скільки точка зміщена **по вертикалі** (від −1 до 1).

| Кут | cos | sin | Де точка (у Processing) |
|---|---|---|---|
| 0 | 1 | 0 | праворуч від центру |
| `HALF_PI` (90°) | 0 | 1 | **знизу** |
| `PI` (180°) | −1 | 0 | ліворуч |
| `PI + HALF_PI` (270°) | 0 | −1 | **зверху** |

| Функція | Аргумент | Повертає |
|---|---|---|
| `sin(кут)` | кут у радіанах | число від −1 до 1 |
| `cos(кут)` | кут у радіанах | число від −1 до 1 |
| `tan(кут)` | кут у радіанах | тангенс (sin / cos) |
| `atan2(dy, dx)` | різниця координат по y і по x | **кут** напрямку від однієї точки до іншої, від −π до π |

## 3. Точка на колі: полярні → декартові координати

Точку можна описати двома способами:
- **декартові** координати — (x, y): «на скільки праворуч і на скільки вниз»;
- **полярні** — (r, a): «на якій відстані від центру і під яким кутом».

Формули переходу (найважливіші в уроці):

```
x = cx + r * cos(a)
y = cy + r * sin(a)
```

де (cx, cy) — центр кола, r — радіус, a — кут.

```java
float a = 0;

void setup() {
  size(400, 400);
}

void draw() {
  background(255);
  float cx = width/2, cy = height/2, r = 120;
  noFill();
  ellipse(cx, cy, r * 2, r * 2);           // орбіта
  float x = cx + r * cos(a);
  float y = cy + r * sin(a);
  line(cx, cy, x, y);                      // «радіус»
  fill(255, 120, 0);
  ellipse(x, y, 24, 24);                   // планета
  a += 0.03;                               // кут зростає — точка біжить по колу
}
```

### Розставити N фігур по колу

Кут між сусідами — `TWO_PI / N`:

```java
for (int i = 0; i < 12; i++) {
  float a = TWO_PI / 12 * i;
  ellipse(200 + 150 * cos(a), 200 + 150 * sin(a), 20, 20);   // 12 «годин» циферблата
}
```

## 4. Коливання

Оскільки `sin()` плавно гойдається між −1 і 1, ним моделюють усе, що коливається: маятник, пружину, хвилю, «дихання» кнопки.

```
значення = центр + амплітуда * sin(кут)
```

| Параметр | Що задає |
|---|---|
| центр | навколо якого значення коливається |
| амплітуда | наскільки далеко відхиляється в обидва боки |
| швидкість зміни кута | як швидко коливається (частота) |

Наприклад, `float d = 50 + 20 * sin(frameCount * 0.1);` — діаметр «дихає» від 30 до 70.

## 5. Кут до курсора: `atan2()`

`atan2(y2 - y1, x2 - x1)` повертає кут напрямку **від** точки 1 **до** точки 2. Зверніть увагу: **спочатку y**, потім x.

```java
void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  float a = atan2(mouseY - height/2, mouseX - width/2);   // кут від центру до миші
  stroke(0);
  strokeWeight(4);
  line(width/2, height/2, width/2 + 80 * cos(a), height/2 + 80 * sin(a));   // «око», що дивиться на мишу
}
```

## 6. Трансформації: рухаємо не фігуру, а аркуш

Досі ми рахували координати **кожної** фігури. Трансформації дозволяють **перемістити, повернути або збільшити саму систему координат**, наче аркуш паперу під рукою. Ви малюєте так само, як завжди, а аркуш уже зсунутий чи повернутий.

| Функція | Аргументи | Що робить з «аркушем» |
|---|---|---|
| `translate(x, y)` | зсув по x і по y | переносить початок координат (0, 0) у точку (x, y) |
| `rotate(кут)` | кут у радіанах | повертає аркуш навколо **поточного** (0, 0) за годинниковою стрілкою |
| `scale(s)` | множник | збільшує (s > 1) або зменшує (s < 1) все, що малюється далі |
| `scale(sx, sy)` | окремі множники | розтягує по осях; `scale(-1, 1)` — дзеркальне відображення |
| `pushMatrix()` | — | **запам'ятати** поточний стан аркуша |
| `popMatrix()` | — | **повернути** аркуш до запам'ятованого стану |

### `translate()`

```java
size(300, 200);
translate(150, 100);        // тепер (0, 0) — у центрі вікна
rectMode(CENTER);
rect(0, 0, 80, 80);         // квадрат з'являється в центрі
```

### `rotate()` — обертає навколо (0, 0)!

Найважливіше правило: `rotate()` обертає навколо **початку координат**, а не навколо центру фігури. Щоб фігура оберталась на місці:
1. `translate()` — перенести (0, 0) у центр фігури;
2. `rotate()` — повернути;
3. намалювати фігуру з центром у **(0, 0)**.

```java
float angle = 0;

void setup() {
  size(400, 300);
  rectMode(CENTER);
}

void draw() {
  background(255);
  translate(width/2, height/2);   // 1. центр обертання
  rotate(angle);                  // 2. поворот
  rect(0, 0, 120, 120);           // 3. фігура з центром у (0, 0)
  angle += 0.02;
}
```

### Порядок трансформацій має значення

`translate()` потім `rotate()` — фігура обертається **на місці**. `rotate()` потім `translate()` — фігура літає **по колу** навколо (0, 0), бо спочатку повернули аркуш, а потім зсунули вздовж повернутої осі.

### Трансформації накопичуються

Кожна трансформація додається до попередніх: два `translate(50, 0)` поспіль = один `translate(100, 0)`. На початку **кожного** виклику `draw()` усі трансформації скидаються.

## 7. `pushMatrix()` і `popMatrix()`

Коли трансформації потрібні лише для **однієї** фігури, її «огортають»:

```java
pushMatrix();               // запам'ятали аркуш
translate(100, 100);
rotate(QUARTER_PI);
rect(0, 0, 50, 50);         // повернутий квадрат
popMatrix();                // аркуш повернувся у звичайний стан
rect(200, 100, 50, 50);     // цей квадрат не повернутий
```

Правило: кожному `pushMatrix()` — свій `popMatrix()`, як відкривній і закривній дужці. Можна вкладати: «запам'ятати Сонце → перейти до Землі → запам'ятати Землю → перейти до Місяця → …».

У нових версіях Processing є також `push()` і `pop()`: вони запам'ятовують ще й стиль (`fill`, `stroke` тощо).

## 8. Ієрархія: Сонячна система

Місяць обертається навколо Землі, яка обертається навколо Сонця. З трансформаціями це записується природно: кожен наступний `rotate`/`translate` діє **відносно** попереднього.

```
translate(центр)        → ми на Сонці
  rotate(кут Землі)
  translate(150, 0)     → ми на Землі
    rotate(кут Місяця)
    translate(30, 0)    → ми на Місяці
```

## 9. Рекурсія

**Рекурсивна** функція викликає **сама себе**. Обов'язкова умова — **умова зупинки**, інакше виклики триватимуть безкінечно (помилка StackOverflow).

Приклад фрактального дерева: «гілка» = лінія + дві менші «гілки» на її кінці під кутом.

```java
void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  translate(width/2, height);
  branch(90);
}

void branch(float len) {
  line(0, 0, 0, -len);       // малюємо гілку вгору
  translate(0, -len);        // переходимо на її кінець
  if (len > 6) {             // умова зупинки: дуже короткі гілки не продовжуємо
    pushMatrix();
    rotate(map(mouseX, 0, width, 0, HALF_PI));
    branch(len * 0.67);      // права гілка — у 1,5 раза коротша
    popMatrix();
    pushMatrix();
    rotate(-map(mouseX, 0, width, 0, HALF_PI));
    branch(len * 0.67);      // ліва гілка
    popMatrix();
  }
}
```

## 10. Трохи 3D

`size(400, 400, P3D);` вмикає тривимірний режим. З'являється третя вісь **z** («у глибину екрана»), функції `translate(x, y, z)`, `rotateX()`, `rotateY()`, `rotateZ()`, фігури `box(розмір)`, `sphere(радіус)` і освітлення `lights()`.

## 11. Типові помилки

| Що сталося | Причина |
|---|---|
| фігура обертається навколо кута вікна | немає `translate()` перед `rotate()` |
| фігура «літає» по колу замість обертатися | у фігури центр не в (0, 0) або переплутано порядок `translate`/`rotate` |
| усе після обертання теж повернуте | бракує `pushMatrix()`/`popMatrix()` |
| `rotate(45)` повертає «дивно» | кут треба в радіанах: `rotate(radians(45))` |
| точка на колі рухається проти годинникової стрілки | кут зменшується (`a -= …`) або знак sin змінено |
| рекурсія «вішає» програму | немає умови зупинки або вона ніколи не стає правдивою |

## 12. Шпаргалка

```java
x = cx + r * cos(a);   y = cy + r * sin(a);      // точка на колі
v = центр + амплітуда * sin(frameCount * швидкість); // коливання
a = atan2(ty - y, tx - x);                       // кут до цілі
pushMatrix(); translate(x, y); rotate(a); ...; popMatrix();
radians(90) == HALF_PI
```
