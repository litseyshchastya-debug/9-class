# Детальна теорія до уроку 3. Як комп'ютер записує колір

> Тут пояснено, чому кольори задають числами від 0 до 255, як змішується світло, що таке прозорість і модель HSB. Розібрано кожен варіант функцій `fill()`, `stroke()`, `background()` і `colorMode()`.

## 1. Колір — це числа

Комп'ютер не знає слова «червоний»: він працює лише з числами. Щоб показати колір, кожен піксель екрана має **три крихітні лампочки**: червону (**R**ed), зелену (**G**reen) і синю (**B**lue). Колір пікселя залежить від того, **наскільки яскраво світить кожна лампочка**.

Яскравість кожної лампочки записують числом від **0** (вимкнена) до **255** (світить на повну).

### Чому саме 255?

На яскравість однієї лампочки відводиться **1 байт = 8 бітів**. Вісім бітів (нулів і одиниць) можуть утворити 2⁸ = **256** різних комбінацій: від `00000000` (0) до `11111111` (255). Три лампочки — 3 байти, тобто 256 × 256 × 256 ≈ **16,7 мільйона** кольорів.

## 2. Відтінки сірого — один аргумент

Якщо всі три лампочки світять **однаково**, бачимо сірий. Тому для сірого достатньо одного числа:

| Число | Колір |
|---|---|
| 0 | чорний |
| 64 | темно-сірий |
| 128 | середньо-сірий |
| 192 | світло-сірий |
| 255 | білий |

```java
size(500, 100);
noStroke();
fill(0);   rect(0, 0, 100, 100);
fill(64);  rect(100, 0, 100, 100);
fill(128); rect(200, 0, 100, 100);
fill(192); rect(300, 0, 100, 100);
fill(255); rect(400, 0, 100, 100);
```

## 3. Модель RGB — три аргументи

`fill(r, g, b)` — три числа: червоний, зелений, синій.

### Світло змішується не як фарби

Фарби на папері **поглинають** світло: що більше фарби змішуємо, то темніше, а всі разом дають майже чорний. Світло на екрані **додається**: що більше лампочок увімкнено, то світліше, а всі разом дають **білий**. Таке змішування називають **адитивним** (від add — додавати).

| R | G | B | Результат | Пояснення |
|---|---|---|---|---|
| 255 | 0 | 0 | червоний | лише червона лампочка |
| 0 | 255 | 0 | зелений | лише зелена |
| 0 | 0 | 255 | синій | лише синя |
| 255 | 255 | 0 | **жовтий** | червоне + зелене світло |
| 0 | 255 | 255 | бірюзовий | зелене + синє |
| 255 | 0 | 255 | пурпуровий | червоне + синє |
| 255 | 255 | 255 | білий | усі на повну |
| 0 | 0 | 0 | чорний | усі вимкнено |
| 128 | 0 | 0 | темно-червоний | червона на половину |
| 255 | 128 | 128 | рожевий | червоний + трохи «білого» |

Як підібрати колір:
- **темніший** — зменшуйте всі три числа пропорційно;
- **світліший, пастельний** — піднімайте менші числа ближче до 255;
- **сіруватий** — зближуйте три числа між собою.

## 4. Прозорість — альфа-канал

Четверте число — **альфа** (alpha): наскільки фігура непрозора.

| Альфа | Вигляд |
|---|---|
| 255 | повністю непрозора (за замовчуванням) |
| 128 | наполовину прозора |
| 50 | ледь помітна |
| 0 | повністю прозора, невидима |

```java
size(300, 200);
background(255);
noStroke();
fill(255, 0, 0, 120);   ellipse(110, 90, 140, 140);
fill(0, 0, 255, 120);   ellipse(190, 90, 140, 140);
fill(0, 200, 0, 120);   ellipse(150, 140, 140, 140);
```

Там, де прозорі фігури накладаються, кольори змішуються. Прозорість зручна для «тумана», тіней і м'яких ефектів.

## 5. Усі варіанти аргументів `fill()`, `stroke()`, `background()`

Ці три функції приймають аргументи **однаково**:

| Виклик | Скільки чисел | Значення |
|---|---|---|
| `fill(сірий)` | 1 | відтінок сірого 0–255 |
| `fill(сірий, альфа)` | 2 | сірий + прозорість |
| `fill(r, g, b)` | 3 | колір RGB |
| `fill(r, g, b, альфа)` | 4 | колір RGB + прозорість |
| `fill(#FF8800)` | шістнадцятковий код | як у веб-дизайні |
| `fill(змінна_color)` | змінна типу `color` | збережений колір |

⚠️ Пастка: `fill(255, 0)` — це **не червоний**, а білий із прозорістю 0, тобто невидимий! Два числа означають «сірий + альфа».

`background()` прозорість не використовує як шар: він заливає все вікно.

## 6. Шістнадцятковий запис кольору

Запис `#FF8800` складається з трьох пар цифр: `FF` — червоний, `88` — зелений, `00` — синій. Кожна пара — число від `00` до `FF` у **шістнадцятковій** системі (цифри 0–9 і літери A–F), тобто від 0 до 255.

| Пара | Десяткове значення |
|---|---|
| `00` | 0 |
| `80` | 128 |
| `88` | 136 |
| `FF` | 255 |

Так `#FF8800` = (255, 136, 0) — помаранчевий. Такі коди зручно брати з інструмента *Tools → Color Selector* або з сайтів із палітрами.

## 7. Тип `color` і функція `color()`

Колір можна зберегти в **змінній** (змінні — тема уроку 4), щоб не повторювати три числа щоразу:

```java
size(300, 200);
color sky = color(135, 206, 235);   // створили колір і запам'ятали
color sun = color(255, 200, 0);
background(sky);
noStroke();
fill(sun);
ellipse(220, 70, 80, 80);
```

| Функція | Аргументи | Повертає |
|---|---|---|
| `color(...)` | ті самі варіанти, що й `fill()` | значення типу `color` |
| `red(c)`, `green(c)`, `blue(c)` | колір | складову 0–255 |
| `alpha(c)` | колір | прозорість |
| `hue(c)`, `saturation(c)`, `brightness(c)` | колір | складові HSB |
| `lerpColor(c1, c2, частка)` | два кольори і число 0–1 | колір **між** ними |

`lerpColor` — «змішувач»: при частці 0 повертає перший колір, при 1 — другий, при 0.5 — рівно посередині. Так будують плавні переходи (градієнти):

```java
size(400, 100);
color a = color(255, 0, 100);
color b = color(0, 100, 255);
for (int x = 0; x < width; x++) {
  stroke(lerpColor(a, b, x / 400.0));
  line(x, 0, x, height);
}
```

*(Цикл `for` докладно буде в уроці 8. Тут він просто малює 400 вертикальних ліній.)*

## 8. Модель HSB

У RGB важко відповісти на питання «який колір зробить небо трохи блідішим?». Модель **HSB** описує колір так, як думає художник:

| Складова | Англійською | Що означає | Діапазон за замовчуванням |
|---|---|---|---|
| **H** | Hue — відтінок | «яка фарба» на колі кольорів: червоний → жовтий → зелений → синій → пурпуровий → знову червоний | 0–255 |
| **S** | Saturation — насиченість | від сірого (0) до найчистішого кольору | 0–255 |
| **B** | Brightness — яскравість | від чорного (0) до найсвітлішого | 0–255 |

### `colorMode()` — перемикач моделі та діапазонів

| Виклик | Що означає |
|---|---|
| `colorMode(RGB)` | модель RGB, усі складові 0–255 (за замовчуванням) |
| `colorMode(HSB)` | модель HSB, усі складові 0–255 |
| `colorMode(HSB, 360, 100, 100)` | HSB з **людськими** діапазонами: відтінок у градусах 0–360, насиченість і яскравість у відсотках |
| `colorMode(RGB, 1.0)` | RGB, але складові від 0.0 до 1.0 |
| `colorMode(режим, max1, max2, max3, maxA)` | окремий максимум для кожної складової й альфи |

Зручно запам'ятати кути відтінку при `colorMode(HSB, 360, 100, 100)`:

| H | Колір |
|---|---|
| 0 | червоний |
| 30 | помаранчевий |
| 60 | жовтий |
| 120 | зелений |
| 180 | бірюзовий |
| 240 | синій |
| 300 | пурпуровий |

```java
size(360, 100);
colorMode(HSB, 360, 100, 100);
noStroke();
for (int h = 0; h < 360; h++) {
  fill(h, 80, 100);
  rect(h, 0, 1, 100);
}
```

Перевага HSB: щоб зробити «той самий колір, але блідіший», змінюємо **лише одне число** — насиченість.

⚠️ `colorMode()` — теж «налаштування інструмента». Після `colorMode(HSB, …)` всі наступні `fill()` розуміють числа як HSB. Щоб повернутися, напишіть `colorMode(RGB, 255);`.

## 9. Типові помилки

| Що сталося | Причина |
|---|---|
| Фігура зникла | `fill(255, 0)` — два числа означають «білий, повністю прозорий» |
| Колір «не той» після HSB | забули повернути `colorMode(RGB, 255)` |
| Число 300 у `fill()` поводиться як 255 | значення більші за максимум обрізаються до максимуму |
| `fill(#ff8800)` не працює | після `#` має бути рівно 6 шістнадцяткових цифр |

## 10. Шпаргалка

- 1 число — сірий; 2 — сірий + альфа; 3 — RGB; 4 — RGB + альфа.
- 0 — «вимкнено», 255 — «на повну».
- Світло: R + G = жовтий, усі = білий.
- `colorMode(HSB, 360, 100, 100)` — думати відтінком, насиченістю й яскравістю.
- `color c = color(…)` — зберегти колір у змінній.

## 11. Перевір себе

1. Який колір дасть `fill(0, 255, 255)`?
2. Як записати напівпрозорий чорний?
3. Що означає `#00FF00`?
4. У режимі `colorMode(HSB, 360, 100, 100)` як отримати яскраво-синій? А блідо-синій?
5. Що поверне `red(color(255, 128, 0))`?

<details>
<summary>Відповіді</summary>

1. Бірюзовий (зелене + синє світло).
2. `fill(0, 128);`
3. (0, 255, 0) — чистий зелений.
4. Яскраво-синій — `fill(240, 100, 100)`; блідо-синій — `fill(240, 30, 100)` (менша насиченість).
5. 255.

</details>
