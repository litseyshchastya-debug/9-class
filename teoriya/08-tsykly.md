# Детальна теорія до уроку 8. Цикли while і for

> Тут пояснено, як змусити програму повторювати дії: будову циклів `while` і `for`, покрокове виконання (трасування), вкладені цикли для сіток і різницю між циклом та `draw()`.

## 1. Навіщо цикли

Намалювати 5 кіл в один рядок можна п'ятьма рядками коду. А 100 кіл? А стільки, скільки вміститься у вікно будь-якої ширини? Для цього потрібен **цикл** — конструкція, яка **повторює** блок коду, поки виконується умова.

Кожен цикл має три складники:
1. **початок** — з якого значення почати лічбу (`x = 0`);
2. **умова продовження** — поки вона правдива, повторюємо (`x < width`);
3. **крок** — як змінювати лічильник після кожного повторення (`x += 20`).

Якщо забути крок, умова ніколи не стане хибною, і цикл виконуватиметься **вічно**: програма «зависне».

## 2. Цикл `while` («поки»)

```java
початок;
while (умова) {
  тіло циклу;
  крок;
}
```

```java
size(400, 100);
background(255);
int x = 20;               // 1. початок
while (x < width) {       // 2. умова
  ellipse(x, 50, 30, 30); // тіло
  x += 40;                // 3. крок
}
```

### Трасування (покрокове виконання)

Простежимо, що відбувається з `x`:

| Повторення | x перед перевіркою | `x < 400`? | Що малюємо | x після кроку |
|---|---|---|---|---|
| 1 | 20 | true | коло в 20 | 60 |
| 2 | 60 | true | коло в 60 | 100 |
| 3 | 100 | true | коло в 100 | 140 |
| … | … | … | … | … |
| 10 | 380 | true | коло в 380 | 420 |
| — | 420 | **false** | цикл закінчено | — |

Разом 10 кіл. Таблиця трасування — найкращий спосіб зрозуміти будь-який цикл, коли щось іде не так.

## 3. Цикл `for` — компактний запис

Усі три складники стоять в одному рядку, через **крапку з комою**:

```
for (початок; умова; крок) {
  тіло циклу;
}
```

```java
size(400, 100);
background(255);
for (int x = 20; x < width; x += 40) {
  ellipse(x, 50, 30, 30);
}
```

Цей код робить **те саме**, що й приклад з `while`.

### Як виконується `for`

```
1. початок (один раз)        int x = 20
2. перевірити умову ─── false ──► вийти з циклу
        │ true
        ▼
3. виконати тіло              ellipse(...)
4. виконати крок              x += 40
5. повернутися до пункту 2
```

### Порівняння з Python

| Python | Processing |
|---|---|
| `for i in range(10):` | `for (int i = 0; i < 10; i++) {` |
| `for i in range(5, 50, 5):` | `for (int i = 5; i < 50; i += 5) {` |
| `for i in range(10, 0, -1):` | `for (int i = 10; i > 0; i--) {` |

### Скільки разів виконається цикл

Для `for (int i = 0; i < N; i++)` — рівно **N** разів, i набуває значень 0, 1, …, N − 1. Це найпоширеніша форма. Запам'ятайте її: «від нуля, менше за N, плюс один».

### Змінна циклу — локальна

`int i`, оголошена в дужках `for`, існує **лише всередині циклу**. Після `}` її вже немає, і це добре: можна знову використати назву `i` в наступному циклі.

## 4. `while` чи `for`?

| Ситуація | Що обрати |
|---|---|
| відомо, скільки разів повторювати або в якому діапазоні рахувати | `for` |
| повторювати, поки щось не станеться (кількість заздалегідь невідома) | `while` |

## 5. Цикл усередині `draw()`

Це часте джерело плутанини:
- `draw()` повторюється **між кадрами** (60 разів за секунду);
- цикл `for` повністю виконується **всередині одного кадру**, і лише потім кадр показується на екрані.

Тому цикл **не** підходить для анімації «по одному колу за раз»: усі кола з'являться одночасно. Для поступової появи потрібна глобальна змінна, яка зростає в `draw()`:

```java
int count = 0;

void setup() {
  size(400, 100);
}

void draw() {
  background(255);
  for (int i = 0; i < count; i++) {   // малюємо стільки кіл, скільки «накопичилось»
    ellipse(20 + i * 40, 50, 30, 30);
  }
  if (frameCount % 30 == 0 && count < 10) count++;   // раз на пів секунди додаємо одне
}
```

## 6. Вкладені цикли — сітка

Цикл **всередині** циклу. Зовнішній перебирає **рядки**, внутрішній — **стовпці** в кожному рядку.

```java
size(300, 300);
background(255);
for (int row = 0; row < 3; row++) {        // зовнішній: рядки
  for (int col = 0; col < 3; col++) {      // внутрішній: стовпці
    rect(col * 100 + 10, row * 100 + 10, 80, 80);
    fill(0);
    text(row + "," + col, col * 100 + 40, row * 100 + 55);
    fill(255);
  }
}
```

### Трасування вкладених циклів

| row | col | Позиція квадрата (x, y) |
|---|---|---|
| 0 | 0 | (10, 10) |
| 0 | 1 | (110, 10) |
| 0 | 2 | (210, 10) |
| 1 | 0 | (10, 110) |
| 1 | 1 | (110, 110) |
| … | … | … |
| 2 | 2 | (210, 210) |

Внутрішній цикл виконується **повністю** для кожного кроку зовнішнього: 3 × 3 = **9** квадратів. Як годинник: хвилинна стрілка робить повне коло, поки годинна зрушує на одну поділку.

### Шахівниця: остача від ділення

Колір клітинки чергується. Якщо сума номерів рядка і стовпця парна — світла клітинка, якщо непарна — темна:

```java
if ((row + col) % 2 == 0) fill(255); else fill(0);
```

| | col 0 | col 1 | col 2 |
|---|---|---|---|
| **row 0** | 0 → світла | 1 → темна | 2 → світла |
| **row 1** | 1 → темна | 2 → світла | 3 → темна |

## 7. Корисні прийоми з циклами

| Прийом | Як |
|---|---|
| рівномірно розставити N фігур по ширині | `for (int i = 0; i < N; i++) { float x = (i + 0.5) * width / N; ... }` |
| градієнт | змінювати колір разом з лічильником: `stroke(i * 255 / width)` |
| концентричні кола | лічильник зменшується: `for (int d = 400; d > 0; d -= 20)` |
| залежність від миші | всередині циклу використати `dist(mouseX, mouseY, x, y)` |

### `break` і `continue`

- `break;` — **негайно** вийти з циклу (наприклад, коли знайшли потрібне);
- `continue;` — пропустити **решту поточного** повторення і перейти до наступного.

## 8. Типові помилки

| Що сталося | Причина |
|---|---|
| програма зависла | нескінченний цикл: крок не наближає до виходу (`x -= 20` замість `x += 20`) або його немає |
| цикл не виконався жодного разу | умова хибна від початку: `for (int i = 10; i < 5; i++)` |
| на одне повторення більше чи менше | плутанина `<` і `<=` (помилка «на одиницю») |
| `for (int i = 0; i < 10; i++);` — тіло виконалось один раз | зайва `;` після дужок: вона стає «порожнім» тілом циклу |
| кома замість крапки з комою: `for (int i = 0, i < 10, i++)` | частини `for` розділяються `;` |
| усі фігури з'являються одразу | цикл виконується за один кадр (див. розділ 5) |

## 9. Шпаргалка

```java
for (int i = 0; i < 10; i++) { }            // 10 разів: i = 0..9
for (int x = 0; x < width; x += 20) { }     // крок 20 по ширині
for (int d = 300; d > 0; d -= 30) { }       // зворотний відлік
while (умова) { ...; крок; }                // поки умова правдива
for (row...) { for (col...) { } }           // сітка
(row + col) % 2 == 0                        // шахове чергування
```

## 10. Перевір себе

1. Скільки разів виконається `for (int i = 3; i <= 12; i += 3)`? Які значення набуде i?
2. Перепишіть цикл `for (int k = 0; k < 5; k++) { println(k); }` через `while`.
3. Вкладені цикли: зовнішній 4 рази, внутрішній 6 разів. Скільки разів виконається тіло внутрішнього?
4. Чому цей код зависне: `int x = 0; while (x < 100) { ellipse(x, 50, 10, 10); }`?
5. Як намалювати 8 кіл, рівномірно розставлених по ширині вікна 400?

<details>
<summary>Відповіді</summary>

1. 4 рази: i = 3, 6, 9, 12.
2. `int k = 0; while (k < 5) { println(k); k++; }`
3. 4 × 6 = 24 рази.
4. `x` ніколи не змінюється, тож умова `x < 100` завжди правдива. Потрібно додати `x += 20;`.
5. `for (int i = 0; i < 8; i++) { ellipse(25 + i * 50, 50, 40, 40); }`. Ширина 400 / 8 = 50, центр першого кола — на половині кроку (25).

</details>
