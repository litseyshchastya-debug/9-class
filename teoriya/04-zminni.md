# Детальна теорія до уроку 4. Змінні, типи даних і обчислення

> Тут докладно розібрано, як оголосити змінну, чим відрізняються типи, як працюють арифметичні оператори та математичні функції Processing: що означає кожен аргумент і що функція повертає.

## 1. Що таке змінна

**Змінна** — це підписана «коробка» в пам'яті комп'ютера, у якій лежить значення. У коробки є:
- **назва** (ярлик), щоб до неї звертатися: `x`, `speed`, `playerName`;
- **тип** — які речі туди можна класти: цілі числа, дробові, текст…;
- **значення** — те, що лежить зараз. Його можна замінити.

У Python тип визначається сам. У Processing (мова Java) тип **обов'язково** вказують, коли створюють змінну. Це як коробка з написом «тільки для цілих чисел»: комп'ютер не дасть покласти туди текст і знайде помилку ще до запуску.

## 2. Три дії зі змінною

```java
int score;          // 1. ОГОЛОШЕННЯ: створити коробку типу int з назвою score
score = 0;          // 2. ПРИСВОЄННЯ (ініціалізація): покласти значення 0
score = score + 10; // 3. ЗМІНА: взяти поточне значення, додати 10, покласти назад
```

Оголошення і перше присвоєння зазвичай пишуть **одним рядком**:

```java
int score = 0;
```

### Знак `=` — це не «дорівнює»

У програмуванні `=` означає **«присвоїти»**: обчислити те, що праворуч, і покласти результат у змінну ліворуч. Тому запис `x = x + 1;` не має сенсу в математиці, але в програмі цілком нормальний: «взяти x, додати 1, записати назад у x».

Для порівняння «чи дорівнює» використовують `==` (урок 7).

## 3. Типи даних

| Тип | Що зберігає | Приклади значень | Діапазон |
|---|---|---|---|
| `int` | ціле число (integer) | `0`, `-15`, `400` | приблизно від −2,1 млрд до 2,1 млрд |
| `float` | дробове число (з рухомою комою) | `3.14`, `-0.5`, `2.0` | дуже великі й дуже малі числа, ~7 точних цифр |
| `boolean` | логічне значення | `true`, `false` | лише два значення |
| `char` | один символ | `'A'`, `'7'`, `'ї'` | одинарні лапки! |
| `String` | текст (рядок символів) | `"Привіт"`, `""` | подвійні лапки; тип пишуть з великої літери |
| `color` | колір | `color(255, 0, 0)` | тип Processing (урок 3) |

### Як обрати тип

- рахуємо **штуки** (кількість життів, номер рівня, кількість кіл) — `int`;
- **координати й швидкості**, які плавно змінюються (2.5 пікселя за кадр) — `float`;
- відповідь **«так / ні»** (гра почалася? кнопку натиснуто?) — `boolean`;
- **текст** для виводу — `String`.

### Що буде, якщо змішати типи

```java
int a = 5;
float b = a;        // можна: ціле число вміщується в дробове (буде 5.0)
float c = 7.8;
int d = c;          // ПОМИЛКА: дробове число не вміщується в ціле
int e = int(c);     // так можна: явне перетворення, дробова частина відкидається → 7
```

Перетворення типів (*casting*):

| Функція | Що робить | Приклад |
|---|---|---|
| `int(x)` | у ціле: **відкидає** дробову частину | `int(7.8)` → 7, `int(-7.8)` → −7 |
| `float(x)` | у дробове | `float(5)` → 5.0 |
| `round(x)` | **округлює** до найближчого цілого | `round(7.8)` → 8, `round(7.4)` → 7 |
| `str(x)` | у текст | `str(42)` → `"42"` |

## 4. Правила іменування змінних

| Правило | Правильно | Неправильно |
|---|---|---|
| починається з літери | `x1`, `ball` | `1x` |
| без пробілів і дефісів | `ballSpeed` | `ball speed`, `ball-speed` |
| латиницею | `rozmir`, `size2` | `розмір` |
| не зарезервоване слово | `count` | `int`, `for`, `if` |
| регістр має значення | `Speed` і `speed` — **різні** змінні | — |

Стиль **camelCase** («верблюжий»): перше слово з маленької літери, кожне наступне — з великої: `playerScore`, `circleDiameter`.

⚠️ Не називайте свої змінні як системні (`width`, `mouseX`, `key`): ви «закриєте» справжні значення.

## 5. Системні змінні

Processing сам створює деякі змінні й постійно оновлює їхні значення. Їх **не оголошують**, ними просто користуються:

| Змінна | Тип | Значення |
|---|---|---|
| `width` | int | ширина вікна (з `size()`) |
| `height` | int | висота вікна |
| `mouseX`, `mouseY` | int | координати миші |
| `frameCount` | int | номер поточного кадру |
| `key` | char | остання натиснута клавіша |

```java
size(400, 300);
background(255);
line(0, height/2, width, height/2);   // горизонтальна лінія посередині — для будь-якого розміру
line(width/2, 0, width/2, height);    // вертикальна
ellipse(width/2, height/2, 50, 50);   // коло рівно в центрі
```

Змініть `size(400, 300)` на `size(600, 200)` — хрест і коло самі «переїдуть» у новий центр. Це перевага змінних над «чарівними числами» (так називають числа в коді без пояснення).

## 6. Арифметичні оператори

| Оператор | Дія | Приклад | Результат |
|---|---|---|---|
| `+` | додавання (і склеювання тексту) | `7 + 2` | 9 |
| `-` | віднімання | `7 - 2` | 5 |
| `*` | множення | `7 * 2` | 14 |
| `/` | ділення | `7 / 2` | **3** (обидва int!) |
| `/` | ділення | `7.0 / 2` | 3.5 |
| `%` | остача від ділення | `7 % 2` | 1 |

### Головна пастка: цілочисельне ділення

Якщо **обидва** числа цілі (`int`), результат теж цілий: дробова частина просто **відкидається**, не округлюється.

```java
println(7 / 2);       // 3
println(9 / 10);      // 0  (!)
println(7.0 / 2);     // 3.5
println(7 / 2.0);     // 3.5
println(float(7) / 2);// 3.5
```

Щоб отримати дробовий результат, хоча б одне число має бути дробовим. Ця пастка особливо підступна в кольорах: `fill(255 * 1 / 3)` дасть 85, а `fill(1 / 3 * 255)` дасть **0**, бо `1 / 3` = 0.

### Остача `%` — дуже корисна

- `n % 2 == 0` — число **парне**;
- `frameCount % 60 == 0` — подія **раз на 60 кадрів** (≈ раз на секунду);
- `x % width` — «загорнути» координату, щоб вона не виходила за ширину вікна.

### Порядок дій

Як у математиці: спочатку `*`, `/`, `%`, потім `+`, `-`. Дужки змінюють порядок: `(2 + 3) * 4` = 20, а `2 + 3 * 4` = 14.

### Скорочені записи

| Скорочено | Повністю |
|---|---|
| `x += 5;` | `x = x + 5;` |
| `x -= 5;` | `x = x - 5;` |
| `x *= 2;` | `x = x * 2;` |
| `x /= 2;` | `x = x / 2;` |
| `x++;` | `x = x + 1;` |
| `x--;` | `x = x - 1;` |

## 7. Математичні функції

Кожна з них **повертає** результат, тобто «відповідає» числом, яке можна покласти в змінну або одразу використати як аргумент.

| Функція | Аргументи | Повертає | Приклад |
|---|---|---|---|
| `abs(n)` | число | модуль (без знака мінус) | `abs(-5)` → 5 |
| `sqrt(n)` | невід'ємне число | квадратний корінь | `sqrt(16)` → 4.0 |
| `sq(n)` | число | квадрат | `sq(5)` → 25.0 |
| `pow(n, e)` | основа, показник | n у степені e | `pow(2, 10)` → 1024.0 |
| `min(a, b)` | два (або три) числа | менше | `min(3, 8)` → 3 |
| `max(a, b)` | два (або три) числа | більше | `max(3, 8)` → 8 |
| `floor(n)` | число | округлення **вниз** | `floor(7.9)` → 7 |
| `ceil(n)` | число | округлення **вгору** | `ceil(7.1)` → 8 |
| `round(n)` | число | до найближчого цілого | `round(7.5)` → 8 |
| `dist(x1, y1, x2, y2)` | дві точки | **відстань** між ними | `dist(0, 0, 3, 4)` → 5.0 |
| `constrain(v, низ, верх)` | значення і межі | значення, «затиснуте» в межах | `constrain(300, 0, 255)` → 255 |
| `map(v, a1, b1, a2, b2)` | значення і два діапазони | значення, перераховане в новий діапазон | `map(5, 0, 10, 0, 100)` → 50.0 |
| `lerp(a, b, t)` | два числа і частка 0–1 | число між ними | `lerp(0, 100, 0.25)` → 25.0 |

### `dist()` докладно

Функція рахує відстань за **теоремою Піфагора**: √((x2 − x1)² + (y2 − y1)²). Вона знадобиться, щоб дізнатися, чи миша над колом, чи зіткнулися два об'єкти тощо.

### `map()` докладно — «перекладач діапазонів»

`map(значення, від1, до1, від2, до2)` відповідає на питання: «якщо значення лежить у діапазоні від1…до1, то якому числу воно відповідає в діапазоні від2…до2?»

Приклад із життя: оцінку 9 із 12 переводимо у відсотки:

```java
float percent = map(9, 0, 12, 0, 100);   // 75.0
println(percent);
```

| Аргумент | У прикладі | Що означає |
|---|---|---|
| значення | 9 | що перераховуємо |
| від1, до1 | 0, 12 | старий діапазон |
| від2, до2 | 0, 100 | новий діапазон |

`map()` не обрізає результат: якщо значення вийде за старий діапазон, результат вийде за новий. Щоб «затиснути», загорніть результат у `constrain()`.

### `constrain()` докладно — «обмежувач»

```java
int brightness = 300;
brightness = constrain(brightness, 0, 255);   // тепер 255
```

Повертає: нижню межу, якщо значення менше за неї; верхню, якщо більше; саме значення, якщо воно між межами.

## 8. Текст і склеювання

Оператор `+` з текстом **склеює** (конкатенація):

```java
String name = "Оля";
int age = 14;
println("Привіт, " + name + "! Тобі " + age + " років.");
println("2 + 3 = " + 2 + 3);     // «2 + 3 = 23» — склеїлось як текст!
println("2 + 3 = " + (2 + 3));   // «2 + 3 = 5» — дужки спочатку рахують суму
```

## 9. Змінні керують малюнком

Головна практична ідея уроку: якщо всі координати фігури залежать від кількох змінних, то, змінивши **одну** змінну, ви переміщуєте чи масштабуєте **весь** малюнок.

```java
size(300, 200);
background(255);
float cx = 150;      // центр будиночка
float base = 160;    // рівень землі
float s = 1.0;       // масштаб
rectMode(CENTER);
fill(230, 180, 120);
rect(cx, base - 40 * s, 100 * s, 80 * s);                  // стіна
fill(180, 60, 40);
triangle(cx - 60 * s, base - 80 * s, cx + 60 * s, base - 80 * s, cx, base - 130 * s);  // дах
fill(120, 200, 255);
rect(cx, base - 45 * s, 30 * s, 30 * s);                   // вікно
```

Спробуйте змінити `cx` на 80 або `s` на 1.3.

## 10. Типові помилки

| Повідомлення / поведінка | Причина |
|---|---|
| `The variable "x" does not exist` | змінну не оголошено або написано з іншим регістром |
| `Duplicate local variable x` | змінну оголошено двічі: тип пишуть лише **перший** раз |
| `Type mismatch: cannot convert from float to int` | дробове значення кладуть у змінну `int`: використайте `float` або `int(...)` |
| результат ділення 0 | обидва числа цілі: `1 / 3` → 0 |
| `"2 + 3 = " + 2 + 3` дає 23 | без дужок числа склеюються як текст |

## 11. Шпаргалка

```
тип назва = значення;     int lives = 3;   float speed = 2.5;
змінити:                  lives = lives - 1;   lives--;   speed *= 2;
перетворити:              int(7.9) → 7   round(7.9) → 8   float(3) → 3.0
ціле ÷ ціле = ціле:       7 / 2 → 3        7 / 2.0 → 3.5    7 % 2 → 1
```
