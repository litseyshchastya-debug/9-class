# Детальна теорія до уроку 2. Фігури, контур, заливка і порядок малювання

> У цьому поясненні розібрано всі функції малювання фігур: що означає кожен аргумент, як працюють режими `rectMode()` та `ellipseMode()`, як задавати кути для дуг і як будувати власні фігури з вершин.

## 1. Головна ідея: «пензель» і «полотно»

Уявіть, що ви художник із двома інструментами:
- **олівець для контуру** — ним обводять край фігури (`stroke`);
- **пензель для заливки** — ним зафарбовують усередині (`fill`).

Перед тим як малювати, ви **налаштовуєте інструменти**: обираєте колір олівця, товщину лінії, колір пензля. Потім малюєте фігури, і **всі вони** виходять з цими налаштуваннями, доки ви їх не зміните.

Це найважливіше правило уроку:

> **Налаштування стилю діють на всі фігури, намальовані після них, доки їх не змінять.**

За замовчуванням: контур чорний товщиною 1 піксель, заливка біла.

## 2. Базові фігури

### `point(x, y)` — точка

| Аргумент | Що означає |
|---|---|
| x, y | де поставити точку |

Колір точки задає `stroke()`, а не `fill()`: точка — це «краплинка» олівця. Розмір — через `strokeWeight()`.

### `line(x1, y1, x2, y2)` — відрізок

| Аргумент | Що означає |
|---|---|
| x1, y1 | перший кінець |
| x2, y2 | другий кінець |

Лінія не має «середини», тому `fill()` на неї не діє. Колір — `stroke()`, товщина — `strokeWeight()`.

### `rect(x, y, w, h)` і `rect(x, y, w, h, r)` — прямокутник

| Аргумент | Що означає (режим CORNER) |
|---|---|
| x, y | лівий верхній кут |
| w | ширина (width) |
| h | висота (height) |
| r *(необов'язковий)* | радіус заокруглення кутів |

```java
size(400, 150);
background(255);
rect(20, 30, 100, 80);        // звичайний
rect(150, 30, 100, 80, 20);   // із заокругленими кутами
rect(280, 30, 80, 80);        // квадрат
```

Є й коротка функція для квадрата: `square(x, y, сторона)`.

### `ellipse(x, y, w, h)` — еліпс; `circle(x, y, d)` — коло

| Аргумент | Що означає (режим CENTER) |
|---|---|
| x, y | центр |
| w, h | ширина й висота (діаметри по горизонталі та вертикалі) |

`circle(x, y, d)` — те саме, що `ellipse(x, y, d, d)`. Тут d — діаметр.

### `triangle(x1, y1, x2, y2, x3, y3)` — трикутник

Шість чисел — це **три вершини** по дві координати. Вершини можна задавати в будь-якому порядку.

```java
size(200, 200);
background(255);
triangle(100, 20, 180, 180, 20, 180);   // вершина, правий кут, лівий кут
```

### `quad(x1, y1, x2, y2, x3, y3, x4, y4)` — чотирикутник

Вісім чисел — чотири вершини. ⚠️ Тут порядок **важливий**: вершини треба перелічувати **по колу** (за годинниковою стрілкою або проти). Якщо переплутати, лінії перехрестяться, як «метелик».

```java
size(300, 150);
background(255);
quad(20, 20, 120, 40, 110, 130, 30, 110);     // вершини по колу — правильно
quad(170, 20, 270, 40, 180, 110, 260, 130);   // порядок переплутано — «метелик»
```

## 3. Дуги: `arc(x, y, w, h, start, stop)` і `arc(..., режим)`

Дуга — це **частина еліпса**. Перші чотири аргументи такі самі, як в `ellipse()`, а два останні кажуть, **з якого кута почати і де закінчити**.

| Аргумент | Що означає |
|---|---|
| x, y, w, h | еліпс, частину якого малюємо |
| start | початковий кут (у радіанах) |
| stop | кінцевий кут (у радіанах), має бути **більшим** за start |
| режим *(необов'язковий)* | `OPEN`, `CHORD` або `PIE` |

### Як рахуються кути в Processing

```
                270° (3π/2)
                     │
                     │
   180° (π) ─────────●───────── 0°  (і 360° = 2π)
                     │
                     │
                 90° (π/2)
```

- Кут **0** — праворуч від центру, як стрілка годинника на «3 годині».
- Кути зростають **за годинниковою стрілкою**. У математиці навпаки, але в Processing вісь y спрямована донизу, тому все «перевертається».
- Тому 90° — це **низ**, а 270° — **верх**.

### Радіани — інша одиниця кутів

Processing вимірює кути не в градусах, а в **радіанах**. Повне коло — це 2π ≈ 6,28 радіана. Готові константи:

| Константа | Градуси | Значення |
|---|---|---|
| `QUARTER_PI` | 45° | ≈ 0,785 |
| `HALF_PI` | 90° | ≈ 1,571 |
| `PI` | 180° | ≈ 3,142 |
| `TWO_PI` | 360° | ≈ 6,283 |

Не хочете думати в радіанах? Скористайтеся функцією `radians(градуси)`: `radians(90)` поверне те саме, що `HALF_PI`.

### Три режими дуги

```java
size(420, 150);
background(255);
arc(70, 75, 100, 100, 0, PI + HALF_PI, OPEN);    // лише дуга, заливка без лінії-хорди
arc(210, 75, 100, 100, 0, PI + HALF_PI, CHORD);  // дугу закрито прямою (хордою)
arc(350, 75, 100, 100, 0, PI + HALF_PI, PIE);    // «шматок піци» — сектор
```

«Пакмен» — це сектор від 45° до 315°: `arc(x, y, d, d, QUARTER_PI, TWO_PI - QUARTER_PI, PIE);`

## 4. Режими `rectMode()` та `ellipseMode()`

Режим змінює значення **перших чотирьох аргументів** фігури.

| Режим | `rect(a, b, c, d)` означає | Для чого зручно |
|---|---|---|
| `CORNER` *(для rect за замовчуванням)* | (a, b) — лівий верхній кут; c, d — ширина й висота | таблиці, сітки |
| `CENTER` *(для ellipse за замовчуванням)* | (a, b) — центр; c, d — ширина й висота | персонажі, симетрія |
| `CORNERS` | (a, b) — один кут; (c, d) — **протилежний кут** | «розтягнути» між двома точками |
| `RADIUS` | (a, b) — центр; c, d — **половини** ширини й висоти | кола за радіусом |

```java
size(300, 200);
background(255);
rectMode(CENTER);
rect(150, 100, 120, 80);   // центр прямокутника — центр вікна
ellipse(150, 100, 60, 60); // центр кола — теж там: фігури вирівняні
```

⚠️ Режим також є «налаштуванням інструмента»: він діє на всі наступні `rect()`, поки ви не викличете `rectMode(CORNER)`.

## 5. Налаштування контуру й заливки

| Функція | Аргументи | Що робить |
|---|---|---|
| `stroke(сірий)` | 0–255 | колір контуру (поки сірий; кольори — урок 3) |
| `noStroke()` | — | **без контуру** |
| `fill(сірий)` | 0–255 | колір заливки |
| `noFill()` | — | **без заливки**, фігура «прозора» всередині |
| `strokeWeight(товщина)` | число в пікселях | товщина лінії та контуру |
| `strokeCap(тип)` | `ROUND`, `SQUARE`, `PROJECT` | форма **кінців** ліній |
| `strokeJoin(тип)` | `MITER`, `BEVEL`, `ROUND` | форма **кутів** у місцях з'єднання ліній |

### Кінці ліній — `strokeCap()`

```
ROUND    (●━━━━━━━━●)   заокруглені кінці (за замовчуванням)
SQUARE    ┃━━━━━━━━┃    обрізано точно по кінцевих точках
PROJECT  ┃━━━━━━━━━━┃   квадратні, ще й «виступають» на половину товщини
```

Різницю видно лише на товстих лініях (`strokeWeight(10)` і більше).

### Що буде, якщо вимкнути і контур, і заливку?

`noStroke(); noFill();` — фігуру не буде видно взагалі. Processing її «намалює», але нічим.

## 6. Порядок малювання = шари

Кожна нова фігура малюється **поверх** попередніх, як аплікація з паперу: що наклеїли пізніше, те й зверху.

```java
size(300, 200);
background(220);
fill(255);                  // налаштували білу заливку
rect(40, 40, 150, 100);     // 1-й шар
fill(100);                  // змінили на сіру
ellipse(170, 110, 120, 120);// 2-й шар — поверх прямокутника
fill(0);
ellipse(170, 110, 30, 30);  // 3-й шар — поверх усього
```

Хочете, щоб коло опинилося **під** прямокутником? Перемістіть рядок з колом **вище**.

## 7. Власні фігури: `beginShape()`, `vertex()`, `endShape()`

Коли готових фігур не вистачає (зірка, стрілка, будиночок одним контуром), фігуру будують з **вершин** (vertex — вершина):

```java
size(200, 200);
background(255);
beginShape();         // «починаю фігуру»
vertex(100, 20);      // вершина 1
vertex(180, 100);     // вершина 2
vertex(140, 180);     // вершина 3
vertex(60, 180);      // вершина 4
vertex(20, 100);      // вершина 5
endShape(CLOSE);      // «закінчую» і з'єдную останню вершину з першою
```

| Функція | Аргументи | Що робить |
|---|---|---|
| `beginShape()` | *(необов'язково)* тип: `POINTS`, `LINES`, `TRIANGLES`… | починає фігуру |
| `vertex(x, y)` | координати | додає вершину |
| `endShape()` | — | закінчує фігуру, **не замикаючи** контур |
| `endShape(CLOSE)` | `CLOSE` | закінчує і **замикає** контур |

Вершини з'єднуються **в тому порядку, в якому ви їх записали**.

## 8. Типові помилки

| Що сталося | Причина |
|---|---|
| Колір лінії не змінюється після `fill()` | лінія фарбується через `stroke()` |
| Усі фігури стали без контуру | десь вище стоїть `noStroke()` — він діє на все далі |
| Коло «з'їхало» вправо-вниз | увімкнено `ellipseMode(CORNER)` |
| Дуга не малюється | `start` більший за `stop`, або кути задано в градусах (`arc(…, 0, 90)`) замість `radians(90)` |
| `quad` схожий на метелика | вершини перелічено не по колу |

## 9. Шпаргалка

| Фігура | Виклик | Що означають перші числа |
|---|---|---|
| точка | `point(x, y)` | координати |
| лінія | `line(x1, y1, x2, y2)` | два кінці |
| прямокутник | `rect(x, y, w, h [, r])` | **кут** (CORNER) |
| еліпс | `ellipse(x, y, w, h)` | **центр** (CENTER) |
| коло | `circle(x, y, d)` | центр, діаметр |
| трикутник | `triangle(x1,y1, x2,y2, x3,y3)` | три вершини |
| чотирикутник | `quad(x1,y1, …, x4,y4)` | вершини по колу |
| дуга | `arc(x, y, w, h, start, stop [, режим])` | еліпс + кути в радіанах |

## 10. Перевір себе

1. Напишіть `rect()`, що малює квадрат 50×50 з центром у точці (100, 100), не змінюючи режиму.
2. Що намалює `arc(100, 100, 80, 80, 0, PI)` — верхню чи нижню половину кола? Чому?
3. Ви написали `fill(0); noFill(); rect(10, 10, 50, 50);`. Якою буде заливка?
4. Як зробити, щоб товста лінія мала квадратні кінці рівно по кінцевих точках?
5. Що зміниться, якщо в прикладі з п'ятикутником замінити `endShape(CLOSE)` на `endShape()`?
