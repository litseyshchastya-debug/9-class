# Детальна теорія до уроку 1. Програма, піксель і система координат

> Тут простими словами пояснено все, що потрібно для уроку 1: що таке програма в Processing, як влаштовані функції та аргументи і як комп'ютер «бачить» екран. Приклади можна запускати в онлайн-середовищі внизу сторінки.

## 1. Що таке програма і скетч

**Програма** — це послідовність команд, які комп'ютер виконує одну за одною, **зверху вниз**. Комп'ютер не здогадується, що ми мали на увазі: він виконує рівно те, що написано.

У Processing програму називають **скетчем** (sketch — «ескіз»). Як художник робить швидкий ескіз олівцем, так і ми швидко пробуємо ідею кодом, запускаємо, дивимося результат і виправляємо.

Скетч зберігається як файл з розширенням `.pde`. Processing завжди кладе його в **папку з такою самою назвою**: скетч `Robot` — це папка `Robot`, у ній файл `Robot.pde`. Якщо назви не збігаються, Processing запропонує створити правильну папку.

Правила для назви скетчу:
- лише латинські літери, цифри та знак `_`;
- не можна починати з цифри: `1robot` — неправильно, `robot1` — правильно;
- без пробілів: `my robot` — неправильно, `my_robot` — правильно.

## 2. Функції та аргументи — найголовніше поняття уроку

**Функція** — це готова команда, яка вміє робити щось одне: намалювати лінію, залити фон, вивести текст. У Processing сотні вбудованих функцій.

**Виклик функції** має сталу форму:

```
назваФункції(аргумент1, аргумент2, ...);
```

- **назва** — що зробити (`line` — лінія, `rect` — прямокутник);
- **аргументи** в круглих дужках — *як саме* зробити: де, якого розміру, якого кольору;
- аргументи розділяються **комами**;
- в кінці — **крапка з комою** `;`. Вона означає «команда закінчилась», як крапка в кінці речення.

Аналогія: функція — це кнопка мікрохвильовки, а аргументи — налаштування: потужність і час. Кнопка та сама, а результат залежить від налаштувань.

### Порядок аргументів має значення

Кожна функція чекає аргументи **у певному порядку**. Для `rect(x, y, ширина, висота)` перше число — завжди x, друге — y. Якщо переплутати порядок, отримаємо зовсім іншу фігуру:

```java
size(300, 200);
rect(20, 50, 200, 40);   // широкий і низький прямокутник
rect(240, 20, 40, 160);  // ті самі числа «переставлені» — вузький і високий
```

### Кількість аргументів теж має значення

`rect()` потребує щонайменше 4 чисел. Якщо написати `rect(10, 10, 50);`, Processing повідомить: *The function "rect()" expects parameters like: "rect(float, float, float, float)"*. Тобто він підказує, скільки і яких аргументів чекає.

## 3. Піксель і система координат

Екран складається з крихітних квадратиків — **пікселів** (pixel = picture element, «елемент зображення»). Кожен піксель світиться одним кольором. Зображення 400×300 — це 400 пікселів у ширину і 300 у висоту, разом 120 000 пікселів.

Щоб указати, де малювати, кожен піксель має **адресу — дві координати**:
- **x** — номер стовпчика: скільки пікселів **праворуч** від лівого краю;
- **y** — номер рядка: скільки пікселів **донизу** від верхнього краю.

```
      x →  0   1   2   3   4   5
y ↓      ┌───┬───┬───┬───┬───┬───┐
  0      │0,0│   │   │   │   │5,0│
         ├───┼───┼───┼───┼───┼───┤
  1      │   │   │2,1│   │   │   │
         ├───┼───┼───┼───┼───┼───┤
  2      │0,2│   │   │   │   │5,2│
         └───┴───┴───┴───┴───┴───┘
```

### Чим це відрізняється від уроків математики

| | Математика | Processing |
|---|---|---|
| Де точка (0, 0) | у центрі | у **лівому верхньому** куті |
| Куди зростає y | **вгору** | **донизу** |
| Від'ємні координати | звичайна річ | точка поза вікном (її не видно) |

Звідки така домовленість? Колись монітори малювали зображення променем, який біг рядками **зверху вниз**, як ми читаємо книжку. Тому рядок 0 — верхній.

### Межі вікна

Якщо вікно має ширину 400, то x змінюється від **0 до 399**, а не до 400. Пікселів 400, але рахунок починається з нуля, як номери квартир, якби перша квартира мала номер 0. Тому правий нижній піксель вікна `size(400, 300)` має координати (399, 299).

## 4. Функції уроку 1 докладно

### `size(ширина, висота)` — розмір вікна

```java
size(400, 300);
```

| Аргумент | Тип | Що означає | Приклад |
|---|---|---|---|
| ширина | ціле число | ширина вікна в пікселях | `400` |
| висота | ціле число | висота вікна в пікселях | `300` |

- Викликається **один раз** і **першим рядком** програми (пізніше — першим рядком `setup()`).
- Задавайте розмір **числами**, а не обчисленнями.
- Якщо `size()` немає взагалі, вікно буде 100×100 пікселів.
- Є третій необов'язковий аргумент — «рендерер», наприклад `size(400, 400, P3D)` для тривимірної графіки (урок 13).

### `background(колір)` — заливка всього вікна

```java
background(255);   // біле тло
background(0);     // чорне тло
background(200);   // світло-сіре тло
```

| Аргумент | Тип | Що означає |
|---|---|---|
| колір | число 0–255 | яскравість сірого: 0 — чорний, 255 — білий |

`background()` фарбує **все вікно** й стирає все, що було намальовано до цього. Тому зазвичай його пишуть **на початку**, а потім малюють фігури. З трьома числами `background(r, g, b)` дає кольоровий фон (урок 3).

### `point(x, y)` — точка

```java
point(50, 20);
```

Зафарбовує один піксель (точніше — точку завтовшки в лінію, за замовчуванням 1 піксель). На сучасних екранах вона дуже маленька, тому для навчання її часто збільшують `strokeWeight(5);` (урок 2).

### `line(x1, y1, x2, y2)` — відрізок

```java
line(10, 20, 150, 80);
```

| Аргумент | Що означає |
|---|---|
| x1, y1 | координати **першого** кінця |
| x2, y2 | координати **другого** кінця |

Порядок кінців не важливий: `line(150, 80, 10, 20)` намалює те саме. Але перші **два** числа — це завжди одна точка, а останні два — інша. Якщо в обох точках однаковий y, лінія горизонтальна; якщо однаковий x — вертикальна.

### `rect(x, y, ширина, висота)` — прямокутник

```java
rect(50, 40, 120, 60);
```

| Аргумент | Що означає |
|---|---|
| x, y | координати **лівого верхнього кута** |
| ширина | на скільки пікселів тягнеться **праворуч** |
| висота | на скільки пікселів тягнеться **донизу** |

Квадрат — це прямокутник з однаковими шириною й висотою: `rect(50, 50, 80, 80);`.

### `ellipse(x, y, ширина, висота)` — еліпс і коло

```java
ellipse(200, 150, 100, 60);   // овал
ellipse(100, 100, 50, 50);    // коло діаметром 50
```

| Аргумент | Що означає |
|---|---|
| x, y | координати **центру** |
| ширина, висота | розміри еліпса; однакові — отримаємо коло |

⚠️ Перша пастка новачків: у `rect()` x і y — це **кут**, а в `ellipse()` — **центр**. Порівняйте:

```java
size(300, 200);
background(255);
rect(100, 50, 100, 100);       // кут у точці (100, 50)
ellipse(100, 50, 100, 100);    // центр у тій самій точці (100, 50)
point(100, 50);
```

Останні два аргументи — це **діаметр**, а не радіус. Коло `ellipse(100, 100, 50, 50)` має радіус 25.

### `println(значення)` і `print(значення)` — повідомлення в консоль

```java
println("Привіт!");
println(25 + 17);
print("Без переходу ");
print("на новий рядок");
```

- `println` виводить значення і **переходить на новий рядок** (ln = line);
- `print` — без переходу на новий рядок;
- текст беруть у **подвійні лапки** `"..."`;
- консоль — чорна панель під редактором. Користувач програми її не бачить, вона для **програміста**, щоб перевіряти себе.

## 5. Правила запису коду

| Правило | Правильно | Неправильно |
|---|---|---|
| крапка з комою в кінці команди | `line(0, 0, 50, 50);` | `line(0, 0, 50, 50)` |
| великі й малі літери розрізняються | `background(0);` | `Background(0);` |
| аргументи через кому | `rect(10, 10, 50, 50);` | `rect(10 10 50 50);` |
| дробові числа через **крапку** | `2.5` | `2,5` (це два числа!) |
| текст у подвійних лапках | `"Привіт"` | `'Привіт'` |

### Коментарі

Коментар — текст для **людини**, Processing його пропускає.

```java
// Однорядковий коментар: усе після двох скісних рисок

/* Багаторядковий коментар:
   усе між цими позначками */
```

Навіщо коментарі:
1. пояснити, що робить код (собі через місяць і вчителеві);
2. тимчасово «вимкнути» рядок, не видаляючи його. Виділіть рядки й натисніть Ctrl+/.

## 6. Як Processing виконує програму

```java
size(200, 200);       // 1. створити вікно 200×200
background(255);      // 2. залити білим
line(0, 0, 200, 200); // 3. провести діагональ
ellipse(100, 100, 80, 80); // 4. намалювати коло поверх лінії
```

Команди виконуються **по черзі**. Коло намальоване після лінії, тому воно **закриває** її середину. Якщо поміняти рядки 3 і 4 місцями, лінія пройде поверх кола. Детальніше про порядок малювання — в уроці 2.

## 7. Шпаргалка уроку

| Функція | Що робить | Аргументи |
|---|---|---|
| `size(w, h)` | розмір вікна | ширина, висота |
| `background(c)` | заливка тла | сірий 0–255 |
| `point(x, y)` | точка | координати |
| `line(x1, y1, x2, y2)` | відрізок | два кінці |
| `rect(x, y, w, h)` | прямокутник | **кут**, ширина, висота |
| `ellipse(x, y, w, h)` | еліпс / коло | **центр**, ширина, висота |
| `println(v)` | вивід у консоль | що вивести |
