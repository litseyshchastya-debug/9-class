# Детальна теорія до уроку 10. Власні функції

> Тут пояснено, як створити власну функцію: з чого вона складається, чим параметр відрізняється від аргументу, як функція повертає значення через `return`, що таке локальні змінні й перевантаження функцій.

## 1. Що таке функція і навіщо писати свої

Ви вже викликали десятки **вбудованих** функцій: `rect()`, `random()`, `dist()`. Їх написали автори Processing. Тепер ви навчитесь створювати **власні**.

**Функція** — це іменований фрагмент коду, який виконує одне завдання. Її **оголошують** один раз, а **викликають** скільки завгодно разів.

Аналогія: функція — це **рецепт**. Ви один раз записали рецепт «Млинці» (оголошення), а потім готуєте за ним щонеділі (виклик). Кількість порцій можна змінювати (аргументи).

Три причини писати функції:
1. **Повторне використання.** Не копіюємо 10 рядків, що малюють дерево, щоб намалювати ліс, а пишемо `drawTree(x, y)` і викликаємо в циклі.
2. **Модульність.** Велику програму розбиваємо на частини з людськими назвами: `move()`, `checkCollision()`, `drawScore()`. Читати такий код — як читати план.
3. **Легше виправляти.** Помилку в дереві виправляємо **в одному місці**, і виправляються всі дерева.

## 2. Анатомія функції

```java
float   circleArea   (float r)   {
  return PI * r * r;
}
```

| Частина | У прикладі | Що означає |
|---|---|---|
| тип результату | `float` | якого типу значення функція **повертає**; `void` — нічого не повертає |
| назва | `circleArea` | за цим ім'ям функцію викликають (правила ті самі, що для змінних) |
| параметри | `(float r)` | «вхідні змінні»: тип і назва кожної, через кому; може бути порожньо `()` |
| тіло | `{ … }` | що функція робить |
| `return` | `return PI * r * r;` | повернути результат і **завершити** функцію |

## 3. Функції `void` — «виконати дію»

```java
void setup() {
  size(400, 200);
}

void draw() {
  background(255);
  drawCar(80, 100, color(255, 0, 0));
  drawCar(220, 140, color(0, 120, 255));
  drawCar(mouseX, mouseY, color(0, 180, 0));
}

void drawCar(float x, float y, color c) {
  rectMode(CENTER);
  fill(c);
  rect(x, y, 80, 30);                // кузов
  fill(0);
  ellipse(x - 25, y + 15, 20, 20);   // колеса
  ellipse(x + 25, y + 15, 20, 20);
}
```

`void` означає «порожнеча»: функція нічого не віддає назад, вона лише **щось робить** (малює). Тому її викликають окремим рядком: `drawCar(...);`.

Оголошення функції пишуть **поза** іншими функціями, на тому самому рівні, що й `setup()` та `draw()`. Порядок не має значення: можна написати `drawCar` вище або нижче за `draw()`.

## 4. Параметри й аргументи

| | Параметр | Аргумент |
|---|---|---|
| Де | в **оголошенні** функції | у **виклику** функції |
| Що це | «порожня комірка» з типом і назвою | конкретне **значення** |
| Приклад | `float x` у `void drawCar(float x, ...)` | `80` у `drawCar(80, 100, ...)` |

Під час виклику значення аргументів **копіюються** в параметри **по черзі**:

```
drawCar( 80,     100,     color(255,0,0) )
          │       │        │
          ▼       ▼        ▼
void drawCar(float x, float y, color c)
```

Правила:
- аргументів має бути **стільки ж**, скільки параметрів;
- типи мають **підходити**: на місце `float` можна передати `int` (5 стане 5.0), а навпаки — ні;
- **порядок** важливий: перший аргумент іде в перший параметр.

### Параметр — це копія

```java
void setup() {
  int a = 10;
  addFive(a);
  println(a);         // 10 — змінна a не змінилася!
}

void addFive(int n) {
  n = n + 5;          // змінюється лише копія n
  println(n);         // 15
}
```

Функція отримує **копію** значення (так званий «передача за значенням»). Змінити змінну того, хто її викликав, вона не може. Щоб «повернути» новий результат, використовують `return`.

## 5. Функції, що повертають значення

```java
float circleArea(float r) {
  return PI * r * r;
}

boolean isInside(float px, float py, float cx, float cy, float r) {
  return dist(px, py, cx, cy) < r;
}
```

Виклик такої функції — це **вираз**: на його місці ніби з'являється відповідь. Тому результат кладуть у змінну, передають як аргумент або перевіряють в умові:

```java
float s = circleArea(10);                 // 314.159…
println("Площа: " + circleArea(5));
if (isInside(mouseX, mouseY, 200, 150, 50)) {
  fill(255, 0, 0);
}
```

### Правила `return`

- Тип значення після `return` має збігатися з типом функції (`float` → повертаємо число).
- `return` **одразу завершує** функцію: рядки після нього не виконуються.
- У функції з типом (не `void`) кожен шлях виконання має закінчуватися `return`:

```java
int sign(float v) {
  if (v > 0) return 1;
  else if (v < 0) return -1;
  return 0;          // без цього рядка — помилка: «This method must return a result of type int»
}
```

- У функції `void` можна написати просто `return;`, щоб достроково вийти.

### Вбудовані функції влаштовані так само

| Вбудована функція | Тип результату | Тому викликаємо так |
|---|---|---|
| `ellipse(...)` | void | окремим рядком |
| `random(10)` | float | `float r = random(10);` |
| `dist(...)` | float | `if (dist(...) < 20)` |
| `color(...)` | color | `color c = color(255, 0, 0);` |

## 6. Локальні змінні функції

Параметри і змінні, оголошені всередині функції, — **локальні**: вони створюються під час виклику і **зникають**, коли функція закінчується. Тому дві різні функції можуть мати змінні з однаковою назвою `x`, і вони не заважатимуть одна одній.

Глобальні змінні (оголошені вгорі скетчу) видно в **усіх** функціях.

⚠️ Якщо назва параметра збігається з назвою глобальної змінної, усередині функції «перемагає» параметр. Це джерело плутанини, тому давайте параметрам інші назви (`tempX`, `newX`).

## 7. Перевантаження функцій

Можна мати **кілька функцій з однаковою назвою**, якщо в них **різні параметри** (кількість або типи). Processing вибере ту, що підходить до аргументів:

```java
void star(float x, float y) {
  star(x, y, 20);                  // розмір за замовчуванням
}

void star(float x, float y, float size) {
  line(x - size, y, x + size, y);
  line(x, y - size, x, y + size);
}
```

Так влаштовані й вбудовані функції: `fill(128)`, `fill(255, 0, 0)` і `fill(255, 0, 0, 100)` — це три перевантажені варіанти `fill`.

## 8. Як добре назвати функцію

- назва — **дієслово** або дія: `drawTree`, `moveBall`, `resetGame`;
- функція, що повертає `boolean`, — питання: `isGameOver`, `hasCollided`;
- одна функція — **одна** задача. Якщо назва виходить «drawTreeAndMoveCarAndScore», розбийте на три.

## 9. Реорганізація скетчу (як у Шиффмана)

Було:

```java
void draw() {
  background(255);
  x += speed;                       // рух
  if (x > width || x < 0) {         // відскок
    speed *= -1;
  }
  fill(175);                        // малювання
  ellipse(x, 100, 32, 32);
}
```

Стало:

```java
void draw() {
  background(255);
  move();
  bounce();
  display();
}
```

`draw()` тепер читається як план дій, а кожна дія має власну функцію.

## 10. Типові помилки

| Повідомлення / поведінка | Причина |
|---|---|
| `The function drawCar(int, int) does not exist` | кількість або типи аргументів не збігаються з параметрами |
| `This method must return a result of type float` | у функції з типом бракує `return` |
| `Void methods cannot return a value` | у функції `void` написано `return 5;` |
| функцію оголошено, а нічого не відбувається | функцію ніде не **викликано** |
| `Syntax error` біля оголошення | функцію вкладено **всередину** `draw()` |
| `int x = drawCar(...)` — помилка | функція `void` нічого не повертає |

## 11. Шпаргалка

```java
void назва(тип1 п1, тип2 п2) { ... }      // дія
тип назва(тип1 п1) { return значення; }    // обчислення
назва(аргумент1, аргумент2);               // виклик дії
тип r = назва(аргумент);                   // виклик з результатом
```
