# Детальна теорія до уроку 12. Масиви та ArrayList

> Тут пояснено, як зберігати багато значень однією змінною: оголошення, створення й заповнення масиву, індекси, `length`, проходження циклом, масиви об'єктів, скорочений цикл for-each і динамічний список `ArrayList` з усіма його методами.

## 1. Навіщо масив

Щоб запам'ятати положення 100 сніжинок, не будемо створювати 100 змінних `y1 … y100`. **Масив** — це одна змінна, яка зберігає **багато значень одного типу**, пронумерованих по порядку.

Аналогія: масив — це **поїзд**: вагони однакові, кожен має **номер**, і в кожному вагоні лежить одне значення.

```
індекс:   [0]   [1]   [2]   [3]   [4]
         ┌────┬────┬────┬────┬────┐
values:  │ 40 │ 90 │150 │ 70 │200 │
         └────┴────┴────┴────┴────┘
```

## 2. Оголошення, створення, заповнення

### Спосіб 1: одразу зі значеннями

```java
int[] values = {40, 90, 150, 70, 200};
String[] days = {"Пн", "Вт", "Ср", "Чт", "Пт"};
```

### Спосіб 2: створити «порожній» масив заданого розміру

```java
float[] ys = new float[100];   // 100 вагонів, у кожному поки 0.0
```

| Частина запису | Що означає |
|---|---|
| `float[]` | тип: «масив дробових чисел» (квадратні дужки = масив) |
| `ys` | назва масиву |
| `new float[100]` | створити масив на 100 елементів |

Значення за замовчуванням у новому масиві: `0` для чисел, `false` для `boolean`, `null` для об'єктів і рядків.

⚠️ **Розмір масиву після створення змінити не можна.** Масив на 100 елементів назавжди має 100 елементів.

## 3. Індекси і `length`

| Запис | Значення |
|---|---|
| `values[0]` | **перший** елемент (індекси починаються з **нуля**!) |
| `values[2]` | третій елемент |
| `values[values.length - 1]` | **останній** елемент |
| `values.length` | кількість елементів (без дужок: це поле, а не метод) |
| `values[1] = 500;` | записати нове значення в другий елемент |

Індексом може бути змінна або вираз: `values[i]`, `values[i + 1]`, `values[int(random(5))]`.

⚠️ Звернення до неіснуючого індексу (`values[5]`, коли елементів 5, або `values[-1]`) — помилка **ArrayIndexOutOfBoundsException** («індекс поза межами масиву»).

## 4. Масиви + цикл `for` — ідеальна пара

Цикл перебирає індекси від 0 до `length - 1`:

```java
for (int i = 0; i < values.length; i++) {
  // values[i] — поточний елемент
}
```

Використовуйте саме `i < values.length`: якщо змінити розмір масиву, цикл підлаштується сам.

### Типові операції

```java
int[] values = {40, 90, 150, 70, 200};

// сума і середнє
int sum = 0;
for (int i = 0; i < values.length; i++) {
  sum += values[i];
}
println("Середнє: " + (float) sum / values.length);

// найбільший елемент
int best = values[0];
for (int i = 1; i < values.length; i++) {
  if (values[i] > best) best = values[i];
}
println("Максимум: " + best);
```

### Трасування пошуку максимуму

| i | values[i] | `values[i] > best`? | best після кроку |
|---|---|---|---|
| — | — | — | 40 (перший елемент) |
| 1 | 90 | true | 90 |
| 2 | 150 | true | 150 |
| 3 | 70 | false | 150 |
| 4 | 200 | true | 200 |

### Масив для малювання: стовпчикова діаграма

```java
int[] values = {40, 90, 150, 70, 200, 120};

void setup() {
  size(420, 250);
}

void draw() {
  background(255);
  float w = width / values.length;           // ширина стовпчика
  for (int i = 0; i < values.length; i++) {
    fill(80, 120, 220);
    rect(i * w + 5, height - values[i], w - 10, values[i]);
    fill(0);
    text(values[i], i * w + 20, height - values[i] - 5);
  }
}
```

## 5. Зсув масиву: «пам'ять» про минуле

Щоб намалювати слід миші з 50 останніх положень, щокадру:
1. зсуваємо всі елементи на одну позицію **ліворуч** (найстаріше значення «випадає»);
2. записуємо нове значення в **останній** елемент.

```java
for (int i = 0; i < xs.length - 1; i++) {
  xs[i] = xs[i + 1];          // кожен бере значення сусіда праворуч
}
xs[xs.length - 1] = mouseX;   // найновіше — в кінець
```

Чому цикл до `length - 1`? На останньому кроці `xs[i + 1]` вийшло б за межі масиву.

## 6. Масив об'єктів

Масиви можуть зберігати не лише числа, а й **об'єкти** (урок 11). Це головна сила поєднання масивів і класів.

```java
Ball[] balls = new Ball[20];      // 1) масив на 20 «місць для м'ячів» — поки ПОРОЖНІХ (null)

void setup() {
  size(400, 300);
  for (int i = 0; i < balls.length; i++) {
    balls[i] = new Ball(random(width), random(height), random(10, 40));  // 2) створюємо КОЖЕН м'яч
  }
}

void draw() {
  background(255);
  for (int i = 0; i < balls.length; i++) {
    balls[i].move();               // 3) кожен м'яч працює сам
    balls[i].bounce();
    balls[i].display();
  }
}
```

*(Потрібен клас `Ball` з уроку 11 з конструктором на три параметри.)*

⚠️ Пастка: `new Ball[20]` створює **масив**, а не м'ячі! Це 20 порожніх паркувальних місць без машин. Самі м'ячі треба створити в циклі через `new Ball(...)`. Інакше буде NullPointerException.

### Скорочений цикл for-each

Коли індекс не потрібен, можна писати коротше:

```java
for (Ball b : balls) {     // «для кожного м'яча b з масиву balls»
  b.move();
  b.display();
}
```

Обмеження: у for-each не можна **замінити** елемент масиву і не видно номер елемента.

## 7. `ArrayList` — список змінної довжини

Звичайний масив має сталий розмір. А частинки феєрверку з'являються і зникають, постріли в грі додаються щосекунди. Для цього є **`ArrayList`** — «гумовий» список, що росте й зменшується.

```java
ArrayList<Particle> particles = new ArrayList<Particle>();
```

| Частина | Що означає |
|---|---|
| `ArrayList<Particle>` | тип: список об'єктів `Particle` (тип елементів пишуть у кутових дужках) |
| `new ArrayList<Particle>()` | створити **порожній** список |

### Методи `ArrayList`

| Метод | Аргументи | Що робить | Повертає |
|---|---|---|---|
| `add(об'єкт)` | новий елемент | додає в **кінець** | — |
| `add(індекс, об'єкт)` | позиція і елемент | вставляє в позицію | — |
| `get(індекс)` | номер | **читає** елемент | елемент |
| `set(індекс, об'єкт)` | номер і новий елемент | замінює елемент | — |
| `remove(індекс)` | номер | **видаляє**, решта зсувається | — |
| `size()` | — | кількість елементів | int |
| `clear()` | — | видаляє все | — |
| `isEmpty()` | — | чи порожній список | boolean |

| | Масив | ArrayList |
|---|---|---|
| Розмір | сталий | змінюється |
| Довжина | `arr.length` | `list.size()` (**з дужками**) |
| Читати | `arr[i]` | `list.get(i)` |
| Записати | `arr[i] = v;` | `list.set(i, v);` |
| Додати | неможливо | `list.add(v);` |
| Типи | будь-які, зокрема `int`, `float` | лише об'єкти (для чисел є `IntList`, `FloatList`) |

### Чому видаляють, ідучи з кінця

Коли видаляємо елемент, усі наступні **зсуваються** на одну позицію ліворуч. Якщо йти вперед (i++), наступний елемент «перестрибне» на місце видаленого, і цикл його пропустить. Тому перебирають **з кінця**:

```java
for (int i = particles.size() - 1; i >= 0; i--) {
  Particle p = particles.get(i);
  p.update();
  p.display();
  if (p.isDead()) {
    particles.remove(i);
  }
}
```

## 8. Типові помилки

| Повідомлення / поведінка | Причина |
|---|---|
| `ArrayIndexOutOfBoundsException: 5` | індекс поза межами: пам'ятайте, що останній індекс — `length - 1` |
| `NullPointerException` у масиві об'єктів | масив створено, а об'єкти в ньому — ні |
| `values.length()` — помилка | у масиву `length` **без дужок** |
| `list.length` — помилка | у ArrayList — метод `size()` **з дужками** |
| `IndexOutOfBoundsException` в ArrayList | `get(i)` з i ≥ `size()` |
| частина частинок «не видаляється» | видалення в циклі, що йде вперед |
