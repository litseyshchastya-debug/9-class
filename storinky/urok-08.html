Урок 8. Цикли while і for. Вкладені цикли та візерунки

Джерела: Shiffman, Learning Processing — розд. 6 «Loops»; Reas & Fry — розд. 8 «Repeat».

Мета уроку

  • використовувати цикли while і for для повторення малювання;
  • будувати сітки за допомогою вкладених циклів;
  • розуміти, чому draw() сам по собі вже цикл.

1. Навіщо цикли?

Без циклу 10 ніг для персонажа — це 10 рядків коду. З циклом — 3 рядки, і кількість ніг змінюється одним числом.

2. Цикл while

int x = 50;
while (x <= 350) {
  line(x, 100, x, 200);
  x += 20;
}

⚠️ Нескінченний цикл: якщо забути x += 20, програма «зависне» — draw() ніколи не завершить кадр.

3. Цикл for

Те саме компактніше:

for (int x = 50; x <= 350; x += 20) {
  line(x, 100, x, 200);
}
Частина Значення
int x = 50 ініціалізація (виконується один раз)
x <= 350 умова продовження
x += 20 крок (після кожного повторення)

Порівняння з Python: for x in range(50, 351, 20):

4. Цикл всередині draw()

draw() повторюється щокадру, а цикл for повністю виконується за один кадр. Тому: - щоб намалювати 100 ліній одночасно — цикл for; - щоб лінії з'являлися по одній — змінна, яка зростає в draw().

Інтерактивний приклад — лінії, що підсвічуються біля курсора:

for (int x = 0; x < width; x += 10) {
  float d = abs(mouseX - x);
  stroke(255 - d);
  line(x, 0, x, height);
}

5. Вкладені цикли = сітка

for (int y = 0; y < height; y += 40) {
  for (int x = 0; x < width; x += 40) {
    fill(x * 255 / width, y * 255 / height, 150);
    rect(x, y, 40, 40);
  }
}

Зовнішній цикл перебирає рядки, внутрішній — стовпці. Так побудовано шахову дошку, таблицю, пікселі зображення (урок 14).

Шахова дошка: остача від ділення

if ((i + j) % 2 == 0) fill(255); else fill(0);

6. Генеративні візерунки

Цикли — основа генеративного мистецтва (Reas & Fry розділ «Repeat» показує роботи, де з простих повторень виникають складні структури).

noFill();
for (int d = 400; d > 0; d -= 20) {
  ellipse(width/2, height/2, d, d);    // концентричні кола
}

📁 Скетчі: skechi/L08_Tsykly (лінії, сітка, кола), skechi/L08_Shakhy

Практика

Рівень 1. Намалюйте 10 кіл в один рядок за допомогою for.

Рівень 2. Створіть шахову дошку 8×8.

Рівень 3 (творчий). Сітка кіл, діаметр кожного залежить від відстані до курсора (dist()), — «живий» візерунок.

Перевір себе

  1. Скільки разів виконається тіло циклу for (int i = 0; i < 10; i += 2)?
  2. Чому програма зависає, якщо в while не змінювати змінну умови?
  3. Що малює вкладений цикл?
  4. Як зробити, щоб лінії з'являлися поступово, а не всі одразу?

// Урок 8. Шахова дошка 8×8 — вкладені цикли та остача від ділення

int n = 8;

void setup() {
  size(400, 400);
  noStroke();
}

void draw() {
  float cell = width / (float) n;
  for (int i = 0; i < n; i++) {        // рядки
    for (int j = 0; j < n; j++) {      // стовпці
      if ((i + j) % 2 == 0) fill(240, 217, 181);
      else                  fill(181, 136, 99);
      rect(j * cell, i * cell, cell, cell);
    }
  }
}

// Урок 8. Цикли: інтерактивні лінії, кольорова сітка, концентричні кола
// Клавіші 1, 2, 3 перемикають режим.

int mode = 1;

void setup() {
  size(400, 400);
}

void draw() {
  background(255);
  if (mode == 1) drawLines();
  else if (mode == 2) drawGrid();
  else drawCircles();
}

// Лінії, що світлішають, коли далеко від курсора
void drawLines() {
  strokeWeight(3);
  for (int x = 0; x < width; x += 10) {
    float d = abs(mouseX - x);
    stroke(constrain(d, 0, 255));
    line(x, 0, x, height);
  }
}

// Вкладені цикли: рядки × стовпці
void drawGrid() {
  stroke(255);
  for (int y = 0; y < height; y += 40) {
    for (int x = 0; x < width; x += 40) {
      fill(x * 255 / width, y * 255 / height, 150);
      rect(x, y, 40, 40);
    }
  }
}

// Концентричні кола, центр — у курсора
void drawCircles() {
  noFill();
  stroke(0);
  strokeWeight(1);
  for (int d = 600; d > 0; d -= 20) {
    ellipse(mouseX, mouseY, d, d);
  }
}

void keyPressed() {
  if (key == '1') mode = 1;
  if (key == '2') mode = 2;
  if (key == '3') mode = 3;
}
