1. Що таке Processing?

Processing — це мова програмування і середовище розробки, яке у 2001 році створили Кейсі Різ і Бен Фрай у Медіалабораторії MIT. Мета — навчити програмуванню художників і дизайнерів через візуальний результат: кожен рядок коду одразу видно на екрані.

Processing побудований на мові Java, тому все, що ви вивчите, знадобиться і в «дорослому» програмуванні (Java, C#, JavaScript/p5.js).

Ідея авторів: програмування — це новий вид грамотності (literacy). Як ми вчимося писати, щоб висловити думку, так ми вчимося кодувати, щоб створювати зображення, анімацію та інтерактив.

2. Середовище розробки (PDE)

  1. Завантажте Processing із сайту processing.org (розділ Download), розпакуйте та запустіть.
  2. Головне вікно містить: - ▶ Run — запуск скетчу (Ctrl+R); - ■ Stop — зупинка; - текстовий редактор — місце для коду; - консоль — сюди виводяться повідомлення println() і помилки.
  3. Збереження: File → Save. Processing створює папку з тією ж назвою, що й файл .pde. Назва не може починатися з цифри та містити пробіли.
  4. Довідка: виділіть назву функції → Help → Find in Reference.

3. Система координат

Шкільна система координат має початок у центрі, а вісь Y спрямована вгору. На екрані комп'ютера інакше:

(0,0) ──────────► X
  │
  │     • (40, 20)
  │
  ▼
  Y
  • Початок координат (0, 0) — лівий верхній кут вікна.
  • X збільшується праворуч, Y — донизу.
  • Вікно size(200, 100) має координати X від 0 до 199 та Y від 0 до 99.

💡 Шиффман радить: перед кодом намалюйте задум на папері в клітинку — кожна клітинка = піксель. Це найкращий спосіб планувати координати.

4. Перший скетч

// Мій перший скетч
size(400, 300);        // розмір вікна: ширина 400, висота 300
background(255);       // білий фон
line(0, 0, 400, 300);  // лінія з лівого верхнього в правий нижній кут
rect(150, 100, 100, 60);    // прямокутник: x, y, ширина, висота
ellipse(200, 130, 50, 50);  // коло: центр x, центр y, ширина, висота
println("Привіт, Processing!");  // повідомлення в консоль

Правила запису коду

  • кожна інструкція закінчується крапкою з комою ;
  • Processing розрізняє великі й малі літери: Size() ≠ size()
  • коментарі: // один рядок та /* кілька рядків */
  • аргументи функції розділяються комами

Типові помилки новачків

Повідомлення Причина
Syntax error, maybe a missing semicolon? пропущено ;
The function "Rect(int,int,int,int)" does not exist неправильний регістр літер
Missing right parenthesis ")" не закрита дужка

Практика

Рівень 1. Створіть вікно 500×500 і намалюйте «хрест» двома лініями з кута в кут.

Рівень 2. На папері в клітинку сплануйте, а потім намалюйте будиночок: стіна — rect, дах — дві лінії, вікно — квадрат, сонце — ellipse.

Рівень 3 (творчий). Намалюйте свій ініціал (першу літеру імені) лише за допомогою line() і rect().

Перевір себе

  1. Де розташована точка (0, 0) у вікні Processing?
  2. Які координати має правий нижній кут вікна size(300, 200)?
  3. Чому скетч потрібно зберігати в папці з такою самою назвою?
  4. Що робить функція println()?

Домашнє завдання

Намалюйте на папері в клітинку (20×20 клітинок) простого робота й запишіть координати всіх його частин — на наступному уроці ми його «оживимо» кодом.

Скетчі уроку

Скопіюйте код у новий скетч Processing або відкрийте файл із папки skechi/ репозиторію. Збережіть скетч під тією самою назвою, а класи покладіть в окремі вкладки.

// Урок 1. Мій перший скетч
// Статичний режим: команди виконуються один раз, зверху вниз.

size(400, 300);             // розмір вікна: ширина 400, висота 300
background(255);            // білий фон

line(0, 0, 400, 300);       // лінія з лівого верхнього в правий нижній кут
line(400, 0, 0, 300);       // друга діагональ

rect(150, 100, 100, 60);    // прямокутник: x, y лівого верхнього кута, ширина, висота
ellipse(200, 130, 50, 50);  // коло: x, y центру, ширина, висота
point(20, 20);              // точка

println("Привіт, Processing!");   // повідомлення в консоль
