Урок 7. Умови: if / else, логічні оператори. Відскок м'яча

Джерела: Shiffman, Learning Processing — розд. 5 «Conditionals» (Boolean expressions, Logical operators, Bouncing ball, Rollovers, Physics 101); Reas & Fry — розд. 6 «Flow».

Мета уроку

  • записувати умови в синтаксисі Java;
  • комбінувати умови логічними операторами;
  • створити м'яч, що відбивається від стінок, та «кнопку», що реагує на мишу.

1. Синтаксис умови

if (умова) {
  // якщо true
} else if (інша умова) {
  // якщо перша false, а друга true
} else {
  // в усіх інших випадках
}

Порівняння з Python: | Python | Processing (Java) | |---|---| | if x > 5: | if (x > 5) { | | elif | else if | | and, or, not | &&, ||, ! | | відступи | фігурні дужки { } |

Оператори порівняння: > < >= <= == !=. ⚠️ = — присвоєння, == — порівняння!

2. Приклад: фон залежно від положення миші

void draw() {
  if (mouseX < width/3) {
    background(255, 0, 0);
  } else if (mouseX < 2*width/3) {
    background(0, 255, 0);
  } else {
    background(0, 0, 255);
  }
}

3. Логічні оператори та «наведення» (rollover)

Чи знаходиться миша всередині прямокутника?

if (mouseX > x && mouseX < x + w && mouseY > y && mouseY < y + h) {
  fill(255, 200, 0);   // підсвічування
} else {
  fill(200);
}
rect(x, y, w, h);

Чи знаходиться миша всередині кола? — відстань до центру менша за радіус:

if (dist(mouseX, mouseY, cx, cy) < r) { ... }

4. Змінна-перемикач (boolean)

boolean isOn = false;

void mousePressed() {
  isOn = !isOn;     // перемикаємо: true ↔ false
}
void draw() {
  if (isOn) background(255);
  else      background(0);
}

5. М'яч, що відскакує

Ключова ідея — швидкість як окрема змінна, яка може змінювати знак:

float x = 100, y = 100;
float xSpeed = 3, ySpeed = 2;

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  x += xSpeed;
  y += ySpeed;
  if (x > width || x < 0)  xSpeed *= -1;   // відскок від бічних стінок
  if (y > height || y < 0) ySpeed *= -1;   // відскок від верху та низу
  ellipse(x, y, 30, 30);
}

Трохи фізики (Physics 101)

Гравітація — це прискорення, яке щокадру збільшує швидкість:

ySpeed += gravity;        // gravity = 0.2
y += ySpeed;
if (y > height) {
  ySpeed *= -0.9;         // відскок із втратою енергії
  y = height;
}

// Урок 7. Кнопка-перемикач і підсвічування при наведенні

int bx = 150, by = 120, bw = 200, bh = 80;
boolean isOn = false;

void setup() {
  size(500, 320);
  textAlign(CENTER, CENTER);
  textSize(24);
}

void draw() {
  if (isOn) background(255, 240, 150);
  else      background(40);

  boolean over = mouseX > bx && mouseX < bx + bw && mouseY > by && mouseY < by + bh;

  if (over) fill(255, 160, 0);   // наведення
  else      fill(200);
  stroke(0);
  rect(bx, by, bw, bh, 12);

  fill(0);
  if (isOn) text("ВИМКНУТИ", bx + bw/2, by + bh/2);
  else      text("УВІМКНУТИ", bx + bw/2, by + bh/2);
}

void mousePressed() {
  if (mouseX > bx && mouseX < bx + bw && mouseY > by && mouseY < by + bh) {
    isOn = !isOn;
  }
}

// Урок 7. М'яч відскакує від стінок і падає під дією гравітації

float x = 100, y = 50;
float xSpeed = 3, ySpeed = 0;
float gravity = 0.3;
float d = 40;

void setup() {
  size(500, 400);
}

void draw() {
  background(255);

  ySpeed += gravity;     // гравітація збільшує швидкість падіння
  x += xSpeed;
  y += ySpeed;

  // відскок від бічних стінок
  if (x > width - d/2 || x < d/2) {
    xSpeed *= -1;
  }
  // відскок від підлоги з втратою енергії
  if (y > height - d/2) {
    y = height - d/2;
    ySpeed *= -0.85;
  }

  fill(255, 120, 0);
  ellipse(x, y, d, d);
}

// Клацання — підкинути м'яч заново
void mousePressed() {
  x = mouseX;
  y = mouseY;
  ySpeed = -8;
}
