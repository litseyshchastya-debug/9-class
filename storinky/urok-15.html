Урок 15. Від ідеї до програми: алгоритм гри, час і налагодження

Джерела: Shiffman, Learning Processing — розд. 10 «Algorithms» (Where have we been? Where are we going?, Catcher game), розд. 11 «Debugging»; Reas & Fry — розд. 23 «Time», 9/18/26 «Synthesis» (Sketching with code, Modularity).

Мета уроку

  • розбивати великий задум на малі кроки (декомпозиція);
  • працювати з часом (millis()) і станами програми;
  • знаходити та виправляти помилки.

1. Як Шиффман будує гру «Ловець крапель» (Catcher)

Задум: з неба падають краплі, гравець ловить їх «ловцем», що рухається за мишею.

Крок 1. Розбити на частини: 1. Ловець (коло за мишею). 2. Перевірка зіткнення двох кіл. 3. Таймер — нова крапля щосекунди. 4. Краплі (клас Drop, ArrayList).

Крок 2. Розробити й перевірити кожну частину окремо — у маленькому скетчі.

Крок 3. Зібрати все разом і лише потім додавати рахунок, рівні, звук.

💡 Головне правило: «Не пишіть 200 рядків, а потім натискайте Run». Пишіть кілька рядків → запускайте → перевіряйте.

2. Зіткнення двох кіл

Кола перетинаються, якщо відстань між центрами менша за суму радіусів:

boolean intersect(Catcher c, Drop d) {
  return dist(c.x, c.y, d.x, d.y) < c.r + d.r;
}

3. Час: millis()

millis() — кількість мілісекунд від запуску програми. Таймер:

int savedTime;
int interval = 1000;    // 1 секунда

void setup() {
  savedTime = millis();
}

void draw() {
  if (millis() - savedTime > interval) {
    // минула секунда — додаємо нову краплю
    savedTime = millis();
  }
}

Також доступні second(), minute(), hour(), day(), month(), year() — системний годинник.

4. Стани програми (екрани гри)

Більшість ігор мають екрани: заставка → гра → кінець. Зберігаємо стан у змінній:

int state = 0;   // 0 — меню, 1 — гра, 2 — кінець

void draw() {
  if (state == 0) drawMenu();
  else if (state == 1) playGame();
  else if (state == 2) drawGameOver();
}

void mousePressed() {
  if (state == 0) state = 1;
  else if (state == 2) restart();
}

5. Налагодження (debugging)

Поради з розділу «Debugging» Шиффмана: 1. Зроби перерву. Свіжий погляд знаходить помилку швидше. 2. Залучи друга — поясни код уголос (метод «гумової качечки»). 3. Спрости. Закоментуйте частини коду, поки помилка не зникне, — так знайдете, де вона. 4. println() — твій друг. Виводьте значення змінних, щоб побачити, що «думає» програма. 5. Режим налагодження PDE: кнопка Debug (метелик), точки зупинки (breakpoints) — клацання на номері рядка, покрокове виконання.

// Урок 15. Гра «Ловець крапель» (за ідеєю Д. Шиффмана, розд. 10)
// Керування — мишею. Стани: 0 — меню, 1 — гра, 2 — кінець гри.

int state = 0;
Catcher catcher;
ArrayList<Drop> drops;
Timer timer;
int score;
int lives;
int best = 0;

void setup() {
  size(500, 600);
  textAlign(CENTER, CENTER);
  restart();
}

void restart() {
  catcher = new Catcher(32);
  drops = new ArrayList<Drop>();
  timer = new Timer(1000);   // нова крапля щосекунди
  timer.start();
  score = 0;
  lives = 3;
}

void draw() {
  background(235, 245, 255);
  if (state == 0)      drawMenu();
  else if (state == 1) playGame();
  else                 drawGameOver();
}

void drawMenu() {
  fill(30, 60, 120);
  textSize(40);
  text("Ловець крапель", width/2, height/2 - 40);
  textSize(18);
  text("Клацніть, щоб почати", width/2, height/2 + 20);
}

void playGame() {
  catcher.setLocation(mouseX, height - 60);
  catcher.display();

  if (timer.isFinished()) {
    drops.add(new Drop(1 + score * 0.1));   // що більший рахунок, то швидше
    timer.start();
  }

  for (int i = drops.size() - 1; i >= 0; i--) {
    Drop d = drops.get(i);
    d.move();
    d.display();
    if (catcher.intersect(d)) {
      score++;
      drops.remove(i);
    } else if (d.reachedBottom()) {
      lives--;
      drops.remove(i);
    }
  }

  fill(0);
  textSize(18);
  text("Рахунок: " + score + "    Життя: " + lives, width/2, 20);

  if (lives <= 0) {
    best = max(best, score);
    state = 2;
  }
}

void drawGameOver() {
  fill(180, 30, 30);
  textSize(40);
  text("Гру закінчено", width/2, height/2 - 40);
  fill(0);
  textSize(20);
  text("Рахунок: " + score + "   Рекорд: " + best, width/2, height/2 + 10);
  text("Клацніть, щоб грати ще", width/2, height/2 + 50);
}

void mousePressed() {
  if (state == 0) {
    state = 1;
  } else if (state == 2) {
    restart();
    state = 1;
  }
}
Catcher.pde · 27 рядків
// Ловець — коло, що рухається за мишею

class Catcher {
  float r;
  float x, y;

  Catcher(float tempR) {
    r = tempR;
  }

  void setLocation(float tempX, float tempY) {
    x = tempX;
    y = tempY;
  }

  void display() {
    stroke(0);
    fill(255, 170, 0);
    ellipse(x, y, r * 2, r * 2);
  }

  // Зіткнення: відстань між центрами менша за суму радіусів
  boolean intersect(Drop d) {
    return dist(x, y, d.x, d.y) < r + d.r;
  }
}
Drop.pde · 32 рядків
// Крапля падає згори

class Drop {
  float x, y;
  float speed;
  float r = 8;
  color c = color(50, 100, 255);

  Drop(float baseSpeed) {
    x = random(r, width - r);
    y = -r * 4;
    speed = baseSpeed + random(1, 3);
  }

  void move() {
    y += speed;
  }

  boolean reachedBottom() {
    return y > height + r * 4;
  }

  // Крапля малюється стовпчиком кіл, що збільшуються донизу (як у Шиффмана)
  void display() {
    noStroke();
    fill(c);
    for (int i = 2; i < r; i++) {
      ellipse(x, y + i * 4, i * 2, i * 2);
    }
  }
}
Timer.pde · 19 рядків
// Таймер на основі millis()

class Timer {
  int savedTime;
  int totalTime;

  Timer(int tempTotalTime) {
    totalTime = tempTotalTime;
  }

  void start() {
    savedTime = millis();
  }

  boolean isFinished() {
    return millis() - savedTime > totalTime;
  }
}
