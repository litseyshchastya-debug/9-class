Програма / Урок 9 з 17

Урок 9. Випадковість і шум Перліна. Генеративне мистецтво

Джерела: Reas & Fry — розд. 21 «Random»; Shiffman, Learning Processing — розд. 4 (Random: Variety is the spice of life), розд. 13 «Mathematics» (Probability, Perlin noise).

Мета уроку

  • використовувати random() для створення різноманітності;
  • розуміти відмінність між хаотичною (random) і плавною (noise) випадковістю;
  • створити першу генеративну композицію.

1. Функція random()

float r = random(10);        // дробове число від 0 до 10 (10 не включно)
float g = random(50, 100);   // від 50 до 100
int n = int(random(6)) + 1;  // ціле від 1 до 6 — кубик

⚠️ random() повертає float. Для цілого числа — перетворення int().

Випадкові кольорові кола

void draw() {
  noStroke();
  fill(random(255), random(255), random(255), 100);
  float d = random(10, 60);
  ellipse(random(width), random(height), d, d);
}

Повторюваний «випадок»

randomSeed(42); — щоразу та сама послідовність «випадкових» чисел. Корисно, коли знайшли вдалу композицію й хочете її відтворити.

Ймовірність

if (random(1) < 0.1) {   // подія з імовірністю 10%
  // ...
}

2. Випадкове блукання (random walk)

Точка щокадру робить крок у випадковому напрямку:

x += random(-2, 2);
y += random(-2, 2);
point(x, y);

3. Шум Перліна — noise()

random() дає «стрибки», а природа змінюється плавно: хмари, гори, рух листя. Кен Перлін придумав функцію шуму для фільму «Трон» (1982) і отримав за це «Оскар».

float t = 0;

void draw() {
  float x = noise(t) * width;   // noise повертає число від 0 до 1
  ellipse(x, height/2, 30, 30);
  t += 0.01;                    // маленький крок → плавніший рух
}
random() noise()
кожне значення незалежне сусідні значення близькі
«шум телевізора» «рельєф гір»
аргумент — межі аргумент — «час» / координата

Гірський пейзаж

for (int x = 0; x < width; x++) {
  float h = noise(x * 0.01) * height;
  line(x, height, x, height - h);
}

4. Генеративне мистецтво

Генеративне мистецтво — коли художник створює правила, а комп'ютер — твір. Кожен запуск дає новий унікальний результат. Відомі автори: Віра Мольнар, Георг Нес, сам Кейсі Різ (співавтор Processing).

Класичний приклад — «10 PRINT»: лабіринт із випадкових діагоналей.

for (int y = 0; y < height; y += 20) {
  for (int x = 0; x < width; x += 20) {
    if (random(1) < 0.5) line(x, y, x + 20, y + 20);
    else                 line(x + 20, y, x, y + 20);
  }
}

📁 Скетчі: skechi/L09_Labirynt (10 PRINT), skechi/L09_Noise (пейзаж і блукач)

Практика

Рівень 1. Кубик: при клацанні мишею на екрані з'являється випадкове число від 1 до 6 (text()), намальоване крапками.

Рівень 2. Зоряне небо: 200 зірок випадкового розміру; кожна мерехтить (яскравість змінюється випадково).

Рівень 3 (творчий). Генеративний постер: поєднайте noise()-пейзаж, випадкові кольори і randomSeed(); натискання s зберігає результат у PNG. Створіть серію з 3 постерів.

Перевір себе

  1. Який діапазон значень повертає random(5, 10)?
  2. Як отримати випадкове ціле число від 0 до 9?
  3. Чим noise() відрізняється від random()?
  4. Що робить randomSeed()?

// Урок 9. «10 PRINT» — генеративний лабіринт
// Клацання мишею — новий лабіринт.

int step = 20;

void setup() {
  size(600, 400);
  strokeWeight(3);
  strokeCap(ROUND);
  drawMaze();
}

void draw() {
  // малюємо лише при клацанні
}

void drawMaze() {
  background(30, 40, 90);
  stroke(255);
  for (int y = 0; y < height; y += step) {
    for (int x = 0; x < width; x += step) {
      if (random(1) < 0.5) {
        line(x, y, x + step, y + step);   // діагональ «\»
      } else {
        line(x + step, y, x, y + step);   // діагональ «/»
      }
    }
  }
}

void mousePressed() {
  drawMaze();
}

// Урок 9. Шум Перліна: гірський пейзаж і плавний блукач

float t = 0;        // «час» для блукача
float offset = 0;   // зсув пейзажу — гори «пливуть»

void setup() {
  size(600, 400);
}

void draw() {
  background(200, 225, 255);

  // Три шари гір: що далі, то світліші
  drawMountains(0.005, 180, color(150, 170, 200), offset * 0.3);
  drawMountains(0.01, 250, color(90, 120, 150), offset * 0.6 + 100);
  drawMountains(0.02, 320, color(40, 60, 80), offset + 200);
  offset += 1;

  // Блукач: плавний рух через noise()
  float x = noise(t) * width;
  float y = noise(t + 1000) * height * 0.5;
  noStroke();
  fill(255, 200, 0);
  ellipse(x, y, 30, 30);
  t += 0.005;
}

// Малює шар гір; scale — «зернистість» шуму, base — висота шару
void drawMountains(float scale, float base, color c, float shift) {
  stroke(c);
  for (int x = 0; x < width; x++) {
    float h = noise((x + shift) * scale) * 200;
    line(x, height, x, base - h + 100);
  }
}
