Урок 12. Масиви та масиви об'єктів. Системи частинок

Джерела: Shiffman, Learning Processing — розд. 9 «Arrays» (Declaration and creation, Array operations, Arrays of objects, Interactive objects, ArrayList); Reas & Fry — розд. 28 «Arrays», 31 «Simulate».

Мета уроку

  • оголошувати, створювати та обробляти масиви в Processing;
  • поєднувати масиви з циклами;
  • створити масив об'єктів і систему частинок з ArrayList.

1. Масив — це список однотипних значень

int[] numbers = {5, 12, 7, 3};       // оголошення зі значеннями
float[] xs = new float[100];          // масив із 100 нулів
  • індекси починаються з 0: numbers[0] = 5, numbers[3] = 3;
  • довжина — numbers.length (без дужок!);
  • розмір масиву фіксований після створення.

⚠️ ArrayIndexOutOfBoundsException — звернення до неіснуючого індексу (наприклад, numbers[4]).

Порівняння з Python: список [5, 12, 7, 3] ↔ масив int[] a = {5, 12, 7, 3};, len(a) ↔ a.length.

2. Масиви + цикли

float[] ys = new float[50];

void setup() {
  size(500, 300);
  for (int i = 0; i < ys.length; i++) {
    ys[i] = random(height);              // заповнення
  }
}

void draw() {
  background(255);
  for (int i = 0; i < ys.length; i++) {
    ellipse(i * 10 + 5, ys[i], 8, 8);   // малювання
    ys[i] += 1;                           // зміна
    if (ys[i] > height) ys[i] = 0;
  }
}

Слід миші (зсув масиву)

Зберігаємо останні 50 положень миші: щокадру зсуваємо всі елементи на одну позицію і записуємо нове значення в кінець. Див. скетч L12_Slid.

3. Масив об'єктів

Справжня сила — у поєднанні з класами (урок 11):

Ball[] balls = new Ball[20];          // 1) масив «порожніх полиць»

void setup() {
  size(400, 400);
  for (int i = 0; i < balls.length; i++) {
    balls[i] = new Ball(random(width), random(height));   // 2) створюємо кожен об'єкт
  }
}

void draw() {
  background(255);
  for (int i = 0; i < balls.length; i++) {
    balls[i].move();                  // 3) кожен об'єкт працює сам
    balls[i].display();
  }
}

Зміна 20 на 2000 — і на екрані дві тисячі м'ячів!

Скорочений цикл for-each

for (Ball b : balls) {
  b.move();
  b.display();
}

4. ArrayList — масив змінного розміру

Коли кількість об'єктів змінюється (постріли, частинки, сніжинки):

ArrayList<Particle> particles = new ArrayList<Particle>();

void draw() {
  background(0);
  particles.add(new Particle(mouseX, mouseY));    // додати
  for (int i = particles.size() - 1; i >= 0; i--) {
    Particle p = particles.get(i);                // отримати
    p.update();
    p.display();
    if (p.isDead()) particles.remove(i);          // видалити
  }
}

💡 Видаляємо, рухаючись з кінця, щоб не пропустити елементи.

5. Системи частинок

Система частинок — набір простих об'єктів, які разом імітують складні явища: вогонь, дим, феєрверк, водоспад. Кожна частинка має положення, швидкість і «тривалість життя» (поступово стає прозорою).

📁 Скетчі: skechi/L12_Slid, skechi/L12_Chastynky (фонтан частинок з ArrayList)

Практика

Рівень 1. Масив із 10 чисел — висоти стовпчиків. Намалюйте стовпчикову діаграму.

Рівень 2. Снігопад: масив зі 100 об'єктів Snowflake, кожна сніжинка падає з власною швидкістю і повертається нагору.

Рівень 3 (творчий). Феєрверк: при клацанні мишею в точці кліку «вибухає» 100 частинок, які розлітаються, падають під дією гравітації та згасають.

Перевір себе

  1. Який індекс має останній елемент масиву довжиною 25?
  2. Що відбувається в рядку Ball[] balls = new Ball[20]; — створюються м'ячі чи ні?
  3. Чим ArrayList відрізняється від звичайного масиву?
  4. Чому елементи з ArrayList зручніше видаляти, перебираючи список з кінця?

// Урок 12. Система частинок з ArrayList: фонтан за курсором
// Клацання — «вибух» із 100 частинок.

ArrayList<Particle> particles = new ArrayList<Particle>();

void setup() {
  size(600, 400);
}

void draw() {
  background(20);
  // Щокадру додаємо дві нові частинки
  particles.add(new Particle(mouseX, mouseY));
  particles.add(new Particle(mouseX, mouseY));

  // Перебираємо з кінця, щоб безпечно видаляти
  for (int i = particles.size() - 1; i >= 0; i--) {
    Particle p = particles.get(i);
    p.update();
    p.display();
    if (p.isDead()) {
      particles.remove(i);
    }
  }

  fill(255);
  text("Частинок: " + particles.size(), 10, 20);
}

void mousePressed() {
  for (int i = 0; i < 100; i++) {
    particles.add(new Particle(mouseX, mouseY));
  }
}

class Particle {
  float x, y;
  float vx, vy;
  float life = 255;     // «тривалість життя» = прозорість
  color c;

  Particle(float startX, float startY) {
    x = startX;
    y = startY;
    float angle = random(TWO_PI);
    float speed = random(1, 4);
    vx = cos(angle) * speed;
    vy = sin(angle) * speed - 2;
    c = color(random(200, 255), random(80, 200), random(50));
  }

  void update() {
    vy += 0.1;          // гравітація
    x += vx;
    y += vy;
    life -= 3;
  }

  void display() {
    noStroke();
    fill(c, life);
    ellipse(x, y, 8, 8);
  }

  boolean isDead() {
    return life <= 0;
  }
}

// Урок 12. Масиви: слід миші з 50 останніх положень

int num = 50;
int[] xs = new int[num];
int[] ys = new int[num];

void setup() {
  size(500, 400);
  noStroke();
}

void draw() {
  background(255);

  // Зсуваємо всі значення на одну позицію вліво
  for (int i = 0; i < num - 1; i++) {
    xs[i] = xs[i + 1];
    ys[i] = ys[i + 1];
  }
  // Нове положення миші — в кінець масиву
  xs[num - 1] = mouseX;
  ys[num - 1] = mouseY;

  // Малюємо: старіші точки — менші та світліші
  for (int i = 0; i < num; i++) {
    fill(255 - i * 5, 100, i * 5);
    ellipse(xs[i], ys[i], i, i);
  }
}
