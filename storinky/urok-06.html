Урок 6. Взаємодія: миша і клавіатура

Джерела: Shiffman, Learning Processing — розд. 3 «Interaction» (Variation with the mouse, Mouse clicks and key presses); Reas & Fry — розд. 7 «Interactivity».

Мета уроку

  • використовувати координати миші для керування малюнком;
  • обробляти події миші й клавіатури;
  • створити інтерактивну програму для малювання.

1. Координати миші

Змінна Значення
mouseX, mouseY поточне положення курсора
pmouseX, pmouseY положення курсора в попередньому кадрі
mousePressed true, якщо кнопку затиснуто
mouseButton LEFT, RIGHT або CENTER 
void setup() {
  size(400, 400);
}
void draw() {
  background(255);
  ellipse(mouseX, mouseY, 40, 40);   // коло ходить за мишею
}

Пензлик для малювання

void setup() {
  size(600, 400);
  background(255);
  strokeWeight(4);
}
void draw() {
  // без background() — малюнок зберігається
  line(pmouseX, pmouseY, mouseX, mouseY);
}

💡 Лінія від попередньої точки до поточної дає неперервний слід навіть при швидкому русі миші.

Миша як «регулятор»

Положення миші можна перетворити на будь-яку величину — колір, розмір, швидкість:

background(mouseX * 255 / width);              // колір фону залежить від X
float d = map(mouseY, 0, height, 10, 200);     // діаметр від 10 до 200

map(value, start1, stop1, start2, stop2) — перераховує число з одного діапазону в інший. Одна з найкорисніших функцій Processing!

2. Події (events)

Функції подій викликаються автоматично, коли щось стається — один раз на подію:

void mousePressed() {   // клацання мишею
  background(255);      // очистити полотно
}

void keyPressed() {     // натискання клавіші
  if (key == 's') {
    saveFrame("malyunok-####.png");   // зберегти малюнок у файл
  }
}
Функція-подія Коли викликається
mousePressed() кнопку миші натиснуто
mouseReleased() кнопку відпущено
mouseDragged() рух із затиснутою кнопкою
mouseMoved() рух без натискання
mouseWheel(MouseEvent e) прокручування колеса
keyPressed() / keyReleased() клавішу натиснуто / відпущено

Змінна vs подія

  • mousePressed (змінна) — «кнопка затиснута зараз?» → перевіряється кожен кадр;
  • mousePressed() (функція) — «щойно відбулося клацання» → спрацьовує один раз.

3. Клавіатура

  • key — символ натиснутої клавіші ('a', '1', ' ');
  • keyCode — код спеціальних клавіш: UP, DOWN, LEFT, RIGHT, SHIFT… (тоді key == CODED).

Приклад: інтерактивний редактор

📁 Скетч: skechi/L06_Malyuvalka — малювання мишею, товщина лінії залежить від швидкості руху, клавіші 1–3 змінюють колір, c — очищення, s — збереження PNG.

Практика

Рівень 1. Персонаж із попередніх уроків слідує за мишею.

Рівень 2. Колір очей персонажа змінюється залежно від mouseX, а клацання мишею перефарбовує фон у випадковий колір.

Рівень 3 (творчий). Створіть «симетричну малювалку»: кожна лінія дзеркально повторюється відносно центру екрана (width - mouseX).

Перевір себе

  1. Що зберігають pmouseX та pmouseY?
  2. Чим змінна mousePressed відрізняється від функції mousePressed()?
  3. Що поверне map(50, 0, 100, 0, 255)?
  4. Як зберегти малюнок у файл?

// Урок 6. Малювалка
// Мишею — малювати; 1, 2, 3 — колір; c — очистити; s — зберегти PNG.

color brushColor;

void setup() {
  size(800, 500);
  background(255);
  brushColor = color(0);
}

void draw() {
  if (mousePressed) {
    // чим швидше рухається миша, тим тонша лінія
    float speed = dist(pmouseX, pmouseY, mouseX, mouseY);
    float w = map(speed, 0, 50, 12, 1);
    strokeWeight(constrain(w, 1, 12));
    stroke(brushColor);
    line(pmouseX, pmouseY, mouseX, mouseY);
  }
  drawPalette();
}

// Підказка-палітра в лівому верхньому куті
void drawPalette() {
  noStroke();
  fill(0);           rect(10, 10, 20, 20);
  fill(220, 30, 30); rect(35, 10, 20, 20);
  fill(30, 90, 220); rect(60, 10, 20, 20);
  fill(brushColor);  rect(90, 10, 20, 20);
}

void keyPressed() {
  if (key == '1') brushColor = color(0);
  if (key == '2') brushColor = color(220, 30, 30);
  if (key == '3') brushColor = color(30, 90, 220);
  if (key == 'c') background(255);
  if (key == 's') saveFrame("malyunok-####.png");
}
