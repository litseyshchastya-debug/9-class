Програма / Урок 10 з 17

Урок 10. Власні функції: параметри та повернення значень

Джерела: Shiffman, Learning Processing — розд. 7 «Functions» (Break it down, Modularity, Reusability, Arguments, Return type, Zoog reorganization); Reas & Fry — розд. 24 «Functions».

Мета уроку

  • створювати власні функції;
  • передавати у функцію аргументи та повертати значення через return;
  • реорганізувати великий скетч на модулі.

1. Навіщо функції?

Шиффман називає дві головні причини: - модульність — велику програму розбиваємо на зрозумілі частини (drawBody(), move(), checkEdges()); - повторне використання — написали один раз, викликаємо скільки завгодно.

2. Оголошення функції

тип_результату назва(параметри) {
  // тіло функції
}
void drawCar(float x, float y, color c) {
  rectMode(CENTER);
  fill(c);
  rect(x, y, 80, 30);          // кузов
  fill(0);
  ellipse(x - 25, y + 15, 20, 20);   // колеса
  ellipse(x + 25, y + 15, 20, 20);
}

void setup() {
  size(400, 300);
}

void draw() {
  background(255);
  drawCar(100, 100, color(255, 0, 0));
  drawCar(250, 200, color(0, 0, 255));
  drawCar(mouseX, mouseY, color(0, 200, 0));
}
  • void — функція нічого не повертає, вона лише виконує дію;
  • float x, float y, color c — параметри: у Java для кожного вказують тип;
  • значення під час виклику — аргументи: їхня кількість і типи мають збігатися.

Порівняння з Python: def draw_car(x, y, c): ↔ void drawCar(float x, float y, color c) {

3. Функції, що повертають значення

float area(float r) {
  return PI * r * r;      // тип результату — float
}

boolean isInside(float px, float py, float cx, float cy, float r) {
  return dist(px, py, cx, cy) < r;
}

Виклик: float s = area(10); або if (isInside(mouseX, mouseY, 200, 200, 50)) { ... }

Вбудовані функції, якими ви вже користувалися, побудовані так само: random() повертає float, dist() — float, ellipse() — void.

4. Реорганізація скетчу

Великий draw() перетворюється на «зміст книжки»:

void draw() {
  background(255);
  move();
  bounce();
  display();
}

Кожна функція — окремий «розділ». Код читається як текст українською: «рухайся, відскакуй, покажися».

5. Локальні змінні та параметри

Параметри та змінні, оголошені всередині функції, — локальні: вони існують лише під час її виконання. Функція отримує копію значення аргументу (для простих типів).

📁 Скетчі: skechi/L10_Funktsii (машинки), skechi/L10_Kvity (функція з параметрами малює квітку)

Практика

Рівень 1. Напишіть функцію drawFlower(x, y, size) і намалюйте нею клумбу з 5 квітів.

Рівень 2. Перепишіть скетч м'яча з уроку 7 так, щоб draw() складався лише з викликів функцій move(), bounce(), display().

Рівень 3 (творчий). Функція drawCharacter(x, y, scale, mood) малює вашого персонажа в різних розмірах і з різним настроєм (mood — boolean: усміхнений / сумний). Намалюйте «натовп» із 20 персонажів у циклі.

Перевір себе

  1. Що означає слово void?
  2. Чим параметр відрізняється від аргументу?
  3. Що буде, якщо викликати drawCar(100, 100) з двома аргументами?
  4. Напишіть функцію, яка повертає більше з двох чисел.

  drawCar(250, 200, color(0, 0, 255));

}

// Малює машину з центром у (x, y) кольору c
void drawCar(float x, float y, color c) {
  rectMode(CENTER);
  stroke(0);
  fill(c);
  rect(x, y, 80, 30);              // кузов
  fill(200, 230, 255);
  rect(x + 10, y - 22, 40, 16);    // кабіна
  fill(0);
  ellipse(x - 25, y + 15, 20, 20); // колеса
  ellipse(x + 25, y + 15, 20, 20);
}

// Урок 10. Функції, що малюють і повертають значення: клумба квітів
// Клацання мишею — посадити нову клумбу.

void setup() {
  size(600, 400);
  noLoop();          // малюємо один кадр; redraw() — ще один
}

void draw() {
  background(120, 190, 90);
  for (int i = 0; i < 12; i++) {
    float x = random(50, width - 50);
    float y = random(50, height - 50);
    drawFlower(x, y, random(30, 80), randomPetalColor());
  }
}

// Малює квітку: центр (x, y), розмір s, колір пелюсток c
void drawFlower(float x, float y, float s, color c) {
  noStroke();
  fill(c);
  for (int i = 0; i < 6; i++) {
    float a = TWO_PI / 6 * i;
    ellipse(x + cos(a) * s / 3, y + sin(a) * s / 3, s / 2, s / 2);
  }
  fill(255, 210, 0);
  ellipse(x, y, s / 3, s / 3);
}

// Повертає випадковий «квітковий» колір
color randomPetalColor() {
  color[] palette = { color(255, 90, 120), color(255, 255, 255), color(160, 110, 230), color(255, 150, 40) };
  return palette[int(random(palette.length))];
}

void mousePressed() {
  redraw();
}
