Урок 3. Колір: відтінки сірого, RGB, прозорість, HSB

Джерела: Shiffman, Learning Processing — розд. 1 (Grayscale Color, RGB Color, Color Transparency, Custom Color Ranges); Reas & Fry — розд. 4 «Color».

Мета уроку

  • зрозуміти, як комп'ютер кодує колір;
  • використовувати моделі RGB та HSB і прозорість (альфа-канал);
  • користуватися інструментом Tools → Color Selector.

1. Відтінки сірого

Одне число від 0 (чорний) до 255 (білий):

background(0);     // чорний
fill(127);         // середньо-сірий
stroke(255);       // білий

❓ Чому саме 255? Бо на один канал кольору відводиться 1 байт = 8 біт, а 2⁸ = 256 значень (0…255). Це ви вже знаєте з теми «Кодування даних».

2. Модель RGB

Екран змішує світло трьох кольорів: червоного (Red), зеленого (Green) і синього (Blue). Це адитивне змішування — зовсім не так, як фарби!

fill(255, 0, 0);      // червоний
fill(0, 255, 0);      // зелений
fill(0, 0, 255);      // синій
fill(255, 255, 0);    // червоний + зелений = жовтий
fill(255, 255, 255);  // усі разом = білий

Кольори також можна записати шістнадцятковим кодом, як у веб-дизайні: fill(#FF8800);

Колір R G B
жовтий 255 255 0
бірюзовий 0 255 255
пурпуровий 255 0 255
помаранчевий 255 136 0

3. Прозорість (альфа-канал)

Четвертий аргумент — альфа: 0 — повністю прозорий, 255 — непрозорий.

background(255);
noStroke();
fill(255, 0, 0, 120);  ellipse(80, 100, 120, 120);
fill(0, 0, 255, 120);  ellipse(140, 100, 120, 120);

Там, де кола перетинаються, кольори змішуються.

4. Модель HSB

Іноді зручніше думати не «скільки червоного», а «який відтінок, наскільки насичений, наскільки яскравий»: - Hue — відтінок (колір на колі кольорів); - Saturation — насиченість (від сірого до чистого кольору); - Brightness — яскравість (від чорного до повного світла).

colorMode(HSB, 360, 100, 100);  // H: 0–360°, S і B: 0–100%
fill(0, 100, 100);    // червоний
fill(120, 100, 100);  // зелений
fill(210, 40, 100);   // блідо-блакитний

colorMode(RGB, 1.0) — дозволяє задавати RGB дробами від 0 до 1. Це те, що Шиффман називає Custom Color Ranges.

5. Тип даних color

Колір можна зберегти в змінній (детальніше про змінні — на наступному уроці):

color sky = color(135, 206, 235);
background(sky);

Функції red(c), green(c), blue(c), hue(c), brightness(c) повертають складові кольору.

Приклад: «Колірна палітра»

📁 Скетч: skechi/L03_Kolir — сім смужок веселки в HSB та накладання прозорих кіл RGB.

Практика

Рівень 1. Розфарбуйте робота з уроку 2 у кольори RGB.

Рівень 2. Відтворіть «діаграму Венна» з трьох прозорих кіл (червоне, зелене, синє). Поясніть, які кольори утворилися в перетинах.

Рівень 3 (творчий). Створіть композицію в стилі Марка Ротко або Піта Мондріана: великі кольорові площини. Використайте Tools → Color Selector для підбору кольорів.

Перевір себе

  1. Який колір дасть fill(0, 0, 0)? А fill(255, 255, 255)?
  2. Чим відрізняється змішування кольорів на екрані від змішування фарб?
  3. Що означає четвертий аргумент у fill(255, 0, 0, 50)?
  4. Коли зручніше використовувати модель HSB?

// Урок 3. Колір: HSB-веселка та змішування RGB з прозорістю

size(600, 400);
background(255);
noStroke();

// Веселка в моделі HSB: змінюється лише відтінок (Hue)
colorMode(HSB, 360, 100, 100);
float stripeW = width / 7.0;
for (int i = 0; i < 7; i++) {
  fill(i * 45, 90, 100);          // відтінок 0°, 45°, 90°, ...
  rect(i * stripeW, 0, stripeW, 150);
}

// Змішування світла RGB з альфа-каналом
colorMode(RGB, 255);
fill(255, 0, 0, 130);  ellipse(250, 260, 160, 160);
fill(0, 255, 0, 130);  ellipse(350, 260, 160, 160);
fill(0, 0, 255, 130);  ellipse(300, 330, 160, 160);

// Колір у змінній та шістнадцятковий запис
color orange = #FF8800;
fill(orange);
rect(500, 330, 60, 40);
println("Червона складова: " + red(orange) + ", зелена: " + green(orange));
