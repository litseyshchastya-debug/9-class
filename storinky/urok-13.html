Програма / Урок 13 з 17

Урок 13. Тригонометрія і трансформації: translate, rotate, scale

Джерела: Shiffman, Learning Processing — розд. 13 «Mathematics» (Angles, Trigonometry, Oscillation, Recursion), розд. 14 «Translation and Rotation (in 3D!)»; Reas & Fry — розд. 14 «Transform», 20 «Calculate», 22 «Motion».

Мета уроку

  • переводити полярні координати в декартові за допомогою sin() і cos();
  • створювати коливальний і круговий рух;
  • використовувати трансформації системи координат.

1. Кути та радіани

У Processing кути вимірюються в радіанах: 360° = 2π ≈ 6,28. radians(90) → HALF_PI; degrees(PI) → 180.

2. Синус і косинус: точка на колі

Точка на колі радіуса r з центром (cx, cy) під кутом angle:

float x = cx + r * cos(angle);
float y = cy + r * sin(angle);

Збільшуючи angle в draw(), отримуємо рух по колу — орбіту планети.

Коливання (осциляція)

sin() повертає значення від −1 до 1 і плавно «гойдається» туди-назад:

float y = height/2 + 100 * sin(frameCount * 0.05);   // маятник, пружина, хвиля

Амплітуда (100) — розмах, множник (0.05) — швидкість коливань.

Хвиля

for (int x = 0; x < width; x += 10) {
  float y = height/2 + 50 * sin(angle + x * 0.05);
  ellipse(x, y, 8, 8);
}
angle += 0.05;

3. Трансформації

Замість того, щоб перераховувати координати кожної фігури, можна перемістити, повернути або масштабувати саму систему координат — «аркуш паперу».

Функція Дія
translate(x, y) перенести початок координат у точку (x, y)
rotate(angle) повернути систему навколо початку координат
scale(s) масштабувати (2 — вдвічі більше)
pushMatrix() запам'ятати поточну систему координат
popMatrix() повернутися до запам'ятованої

⚠️ rotate() обертає навколо точки (0, 0). Щоб обертати фігуру навколо її центру: спочатку translate() у центр фігури, потім rotate(), потім малюємо фігуру з центром у (0, 0).

pushMatrix();
translate(200, 200);
rotate(angle);
rectMode(CENTER);
rect(0, 0, 100, 100);   // квадрат обертається навколо свого центру
popMatrix();
angle += 0.02;

Трансформації накопичуються протягом кадру й скидаються на початку кожного нового draw().

4. Ієрархія: Сонячна система

Земля обертається навколо Сонця, Місяць — навколо Землі:

translate(width/2, height/2);   // Сонце в центрі
ellipse(0, 0, 60, 60);
rotate(earthAngle);
translate(150, 0);               // орбіта Землі
ellipse(0, 0, 25, 25);
rotate(moonAngle);
translate(30, 0);                // орбіта Місяця відносно Землі
ellipse(0, 0, 8, 8);

pushMatrix()/popMatrix() дозволяють додати ще одну планету, «повернувшись» до Сонця.

5. Рекурсія та фрактали (додатково)

Функція, що викликає сама себе, з трансформаціями дає фрактальне дерево: гілка → дві менші гілки під кутом → ... Див. скетч L13_Derevo. Кут розгалуження керується мишею.

6. Погляд у 3D (для зацікавлених)

size(400, 400, P3D); вмикає 3D: з'являється вісь Z, rotateX(), rotateY(), box(), sphere(), lights().

📁 Скетчі: skechi/L13_Orbita (Сонячна система), skechi/L13_Khvylya, skechi/L13_Derevo (фрактал)

Практика

Рівень 1. Квадрат обертається в центрі екрана; швидкість обертання залежить від mouseX.

Рівень 2. Годинник: три стрілки показують поточний час (hour(), minute(), second()).

Рівень 3 (творчий). «Квітка-мандала»: у циклі 12 разів повертайте систему координат на TWO_PI/12 і малюйте пелюстку; додайте пульсацію через sin().

Перевір себе

  1. Як знайти координати точки на колі радіуса 100 під кутом 45°?
  2. Навколо якої точки обертає rotate()?
  3. Для чого потрібні pushMatrix() і popMatrix()?
  4. У якому діапазоні змінюється значення sin()?

Скетчі уроку

Скопіюйте код у новий скетч Processing або відкрийте файл із папки skechi/ репозиторію. Збережіть скетч під тією самою назвою, а класи покладіть в окремі вкладки.

// Урок 13. Рекурсія + трансформації: фрактальне дерево
// Кут розгалуження керується положенням миші по X.

float theta;

void setup() {
  size(600, 450);
}

void draw() {
  background(255);
  stroke(60, 40, 20);
  theta = map(mouseX, 0, width, 0, HALF_PI);
  translate(width/2, height);   // стовбур росте від низу по центру
  branch(120);
}

// Малює гілку довжини len і дві менші гілки на її кінці
void branch(float len) {
  strokeWeight(max(1, len / 12));
  line(0, 0, 0, -len);
  translate(0, -len);
  if (len > 4) {               // умова зупинки рекурсії
    pushMatrix();
    rotate(theta);
    branch(len * 0.67);
    popMatrix();

    pushMatrix();
    rotate(-theta);
    branch(len * 0.67);
    popMatrix();
  }
}

L13_Khvylya

L13_Khvylya.pde · 35 рядків
// Урок 13. Синус: хвиля та маятник
// Миша по X змінює довжину хвилі, по Y — амплітуду.

float angle = 0;

void setup() {
  size(600, 400);
}

void draw() {
  background(255);

  float waveLen = map(mouseX, 0, width, 0.01, 0.15);
  float amp = map(mouseY, 0, height, 10, 150);

  // Хвиля з кружечків
  noStroke();
  fill(0, 120, 255);
  for (int x = 0; x < width; x += 10) {
    float y = height/2 + amp * sin(angle + x * waveLen);
    ellipse(x, y, 10, 10);
  }

  // Маятник: кут коливається через sin()
  float a = QUARTER_PI * sin(frameCount * 0.05);
  float bx = 520 + 80 * sin(a);
  float by = 20 + 80 * cos(a);
  stroke(0);
  line(520, 20, bx, by);
  fill(255, 80, 80);
  ellipse(bx, by, 20, 20);

  angle += 0.05;
}

L13_Orbita

// Урок 13. Трансформації: Сонячна система (Сонце — Земля — Місяць, Марс)

float earthAngle = 0;
float moonAngle = 0;
float marsAngle = 0;

void setup() {
  size(600, 600);
}

void draw() {
  background(10, 10, 30);
  translate(width/2, height/2);   // початок координат — у центрі

  // Орбіти
  noFill();
  stroke(60);
  ellipse(0, 0, 300, 300);
  ellipse(0, 0, 480, 480);

  // Сонце
  noStroke();
  fill(255, 200, 0);
  ellipse(0, 0, 60, 60);

  // Земля + Місяць
  pushMatrix();                   // запам'ятали систему «Сонце»
  rotate(earthAngle);
  translate(150, 0);
  fill(50, 120, 255);
  ellipse(0, 0, 25, 25);
  rotate(moonAngle);
  translate(30, 0);               // Місяць — відносно Землі
  fill(200);
  ellipse(0, 0, 8, 8);
  popMatrix();                    // повернулися до Сонця

  // Марс
  pushMatrix();
  rotate(marsAngle);
  translate(240, 0);
  fill(220, 80, 40);
  ellipse(0, 0, 18, 18);
  popMatrix();

  earthAngle += 0.01;
  moonAngle += 0.05;
  marsAngle += 0.006;
}
